仕事内容

■仕事概要
「営業活動の摩擦をゼロにする」をミッションにAI-Native CRM「Frictio」を開発するSYSLEAで、プロダクトの方向性と事業成果に責任を持つPdMです。AIで実装コストが下がった今、「何を、なぜ、どの順番で作るか」を正しく決め、AIとチームが迷わず動ける形に翻訳し、市場で素早く検証して事業成果につなげます。要件定義・リサーチ・データ分析・実装などの実行作業はAIエージェントに任せ、ユーザーとの対話、課題の見極め、優先順位や品質の判断に時間を集中し、必要なら自らコーディングエージェントで開発・リリースまで進めます。

■仕事の詳細
【プロダクト戦略・意思決定】

  • プロダクトビジョンと中長期戦略の策定（ターゲット顧客、提供価値、勝ち筋の定義）
  • 国内外のCRM／SFA／セールステックの市場・競合分析と差別化方針づくり
  • プロダクトロードマップの策定と、事業インパクト・工数・リスクにもとづく優先順位付け（「作らない判断」を含む）
  • プロダクトKPI（活性化・定着・利用拡大・解約など）の設計とモニタリング
  • 料金設計やプラン構成、機能ごとの提供範囲の提言

【課題発見・検証】

  • ユーザー（営業チーム・CSチーム・経営層）との直接対話による課題の発見と深掘り
  • 商談データ・利用ログ・インタビュー記録からの示唆抽出と仮説立案
  • AIコーディングツールを使ったMVP／プロトタイプの自力構築と、数日〜1週間サイクルの高速検証
  • リリース後の効果測定、データ分析、学習サイクルの運営

【開発】

  • コーディングエージェント（Claude Code、Codexなど）を使った機能開発・改善（要件定義から実装、テスト、PR作成、レビュー対応、本番リリースまで）
  • 小さなUI改善、文言修正、設定変更、社内ツールやデータ抽出スクリプトなどの実装

【デリバリー・合意形成】

  • AIエージェントとエンジニアが自律的に実装できる粒度での要件定義（背景・目的・受け入れ条件・ドメイン用語・制約の明文化）
  • 経営・エンジニア・デザイナー・Sales・CSとの合意形成と意思決定背景の共有
  • Sales／CS／マーケティングと連携した市場投入と顧客への定着推進
  • 顧客要望・フィードバックをプロダクト方針へ反映する仕組みの運営
  • AIエージェントが動きやすい情報構造・ドキュメント・ワークフローなど開発プロセスの設計と改善

【キャリアパス】

  • 将来的にはCPO・事業責任者へのキャリアパスあり

必須条件

  • PdM／PM として、プロダクトの企画・開発・グロースに携わった経験、あるいはフルスタックエンジニアとしての経験（3年以上）
  • プロダクト戦略やロードマップを策定し、優先順位の判断を関係者に説明して合意を得た経験
  • KPI を設計し、データにもとづいて施策の効果を検証・改善した経験
  • ユーザーインタビューや定量データから課題を構造化し、検証可能な仮説として定義できる力
  • 要件を、実装者（人・AI の両方）が迷わない粒度で言語化できる力
  • AI コーディングツール（Claude Code、Cursor、Codex など）を日常的に使い、プロトタイプや小規模な機能を自力で作れる力
  • Git / GitHub を使った基本的な開発フロー（ブランチ、PR、レビュー）への理解
  • 「完璧」よりも検証の段取りを優先し、小さく出して学ぶマインドセット
  • エンジニアと技術的な議論ができる程度のソフトウェア開発の理解
  • 日本語でのコミュニケーション能力（ユーザーとの直接対話があるため）

歓迎条件

  • B2B SaaS プロダクトの PdM 経験（特に、収益への責任を持った経験）
  • CRM／SFA／セールステック領域のドメイン知識、または営業・CS の実務経験
  • 料金設計や、新規プロダクト・新機能の市場投入をリードした経験
  • ソフトウェアエンジニアとしての開発経験、または本番環境へのコード変更をリリースした経験
  • AI エージェント（Claude Code、Codex など）を組み込んだ業務フローや開発プロセスの設計経験
  • LLM を使った機能の企画・評価経験（プロンプト設計、評価指標の設計など）
  • データ分析のスキル（SQL、BI ツール）
  • UI/UX デザインの知見（Figma などの利用経験）
  • 0→1 のプロダクト立ち上げ経験
  • スタートアップでの勤務経験

求める人物像

  • 「仕様を書く人」ではなく「AI とチームが正しいものを自律的に作れる状態をつくる人」として働きたい方
  • 機能をリリースすることではなく、顧客の成果と事業の成長をゴールに置ける方
  • 「作らない判断」も含めて、事業インパクトで優先順位を決め、その理由を明確に説明できる方
  • 必要なら自分で手を動かし、「決める」から「届ける」までを最短距離で進めたい方
  • ユーザーの現場に入り込み、言葉になっていない課題を掘り出すことにやりがいを感じる方
  • AI をただ使うだけでなく、情報の構造や判断基準を設計することで、アウトプットの質を仕組みで担保できる方
  • 曖昧な課題に対して自分で仮説を立て、少人数のチームで実行まで持っていける方
  • B2B SaaS に求められる信頼性（セキュリティ・正確性・コンプライアンス）を理解したうえで意思決定できる方
  • 課題の発見から顧客への価値提供までの間にある「人の手を介す工程」を減らすことに、こだわり続けられる方
  • FDEなどの役割にも興味がある方
  • AI の進化に合わせて自分の働き方や役割を更新し続け、その変化自体を楽しめる方
  • スタートアップの 0→1 フェーズにワクワクする方
