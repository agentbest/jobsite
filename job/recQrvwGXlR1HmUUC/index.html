仕事内容

■仕事概要
■B4Aについて
B4Aは、自由診療クリニックに特化したDXツール「B4A（特許取得済）」を開発するスタートアップです。
電子カルテ・予約・決済・CRM・経営ダッシュボードなど、クリニック経営に必要な機能をワンストップで提供し、現場の業務効率化と経営支援を実現しています。
創業4年で500院以上に導入され、第三者機関調べでは自由診療向け電子カルテ導入院数No.1を獲得。
美容・AGA・歯科など、大手から個人院まで幅広く導入が進み、市場で確固たる地位を築いています。
累計調達額は約10億円を突破。今後はプロダクト開発と採用をさらに強化し、自由診療領域の発展を牽引していきます。
■チームについて
大手・急成長企業でマネジメントや事業運営を牽引してきた、経験豊富なメンバーが集う少数精鋭の組織です。
出身企業には、エムスリー、メルカリ、リクルート、SBI、ADKなど業界をリードする企業が名を連ね、それぞれの領域で培った高い専門性を発揮しています。
成果へのこだわりとプロフェッショナリズムを重んじる一方で、互いを尊重し合うフラットで風通しの良いカルチャーが根づいており、「強い個」と「強いチーム」の両立を目指して日々挑戦を続けています。
■今後の展望
自由診療領域におけるシェアNo.1という実績にとどまらず、クリニック経営と医療現場を支える「なくてはならないインフラ」として社会に根づく存在を目指しています。
今後もワンストップでの提供価値をさらに深化させ、プロダクトの力で市場全体の発展を牽引しながら、領域のDXをリードする圧倒的な存在へと成長を続けていきます。
■業務で関わるサービス
自由診療クリニック特化型 電子カルテ・DXツール「B4A」（特許取得済）
リアルタイム予約や電子カルテの機能をそなえた、自由診療クリニックのDXを実現するSaaSです。
＜主要機能＞

  • リアルタイム予約
  • 事前オンライン問診
  • 電子カルテ、画像管理
  • シフト管理
  • 請求、役務管理
  • 経営数値管理

  • 言語: Ruby, TypeScript, Go
  • フレームワーク等: Ruby on Rails, Next.js, React, GraphQL
  • インフラ: AWS(Fargate, Aurora PostgreSQL), Terraform
  • CI: GitHub Actions
  • 自動テスト: RSpec, Jest
  • ツール: Google Workspace, Github, Slack, Jira, Notion, Figma

■募集背景
B4Aはプロダクトの急成長に伴い、開発の速度と品質を高い次元で両立させる体制構築が急務となっています。
私たちのプロダクトは患者さんの大切な情報を預かるシステムであるため、極めて高いセキュリティ水準が求められます。
また、加速する開発スピードの中にあっても、クリニックの業務効率化やDX推進に直結する品質の維持・向上を実現し続けなければなりません。
現在は開発メンバーのQA活動のサポートや、新しく入社するテスト/QAエンジニアが早期に活躍できる環境の整備を進めています。
今後はさらに一歩進め、チーム全体の品質戦略の策定や自動化、QAプロセスの仕組み化を加速させる必要があります。
そこで、AIなどの先端技術も積極的に取り入れながら、開発の速度を落とさずに品質を担保する仕組みを自ら設計・推進し、「全員品質」の文化を牽引していただけるQAエンジニアを募集します。
■ポジション概要
開発チームのQAエンジニアとして、最先端のツールや手法を柔軟に取り入れながら、テスト自動化の推進やQAプロセスの仕組み化、さらには仕様検討といった開発の上流工程から主体的に関わっていただきます。
単にテストを消化するだけでなく、PdM、エンジニア、デザイナーと密に連携し、いかにしてチーム全体で品質を作り込むかを追求・実行する、裁量の大きなポジションです。
■このポジションの特徴・やりがい

  • 仕様の考慮漏れを未然に防ぐシフトレフトを主導し、本質的な品質保証スキルを磨ける環境です
  • プロセスの自動化や仕組み化を自ら推進し、より高次元なテスト戦略の策定にリソースを集中できます
  • メンバーのサポートや品質意識の啓発を通じ、チームに「全員品質」の文化を根づかせる手応えがあります
  • 医療DXと高いセキュリティという、社会的意義が大きく難易度の高い課題に当事者として挑戦できます

■業務内容
開発チームの一員として、プロダクトの急成長と高いセキュリティ・品質を両立させるためのQA戦略の策定から実行、プロセス改善までを一気通貫でリードしていただきます。

  • PdMやエンジニアと連携した、クリティカルな視点での仕様レビューと潜在リスクの先回り提案
  • 新機能やシステム全体のテスト計画・設計の主導、および適切なツールを組み込んだ効率的なQAプロセスの構築
  • E2Eやリグレッションテストにおける、保守性とスピードを両立した自動化戦略の策定・環境構築・運用
  • 高いセキュリティ水準（3省2ガイドライン等）やシステムの安定性を考慮した非機能要件の検証設計・推進
  • 開発メンバーやテストエンジニアのQA活動のサポート、およびチーム全体の品質意識醸成によるQA能力の底上げ

必須条件

  • Webアプリケーションを対象とした、コードベースのリグレッションテストの自動化（E2Eテストの自動化）基盤を保守性を考慮しながら構築・運用した経験
  • 他職種とフラットに議論し、ビジネス目的やUI/UXの意図を汲んで上流工程からリスクや改善案を提案した経験
  • SQL（テーブル結合や集計関数など）を用いた、データベースの状態を正しく検証した実務経験

歓迎条件

  • QAプロセスの仕組み化・改善、またはアジャイル環境でのシフトレフトの推進経験
  • 医療や決済など、高いセキュリティや「3省2ガイドライン」準拠を要する領域でのQA経験
  • プロダクトの主要言語のコードリーディングに基づく効率的な検証経験
  • 非機能テスト（負荷試験、パフォーマンス検証、セキュリティスキャンなど）の計画・実施経験
  • 生成AI等のツール導入やCI/CD連携による、QAプロセスの効率化・仕組み化の経験
