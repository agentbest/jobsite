企業情報

株式会社テックオーシャン（TECH OCEAN Co.,Ltd.）は、2018年（平成30年）6月に杉並区で創業した理系人材特化のHRテック企業。本社は東京都千代田区永田町（住友不動産永田町ビル3階）、資本金3億5,000万円（資本準備金含む）。「若者に気付きと刺激とフィールドを」を合言葉に、京都大学大学院卒で三菱化学を経て大学院生採用支援ベンチャーの取締役として年間約1万人以上・累計4万人の上位校理工系大学院生に就活指導を行い、一般社団法人知的人材連携センター（IPAC）を創設、キーエンスグループのイプロスで新事業創出に取り組み経営貢献賞を受賞した創業者（代表取締役 CVO FOUNDER）が設立し、インテリジェンス（現パーソルキャリア）でHITO総合研究所社長執行役員やLINEバイト代表取締役、LINEのHRサービス事業部設立を歴任した人物が2025年6月に代表取締役CEOに就任、イプロス新卒1期生として約10年勤務し2018年に参画した事業推進統括、オービックビジネスコンサルタント・マイクロソフト・ポーターズ執行役員CTOを経たCTOらが経営する。「人と組織の可能性で豊かな社会をつくる - FUTURE DRIVEN by POTENTIAL」を掲げ、理工系専用就活サイト「TECH OFFER」は日本マーケティングリサーチ機構の調査で「理系会員学生No.1」「アクティブ会員数No.1」「学生一人当たりオファー獲得数No.1」「プライム市場上場企業利用社数No.1」など5冠を達成し、業界シェア第1位の採用管理システム「i-web」（ヒューマネージ）やsonar ATS（Thinkings）とAPI連携、2022年度グッドデザイン賞、日本のサービスイノベーション企業2022に選定、ASAC主催ピッチイベントでAmazon Web Service賞、第5回WOMAN’s VALUE AWARD優秀賞を受賞。有料職業紹介許可を持ち、代表を装った不審メールへの注意喚起を行う。

仕事内容

■仕事概要
4万件の研究室データベースと100万件の技術キーワードで理系学生と企業をマッチングし、累計8万人超が利用する就活サービス「TECH OFFER」や、低学年からの企業との接点をつくる新サービス「TECH PORTAL」を開発する同社で、プロダクトエンジニアとして開発を担いながら、プロジェクトを前に進める役割にも段階的に領域を広げていただきます。現在はPdM・デザイナーとの要件調整や進捗管理をEMが兼務している状態で、開発だけでなくプロジェクトを動かせるエンジニアを増やすための募集です。

■仕事の詳細

  • Go／TypeScriptを用いたWebアプリケーションの設計・開発・運用
  • PdMやデザイナーとの要件整理・仕様検討
  • 開発タスクの整理、優先順位付け、進捗・課題管理
  • 中長期のプロダクト成長を見据えた設計・改善
  • 外部パートナーとの連携・進行管理

【入社後の流れ】

  • まずはエンジニアとしてプロダクト開発に入り、プロダクトやチームを理解
  • その後、経験や得意領域に合わせて要件整理やプロジェクトマネジメントへ徐々に担当範囲を拡大（PM/PL経験の有無は問わず、志向とスキルを見ながら実プロジェクトで役割を任せる）

【開発スタイル】

  • PdMや事業責任者との距離が近く、何を・なぜ・どう作るかをビジネスとエンジニアが一緒に考える。エンジニアからの提案も歓迎
  • 意思決定は速い一方、今後プロダクト・事業が広がることを見据えてシステムの土台をつくる

【キャリアパス】

  • PdM／TPM、エンジニアリングマネージャー（EM）、テックリード／アーキテクトなど、志向に応じて選択可能

必須条件

  • Webアプリケーションの開発実務経験（目安3年／言語不問）
  • コンピュータサイエンスの基礎知識（アルゴリズム・OS・ネットワーク など）
  • 今後、PM／PLなどプロジェクトを動かす役割にも挑戦したい方
  • 実装だけでなく、要件整理やプロジェクト推進にも関わっていきたい方

歓迎条件

  • テックリードやチームリーダーの経験
  • PdMやデザイナーと要件整理や仕様策定を行った経験
  • アーキテクチャ設計や技術選定に携わった経験
  • 生成AI／LLMを活用した開発フローの改善経験

求める人物像

  • エンジニアとしての専門性を持ちながら、今後はプロダクトを動かす経験も積みたい方
  • 自分の担当範囲だけを見るのではなく、プロジェクト全体がうまく進むために必要なことを考えられる方
  • PdMやデザイナーなど、職種の異なるメンバーとも自分からコミュニケーションを取れる方
  • わからないことや課題をそのままにせず、自分から確認・相談しながら前に進められる方
  • チームでより良いプロダクトをつくることを楽しめる方
