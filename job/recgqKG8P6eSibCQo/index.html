仕事内容

■仕事概要
あらゆる技術を組み合わせて顧客の事業変革（BX/DX）を牽引するエスユーエスで、AIをアシスタントとして使いこなし、スピードと品質を両立してシステムを構築するFDE（Forward Deployed Engineer）を担います。営業が要件を聞き設計書が降りてくるのを待つのではなく、曖昧なビジネス要件から自ら仮説を立て、現場のすぐ横で即日プロトタイプ（モック）を作成・検証する「AI駆動開発」を最前線で牽引します。

■仕事の詳細

  • 顧客のビジネス要件のヒアリングと仮説立案、技術タスクへの分解
  • AIツールを活用したプロトタイプ（モック）の即日作成・検証
  • システム構築と、AI生成コードの検証・品質担保

【プロジェクト事例（BX/DX）】

  • 大手自動車会社における品質改善、車両生産の手順変更の展開
  • 工場現場における生産効率化、生産量増加に向けた人員配置
  • 全社AI活用導入における教育育成、RAG・エージェント導入

【使用技術・ツール】

  • 言語：Python、SQL、シェルスクリプト（Linux）等
  • 環境：Linux（Ubuntu等）、AWS、GCP、Azure、Windows 等
  • ツール：AIエディタ（Cursor等）、Dify等のローコード/ノーコードツール、Visual Studio Code、Git、Docker 等
  • モジュール：NumPy、Pandas、scikit-learn、PyTorch、TensorFlow、LangChain、OpenAI API 等

【勤務】

  • 自社（六本木）での請負・受託案件、またはお客様先（東京・神奈川・埼玉・千葉・栃木・茨城・群馬等）
  • 階層別AI教育プログラムあり

必須条件

AI時代において、現在の保有スキルはすぐに陳腐化します。そのため、我々は過去の経験以上に「変化への適応力」と「人間固有の価値」を重視します
【必須】

  • 社内でAX/DXを進めていた経験（業界問わず）
  • 何らかの言語でのシステム開発実務経験（基本設計〜実装・テストまで目安2〜3年以上）
  • 基本・詳細設計書を読み解き、実装に落とし込めるIT基礎力（AI生成コードの意図や脆弱性を理解し、人間として厳格な検証と品質担保に責任を持てるスキル）

歓迎条件

  • 生成AI（プロンプトエンジニアリング）の実務やプライベートでの活用経験（バイブコーディングなどの活用経験）
  • ビジネス要件の技術翻訳力（曖昧な要望を的確な技術タスクへ分解できる力）
  • 顧客や他部署との折衝・要件調整の経験、チーム開発におけるリード・レビュー経験
  • データ分析、機械学習モデルの開発・実装経験

求める人物像

  • アンラーニング力（学習棄却力）と変化適応力：

⇒過去の自分のやり方（手書きのコード等）に固執せず、AI前提の新しい開発スタイルを素直に受け入れ、学び直せる柔軟性

  • 「作業者」からの脱却意欲と当事者意識：

⇒「仕様書がないと動けない」という受け身の姿勢を捨て、自ら仮説を立てて「共に正解を創り上げる」スタンスを持てる方

  • 現場のリアリティへの執着：

⇒AIの出力を鵜呑みにせず、実ビジネスの文脈に照らし合わせて検証・補正する「ラストワンマイル」を泥臭くやり抜く責任感
