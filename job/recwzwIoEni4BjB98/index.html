仕事内容

＜募集背景＞
GMOTECHホールディングスでは、複数のグループ会社を横断した事業展開を行っており、Webサービス・業務システム・インフラ基盤も年々拡大しています。
2025年に品質管理チームを立ち上げたことを皮切りに、
「開発 × 運用 × 品質 × AI活用」を横断的に統括できる体制強化が求められています。

そこで今回、グループ全体のシステム運用・開発に関して、
技術面・体制面の両方からマネージメントいただけるシステムエンジニアを募集します。

＜職務内容＞
o グループ全体のシステム運用・開発に関する方針策定・技術的アドバイス
o Webサービス・業務システムの設計レビュー、改善提案
o AWSを中心としたインフラ構成・運用体制のマネージメント
o 開発チーム・QAチームとの連携、品質・開発プロセスの最適化
o 外部ベンダーや協力会社との技術的な折衝・進行管理
o （状況に応じて）自ら設計・実装・検証に関与するプレイング業務

必須条件

o Webサイト・Webサービスの開発経験
o AWS環境での運用経験（設計・改善・トラブル対応など）
o システム全体を俯瞰して考えられる設計・判断力

【使用技術・開発言語】
o フレームワーク／言語
o Java
o PHP
o Rails/Ruby
o Python
※すべて必須ではなく、いずれかの実務経験があれば可

歓迎条件

o AI技術への強い興味・関心がある方
o すでにAIエージェントや生成AIを業務に活用している方
o 開発チームやプロジェクトのマネージメント経験
o テスト・品質保証（QA）観点を踏まえた開発経験
o 新しい技術やツールを積極的に検証・導入してきた経験

求める人物像

o 技術とビジネスの両面から物事を考えられる方
o グループ全体最適を意識して判断・提案ができる方
o 現場のエンジニアやQAと対話しながら、チームを前に進められる方
o AIや自動化を活用し、「より良い仕組み」を作ることに楽しさを感じる方
