企業情報

Turing株式会社（チューリング）は、2021年8月に創業された完全自動運転の実現を目指すスタートアップ。本社は東京都大田区平和島（東京流通センター物流ビルA棟）、資本金3,000万円、累計調達金額365億円（株式235億円／融資130億円）。創業者・代表取締役CEOは愛知県出身で、東京大学での留年をきっかけにプログラミングを学び10年間コンピュータ将棋プログラムPonanzaを開発して佐藤名人（当時）を倒し、東京大学大学院修了後にHEROZに入社しリードエンジニアとして上場まで助力した人物で、愛知学院大学特任教授も兼任。執行役員兼CTOは産業技術総合研究所研究員／米国NIST客員研究員として研究しつつ日本の囲碁AIプロジェクトの開発代表として最大1,100GPUの並列分散強化学習を設計・開発し世界大会準優勝、将棋AIでも世界大会優勝の実績を持つ。取締役COOはGoogle・メドレー出身、取締役CFOはGE・モルガン・スタンレー・One Capital出身、社外取締役はHondaでF1エンジン制御を開発しグローバル・ブレインでハードウェア領域の投資に携わる人物など、AI・自動車・金融の専門家が集う。ミッションは「We Overtake Tesla（テスラを超える）」というあえて誤解を恐れない言葉に集約され、世界への本当の革新は常に賛否の分かれる場所から始まってきたとして好き嫌いの分かれる高い目標を掲げる。生成AI・大規模基盤モデルを用いた自動運転ソフトウェアの研究開発とそれを搭載する自動車の開発を行い、初めてエンドユーザー向けに販売した「THE FIRST TURING CAR」を経て、ロボット基盤モデルの研究開発（GENIAC）に採択され、完全自動運転に向けたフィジカル基盤モデルの開発と車載E2Eシステムの実装を推進する。

仕事内容

■仕事概要
「We Overtake Tesla」を掲げ完全自動運転AIを開発するチューリングで、機械学習基盤を支えるGPUクラスタ（主にクラウド上のSlurm環境）の運用・改善をリードし、オンプレを含めた計算資源の利用効率を最大化します。2025年12月時点でオンプレ・クラウド合わせて約0.7EFLOPS（FP16）を常時運用し、今後2年で5〜10倍に拡大する計画が進行中です。GPUは非常に高額なため、利用効率やクラスタ信頼性の改善が大きな費用対効果につながるポジションです。

■仕事の詳細

  • AWS・GCP・オンプレミスにまたがる大規模GPU計算基盤の設計・構築・運用・継続的な改善
  • GPUクラスタの信頼性向上に向けた障害対応・原因分析・運用自動化・再発防止の仕組みづくり
  • GPU・ストレージ・ネットワーク・ジョブスケジューリングを含む計算資源の可視化・性能分析・利用効率の最適化
  • MLエンジニアと連携した、学習ワークロードの実行環境・開発体験・CI/CD・モニタリング基盤の改善

【技術的な取り組み】

  • 次世代オンプレミスGPU基盤の構築（GPU間をRoCE v2で800Gbps接続するネットワーク）
  • クラウド・オンプレミスを横断したワークロード配置、将来的なKubernetesとの連携

【体制】

  • 機械学習エンジニア、インフラエンジニア、MLOpsエンジニアと連携し、OS・ネットワーク・ストレージから学習ワークロードまで横断して課題解決をリード
  • エンジニア／シニア／プリンシパルの3レベルで募集

【経験について】

  • GPU/HPCやSlurmの経験は必須ではなく、WebサービスのSRE、Kubernetes Platform Engineer、クラウドインフラ等の経験からGPU/HPC領域へ専門性を広げたい方も歓迎

必須条件

※全てではなく、下記のいずれかやその他の技術に精通している方を探しています

  • Linuxを用いた本番インフラの運用
  • 障害対応経験Terraform / Ansible等を用いたInfrastructure as Codeの経験
  • Python / Go / Shell script等による運用自動化・ツール開発経験
  • Kubernetes、クラウド基盤、大規模分散システム等のいずれかの構築・運用経験
  • OS、ネットワーク、ストレージ、アプリケーションを横断して問題を切り分ける能力
  • 本番環境で安全なrollout、rollback、復旧を行った経験

歓迎条件

※全てではなく、下記のいずれかやその他の技術に精通している方を探しています

  • マルチクラスタ構成の大規模GPUクラスタの構築・運用・性能改善経験
  • 学習ジョブの特性に応じた、スケジューリングやリソース最適化の経験
  • Slurm × Kubernetes の統合・運用経験
  • MLワークロード（学習・推論）や分散学習（PyTorch DDP 等）への理解
  • 並列分散ファイルシステム(ex. Lustre)や高速ネットワーク(InfiniBand / RDMA / EFA / RoCE)の知識
  • GPU/NIC/driver/firmwareのトラブルシュート

求める人物像

  • 経験の少ない領域や不確実性の高い環境でも、主体的に学び、優先順位をつけながら自走できる方
  • インフラからアプリケーションまで広い視点を持ち、MLエンジニアの課題を理解して技術的な解決策に落とし込める方
  • 部門や職種を横断して関係者と密に連携し、対面でのコミュニケーションも活かしながら、基盤の改善や新しい技術への挑戦を主体的に推進できる方
