企業情報

ＡＲアドバンストテクノロジ株式会社（ARI）は、東京・渋谷に本社を置く、クラウド技術とデータ・AI活用によるDXソリューション企業。IT化／デジタル化それ自体は目的ではなくビジネス目標達成のための手段に他ならないと捉え、ビジネスからITに至るまで顧客が直面する事業課題に応じ、幅広いサービスラインナップで課題解決を主体的にリードする。顧客との円滑なコミュニケーションなくしてプロジェクトの成功はないと考え、顧客の置かれた状況や担当者の背景に応じて柔軟かつ高品質なサービスを提供、「お客様の成功こそが我々が提供すべき価値」を信条とし、単なるシステム導入に留まらない一気通貫したサービスを提供する。解決すべき問題が高度化し多様な専門性が求められる時代に、BUSINESS、TECHNOLOGY、CREATIVEと多彩な専門性をもったチームからプロジェクト毎に最適なフォーメーションを構成し、柔軟性と拡張性の高い専属チームで徹底的な顧客目線で伴走する。ビジネス課題の本質に対してクラウドの利点を徹底活用する「cnaris（Cloud Native ARI Sustainability）」、企業の様々なデータからビジネス課題の診断・予測・分析を行いAI・数理最適化・量子コンピュータなどの最新テクノロジーと人のインテリジェンスを融合する「dataris（Data AI Tactics ARI Sustainability）」を軸に、EARTHBRAINの建設DXを支えるアプリ基盤再構築（Cursorを活用したAI駆動開発とUI/UXデザイン先行アプローチ）、グループ利用者10,000ユーザーを超えるChatGPTによる社内生成AI活用基盤のセキュアな構築、ふるさと納税サイト「ふるなび」のモバイルファースト化、国際的な日本文化発信サイト構築などを支援。ダイキン情報システム、大和ライフネクスト、アイモバイル、日清丸紅飼料、インテック、GMOあおぞらネット銀行などの事例を持ち、AWS表彰プログラムで2026 Japan AWS Top Engineers等に計14名が選出された。

仕事内容

＜募集背景＞
もっと上流から関わりたい。もっとAIを使いこなしたい。もっと変化の中心に近い場所で、プロジェクトを前に進めたい。

私たちは、Claude / Claude Code をはじめとした生成AIを開発の前提に据え、「つくり方」そのものをアップデートしているチームです。AIで生産性を上げるだけでなく、AIを組み込んだアプリケーション開発にも挑戦しています。

さまざまな業界のお客様から「AIで解決したい」というご相談が数多く集まります。生成AIを活用した開発に本格的に取り組みながら、多様なAI案件を通じて経験をどんどん積めるのが私たちの環境です。

今後は、AI駆動開発を個人の取り組みに留めるのではなく、プロジェクト全体として再現性のある開発スタイルへと進化させていきたいと考えています。

まだ完成された組織ではありません。でも、もう動き始めています。
この変化の中で、AIネイティブ開発プロジェクトを推進し、お客様の課題解決とチームの成果創出を牽引していただけるPMを募集します。

＜業務内容＞
生成AIを開発の前提に据え、従来の開発プロセスそのものをアップデートしながら、モダンなアプリケーション開発を推進しています。お客様のビジネス実現を加速させるため、企画・コンサルティングから要件定義、設計、開発、テスト、運用まで一気通貫で携わります。特定の業界に閉じず、多様な業界のお客様の課題解決にAIを活用していきます。

これから特に強化していくのが、Claude / Claude Code などを活用したAI駆動開発です。開発生産性を高めるだけでなく、AIを組み込んだアプリケーションや、新しい開発体験そのものにも挑戦します。

本ポジションでは、AIネイティブ開発プロジェクトのPMとして、お客様との折衝、課題整理、要件定義、プロジェクト計画、進行管理、品質・コスト・納期管理、チームマネジメントなどをお任せします。AIを活用した開発プロセスを前提に、プロジェクト全体の生産性と提供価値を高めていただくことを期待しています。

また、単にプロジェクトを管理するだけでなく、お客様の業務課題に対して「AIで何を解決できるか」「どのようなプロダクト・機能に落とし込むべきか」を考え、エンジニアや関係者と連携しながら実現まで推進していただきます。

  • AIネイティブ開発プロジェクトの企画、提案、要件定義、プロジェクト推進
  • お客様の業務課題、要望の整理およびAI活用テーマの具体化
  • プロジェクト計画の策定、進行管理、課題管理、リスク管理

  • エンジニア、デザイナー、コンサルタントなど社内外メンバーとの連携、チームマネジメント
  • Claude / Claude Code 等を活用した開発プロセス改善、AI駆動開発の推進
  • AIを組み込んだ機能／アプリケーションの企画、実装方針の検討、改善提案

＜ポジションの魅力＞

  • AIネイティブ開発プロジェクトを上流から推進できる

お客様の課題整理や要件定義から関わり、AIを活用した解決策を具体化していくことができます。単なる開発管理ではなく、AIをどう事業・業務に活かすかを考え、プロジェクトとして実現していく経験ができます。

  • 多様な業界のAI案件に数多く携われる

業界を限定せず、多くのお客様から「AIで解決したい」という相談が集まります。多様なテーマに触れながら、AIを活用したアプリケーション開発・業務改善・プロジェクト推進の経験値を積み上げられます。

  • 全社をあげてAI活用に取り組んでいる

全社員にClaudeを配布。経営トップが「従来型のシステム開発が変わっていく」という強い危機感のもとAIシフトを牽引し、部門責任者も日々最新のAI情報を社内に発信しています。組織全体にAI活用の文化が根付きつつあります。

  • AI駆動開発をプロジェクト全体に広げられる

Claude / Claude Code などの生成AIを個人で活用するだけでなく、プロジェクト運営やチーム開発にどう組み込み、品質・生産性・スピードをどう高めるかにも関われます。AIを前提としたプロジェクトマネジメントの型づくりに挑戦できます。

  • これからの組織・文化を一緒につくれる

完成された環境ではないからこそ、開発文化や働き方、AIを活用した開発スタイルを一緒につくれます。AIネイティブ開発を推進する組織づくりにも関われるポジションです。
