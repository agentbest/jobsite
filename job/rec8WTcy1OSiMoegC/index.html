企業情報

ColorSing株式会社は、歌に特化したライブ配信アプリ「ColorSing（カラーシング）」を開発・運営する企業。国内最大規模のライブ配信アプリを運営していたチームがサービスを手掛けており、カラオケ機器「JOYSOUND」を提供するエクシングと、ライブ配信アプリ「Pococha」を運営するDeNAから出資・事業サポートを受けている。歌好きのリスナーだけが集まる環境で「歌」を純粋に評価・応援してもらえる場をつくり、「歌で生きていく」夢を業界最高水準の報酬制度で支えることを掲げる。配信者（Lシンガー）は審査制で、専門チームが常時配信を監視することで安心・安全な配信環境を整えている。

仕事内容

■仕事概要
「JOYSOUND」のエクシング社や「Pococha」のDeNA社から出資・事業サポートを受ける歌特化型ライブ配信アプリ「ColorSing」（2023年7月リリース、DAU約3万人・配信者DAU約3,500人・月次売上4億円超）で、動画配信・音声配信の技術を通じてUX・品質向上のための開発を担うポジションです。

■仕事の詳細

  • ライブストリーミングの遅延を極力減らす開発
  • 高品質な映像・音声を届けるための開発
  • 既存の配信視聴機能を、保守や追加開発しやすい形に再設計・リファクタリング
  • 視聴プレーヤー（カラオケ・ギフト機能含む）の開発

【開発環境】

  • 配信：Tencent Real-Time Communication
  • インフラ：GCP（GKE, Cloud Run, GCS, Pub/Sub）, Terraform
  • DB：Google Cloud Spanner
  • サーバー：Go
  • アプリ：Flutter/Dart
  • Webフロント：TypeScript, Next.js, React
  • その他：GitHub, Figma, Notion, Slack

【チーム体制】

  • エンジニアは現在20名（ほとんどが業務委託または副業）
  • 開発はフルリモートで、コミュニケーションはほぼSlackとGitHub上
  • PdMやサーバーエンジニアと協力して開発し、QA・CSチームとも連携

必須条件

  • 動画配信基盤(AWS IVS, Tencent TRTC, Wowza Media Server, Agora など) を使った開発の経験
  • iOSまたはAndroidアプリ開発の実務経験
  • Flutter/Dartを用いたAPI開発のキャッチアップできる方
  • GitHubを用いたチームでの開発経験

歓迎条件

  • 動画視聴ライブラリを開発した経験
  • 法人ではなく個人(プライベート)での開発経験でも可
  • カメラアプリのフィルタ開発経験
  • 顔の塗り替えアプリ開発経験
  • H264やVP9などを使った動画プレーヤーの開発経験

求める人物像

  • 0→1の領域・事業で、サービスの成長にコミットしたい方
  • ユーザーの体験の向上を追求するサービスに関わりたい方
  • サービス成功のため、あらゆる課題に主体的にチャレンジする意欲をお持ちの方
