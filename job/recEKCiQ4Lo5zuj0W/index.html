企業情報

株式会社LIGHTzは、熟練者やハイパフォーマーが持つ"言語化されていない知"を構造化し、AIとテクノロジーの力で組織全体に拡張する企業です。ベテラン技術者の暗黙の判断基準をヒアリングやデータ解析を通じて構造化するなど、製造業を中心に企業ごとの個別支援を行ってきました。スペシャリスト思考の「技術伝承AI」の提供と実務適用支援、「汎知化」技術を活用したナレッジ共有プラットフォームの開発を手がけています。2016年10月設立で、現在はIPO準備フェーズにあり、つくばの本社のほか東京（御徒町）・名古屋にオフィスを構えています。

仕事内容

■仕事概要
熟練者の“言語化されていない知”を構造化し、AIとテクノロジーで組織に拡張する、IPO準備フェーズの企業で、Microsoft 365を中心としたコーポレートIT基盤の運用から業務改善まで幅広く担います。一部個人の判断や手作業に頼っている業務を整理し、セキュリティ強化・IT統制・業務自動化・生成AI活用を通じて、効率的で継続しやすい仕組みに進化させる、手を動かす比重の高いポジションです。

■仕事の詳細
【全社IT基盤の企画・運用・改善】

  • Microsoft 365、Teams、SharePoint、Entra ID、Intuneを中心とした社内IT基盤の運用・改善
  • アカウント管理、権限設計、ライセンス管理、IT資産管理の整備・最適化
  • ベンダーとの連携および運用品質の改善

【業務改善・自動化・生成AI活用の推進】

  • Microsoft 365および各種SaaSを活用した業務プロセス改善
  • 社内ナレッジの蓄積・活用を促進する仕組みづくり
  • Microsoft Copilot、Claude、Gemini等の生成AI活用の企画、環境整備、ルール策定
  • 継続的な業務効率化・生産性向上施策の推進

【セキュリティ・IT統制の強化】

  • Entra ID、Intune、Microsoft Defender for Endpoint等を活用したIT統制の整備・改善
  • アカウント棚卸し、権限管理、デバイス管理の高度化

【社内ITパートナーとしての改善推進】

  • 各部門との対話を通じた業務課題の整理と改善提案
  • オンボーディング、問い合わせ対応、ナレッジ整備等の運用改善
  • 利便性とセキュリティのバランスを踏まえた意思決定支援

【体制】
既存メンバーと連携しながら経験の幅を広げ、将来的にはコーポレートITの各テーマを主体的に担うことが期待されます。

歓迎条件

  • SaaSの導入・管理・運用経験
  • ISMS運用またはIT監査対応経験
  • IPO準備企業でのコーポレートIT経験
