企業情報

ファインディ株式会社（Findy Inc.）は、2014年2月設立（本格的な事業開始は2016年7月）のエンジニアプラットフォーム企業。本社は東京都品川区大崎（アートヴィレッジ大崎セントラルタワー）、従業員478名（2026年1月時点、有期雇用社員含む）、資本金1億円（資本準備金含め19億9,692万円）。「つくる力を、社会の力へ。」を掲げ、「つくる人が能力を発揮できる組織がなければ、イノベーションは実現しない」という考えのもと、エンジニアが不安なく挑戦できるプラットフォームを通じて個人の可能性を広げるとともに組織の生産性も高め、社会の人材資産を好循環させる未来を目指す。シリーズA約2億円、B約5.5億円、C約15億円、D約20.5億円と資金調達を重ね、インドを皮切りに韓国・台湾へ進出して世界共通のエンジニアプラットフォームづくりを進める。「Findy Team+」は国際セキュリティ認証SOC2 Type2を取得、エンジニア組織表彰「Findy Team+ Award」やエンジニアリング組織の意思決定層が集う「Engineering Leaders Day」を主催し、ソフトウェア開発組織に関する市場調査も発信。有料職業紹介事業許可。

仕事内容

Findyは「挑戦するエンジニアのプラットフォームをつくる。」をビジョンに、エンジニアと企業のより良い出会いを生み出すサービスを展開しています。

Findy転職事業部では、エンジニア採用支援を起点に、エンタープライズ企業・SIer / 受託企業への支援を強化しています。企業の採用課題が複雑化する中で、求職者と企業の双方に深く向き合い、より質の高いマッチングを実現する体制づくりを進めています。

特にAgent組織では、エンタープライズ企業・SIer / 受託企業のAI・クラウド領域強化に対して、Findyが得意とするモダンWeb・クラウド・AI人材とのマッチングを創出することを目指しています。求職者に対しても、AI時代でキャリアの選択肢が複雑になる中で、新しいキャリアの可能性を広げる支援を行っていきます。

今回は、Enterprise領域とSIer / 受託領域それぞれで1名ずつの採用を想定しています。いずれも両面型の支援スタイルをベースにしながら、Enterprise領域では企業攻略、SIer / 受託領域では求職者のキャリアデザイン支援により深く向き合うポジションです。

世の中には数多くの人材紹介会社があります。その中でFindyが目指しているのは、単に求人と求職者をつなぐことではありません。

求職者に対しては、本人の志向や不安、これまでのキャリアを丁寧に理解し、意思決定に必要な判断材料を提供すること。企業に対しては、求人票に書かれた条件だけでなく、開発組織の課題や採用背景まで理解し、採用成功に向けて伴走すること。

本ポジションは、求職者と企業の双方に向き合いながら、担当企業の採用成功と求職者の意思決定支援を一気通貫で担う、両面型エージェントポジションです。

一人ひとりのキャリアに向き合いながら、求職者の可能性と企業の開発組織づくりの双方に向き合い、より良い意思決定を支援する役割を担っていただきます。

Findy転職事業部では、事業拡大に伴い「エンタープライズ企業」および「SIer / 受託領域」におけるエンジニア採用支援の強化を進めています。

DX推進やAI活用、開発内製化が進む中、多くのエンタープライズ企業が高度なエンジニア採用に課題を抱えています。また、SIer / 受託領域においてもモダン開発への移行が進む一方、従来の固定観念や求人票の情報だけでは企業の本当の魅力が求職者に伝わりにくいという構造的課題があります。

だからこそ、表面的なマッチングにとどまらず、企業の実態を深く理解し、求職者にとっての新たな選択肢やキャリアの可能性を可視化していくAgentの介在価値が高まっています。

今回の募集では、CA / RAの枠を超えた両面型エージェントとして、企業・求職者の双方に深く向き合っていただける方を求めています。決まった型をなぞるだけでなく、担当領域の勝ち筋づくりや事業成長の仕組み化から携われる、挑戦しがいのあるフェーズです。

人材紹介の経験を活かし、より専門性が高く介在価値の深い支援へステップアップしたい方を募集します。

■仕事内容・ミッション

入社後は、EnterpriseまたはSIer / 受託領域の担当企業を持ち、企業・求職者双方への支援を通じて、採用成功と求職者のキャリア意思決定を支援していただきます。

担当企業の採用課題や求職者の志向を深く理解し、適切なマッチング・選考支援・アトラクトを行いながら、成果創出に向けた計画立案・実行・振り返りまで担っていただくことを期待しています。

FindyのAgentは、担当企業の解像度、求職者への訴求方法、面談の質がそのままマッチングの質に直結する仕事です。企業と求職者の間に立ち、双方にとって納得感のある意思決定をリードしていただきます。

Enterprise領域では、企業の採用成功に向けて、採用要件や選考プロセス、アトラクトの設計に踏み込みながら、顧客組織を動かすアカウント攻略を担います。SIer / 受託領域では、求職者との面談を通じて、本人の価値観や志向を整理し、新しいキャリアの選択肢を検討できるよう支援します。

求職者に対しては、転職を急かすのではなく、本人が大切にしている価値観やキャリアの可能性を整理しながら、判断材料を提供します。企業に対しては、求職者をただ推薦するのではなく、採用要件や選考体験、アトラクトの改善にも踏み込みます。

■このポジションのやりがい・魅力

■Findyならではの集客基盤とデータを武器にできる

Findyには、Webエンジニアを中心とした自社プラットフォームの集客基盤があります。外部媒体だけに依存するのではなく、Findyに登録しているエンジニアとの接点や、GitHub連携などのデータを活用しながら、企業と求職者双方に向き合えることが特徴です。

一般的な人材紹介では出会いづらい層に対して、企業の魅力やキャリアの可能性を届けられるため、単なる求人紹介ではなく、Findyならではの介在価値を発揮できます。

■意思決定の質に向き合う支援ができる

Findyでは、求職者が自分の意思で選べるように情報を届けることを大切にしています。企業側にも、単なる推薦ではなく、採用要件・選考プロセス・アトラクトの改善まで踏み込むため、企業と求職者双方にとって質の高いマッチングを追求できます。

両面型だからこそ、企業側だけ、求職者側だけではなく、双方の課題・期待・意思決定プロセスを理解したうえで、より良いマッチングをつくることができます。

■エンジニア領域へのチャレンジで、汎用的な紹介経験を専門性に変えられる

Findyが向き合うのは、採用難易度が高く、専門性も高いエンジニア採用領域です。人材紹介で培った求職者理解・企業理解・マッチング力を活かしながら、技術領域・開発組織・エンジニアキャリアへの理解を深めることで、今後のキャリアにおいても資産になる専門性を磨けます。

■担当領域によって異なる支援スタイルに挑戦できる

FindyのAgent組織では、Enterprise領域とSIer / 受託領域の双方に向き合っていますが、それぞれで求められる支援スタイルは異なります。

SIer / 受託領域では、求職者のキャリアデザインに深く寄り添い、本人がまだ気づいていない選択肢を一緒に整理することが重要です。技術環境やプロジェクトの特徴、キャリアの広がりを丁寧に伝えながら、求職者が自分の意思で選べるよう支援します。場合によっては、求職者との面談から選考フォローまで一気通貫で担い、キャリアの見方そのものを広げていくことも求められます。

一方、Enterprise領域では、企業側の採用成功に向けたアカウント攻略がより重要になります。採用要件や選考プロセス、アトラクト設計を見直し、現場・人事・経営層を含む複数関係者を巻き込みながら採用成功の勝ち筋をつくっていきます。大手企業の内製開発・AI活用・クラウド活用の機運を捉え、採用支援を通じて事業・組織づくりに踏み込んでいく面白さがあります。

求職者のキャリアに寄り添う力と、企業の採用課題を攻略する力。その両方を磨けることが、FindyのAgentならではの面白さです。

■1→10フェーズで事業拡大に関われる

Findy転職事業部のEnterprise・SIer / 受託領域は、これからさらに伸ばしていくフェーズです。

決まったオペレーションをこなすだけではなく、どうすれば承諾数を最大化できるか、どの企業・求職者に注力すべきか、どの打ち手を変えるべきかを自ら考え、事業拡大に貢献できます。

人材紹介の経験を活かしながら、支援する企業群の拡張やマッチングの型づくりにも関われることが、Findyならではの面白さです。

■挑戦を後押しするチームづくりを大切にしている

Agent組織では、戦略や仕組みだけでなく、それを実行するチームづくりを大切にしています。

新しい領域への挑戦や試行錯誤には難しさもありますが、失敗を学びに変えながら、もう一度チャレンジできる組織でありたいと考えています。安心して挑戦できる環境の中で、自分自身のキャリアの可能性も広げていけるポジションです。

■入社後の立ち上がり

入社後は、これまでの人材紹介・採用支援経験を活かしながら、エンジニア採用領域の専門性と、企業・求職者双方に向き合う両面型の支援力を段階的に高めていただきます。

まずは、Findyのサービスや転職事業部の支援スタイル、エンジニア採用市場の特徴をキャッチアップしていただきます。これまで培ってきた求職者理解・企業理解・マッチング力を土台に、エンジニアの職種・スキル・レイヤーごとの転職ペインや、企業側の開発組織課題を理解し、専門性の高い採用支援へ広げていきます。

その後は、EnterpriseまたはSIer / 受託領域の担当を持ち、企業・求職者双方への支援を担っていただきます。SIer / 受託領域では求職者の選択肢を広げるキャリアデザイン力を、Enterprise領域では大手企業の採用成功に向けたアカウント攻略力を磨いていきます。

将来的には、求職者支援の質を高める取り組みや、企業攻略の勝ち筋づくり、マッチングの型づくりにも関わりながら、チーム全体の支援品質向上に貢献していただくことを期待しています。
