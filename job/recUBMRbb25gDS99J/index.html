企業情報

株式会社NaLaLys（NaLaLys Co., Ltd.）は、2023年1月設立、代表取締役・長谷島良治氏が率いるAIコンプライアンス企業。本社は東京都港区港南（品川インターシティA棟 SPROUND内）、資本金3億999万9,963円（資本準備金含む）。代表はフリークアウト、LINE、H2O.aiを経て創業したAI・機械学習の専門家で、コンピュータビジョンと自然言語処理のディープラーニングに豊富な経験を持ち、世界最大のデータサイエンスコンペティションKaggleで複数回トップ10入り・5回優勝（最高世界ランク4位）の実績を持つ。企業とそこで働く従業員に安心で安全なビジネス環境を提供するため、AIを活用して企業のコンプライアンスをあらゆる角度から支えるプラットフォームを展開し、デジタル技術でコンプライアンス業務の効率化と高度化を支援。経営陣にはPwCアドバイザリーのフォレンジック部門で不正調査を経験したCFO/COOや、贈収賄防止・企業犯罪・ビジネスインテリジェンスのリスクマネジメント専門家、渥美坂井法律事務所パートナー弁護士が参画する。

仕事内容

■仕事概要
「不正」という社会課題にAIで挑み、メール・チャットのAI分析で不正・ハラスメント・情報漏えいの兆候を検知する「モニタリング」や「AI通報窓口」を提供するNaLaLysで、プロダクトの中核となるAIシステムを進化させるMLエンジニアです。多様なデータソースや新たなリスク類型への対応、オンプレミス環境を含むエンタープライズ向け提供の強化に向け、特定領域の専任ではなく、モデル開発・データ処理・推論基盤・顧客対応までを一貫して担当します。

■仕事の詳細
【モデル開発】

  • LLMを活用したリスク検知パイプラインの設計・開発・運用
  • 新しいデータソースやリスク類型の追加、検知精度向上に向けた機能開発
  • モデルのファインチューニング、プロンプト設計、評価基盤の整備
  • 学習データの収集・加工・品質改善、および実験設計・効果検証

【基盤構築・運用】

  • GPU推論環境（vLLM / CUDA / マルチGPU）の構築・運用・最適化
  • AIワークロードのコスト最適化、性能改善、安定稼働の実現
  • オンプレミス環境への導入支援、アップデート対応、障害対応
  • 本番環境で発生する課題の調査、原因分析、改善施策の実装

【顧客課題の解決とプロダクト改善】

  • 新規顧客や新規ユースケース向けの検知ロジック設計・PoC推進
  • クライアントや事業部門と連携した技術提案、技術ドキュメント作成
  • 検知結果の分析やフィードバックをもとにしたプロダクト改善

【開発組織への貢献】

  • 設計レビュー、コードレビューへの参加
  • 技術方針やアーキテクチャの検討・意思決定
  • 開発プロセスや品質向上に向けた継続的な改善

【開発環境】

  • フロントエンド：TypeScript / JavaScript / React / HTML / CSS
  • バックエンド：Python / Go / Node.js
  • データベース：MySQL / PostgreSQL / MongoDB
  • インフラ：AWS / Docker
  • CI/CD：GitHub Actions、情報共有：Slack / Notion、課題管理：GitHub
  • Coding agent（Claude, Codex, Cursor）は各自自由に利用

【体制】

  • AI開発チームは現在2名。開発チームにはKaggle Grandmasterの称号を持つAIエンジニアも在籍
