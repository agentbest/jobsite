仕事内容

ChatGPT・Gemini・Perplexity・Google AI Overviews等の生成AI検索において、クライアントのブランド・サービスが「引用され、推奨される」状態をつくるLLMO（Large Language Model Optimization）コンサルティングを担うポジションです。

検索行動は「10本の青リンクから選ぶ」から「AIの回答をそのまま受け取る」へ移行しつつあります。従来のSEOだけでは流入を維持できないクライアントが増えており、生成AI検索での露出を設計・計測・改善する専門機能を立ち上げます。

国内でこの領域の実務を語れる人はまだ少数です。手法が固まりきっていない段階から検証を回し、自分の手で方法論を作れる人を求めています。

【主な業務内容】
1. 生成AI検索の現状分析

  • 主要LLM・AI Overviewsにおける引用・言及状況の調査
  • 競合ブランドとの被引用差の分析
  • 自社・クライアントの情報が誤って回答されているケースの特定

2. LLMO戦略・施策立案

  • 検索意図とプロンプト行動の分析に基づく対策方針の策定
  • エンティティ設計（ブランド・人物・サービスの実体情報の整備）
  • 構造化データ・技術要件の改善方針の立案

3. コンテンツ改善のディレクション

  • 一次情報・独自データを軸としたコンテンツ企画
  • LLMが引用しやすい構成・記述への改善指示
  • ライター・制作チームへの指示書作成と品質チェック

4. 効果測定・レポーティング

  • 引用率・言及内容・トーンのモニタリング設計と定点観測
  • Google Analytics / Search Consoleと生成AI経由流入の突合
  • 施策効果の検証と次アクションの提案

5. クライアントコミュニケーション

  • 定例MTGでの報告・提案
  • 提案資料の作成
  • 経営層・マーケ責任者への説明

【入社後の流れ】
〜3ヶ月

  • クライアントサイト・ブランドの生成AI検索上での現状把握（引用状況・言及内容・競合との差）
  • 主要LLM（ChatGPT / Gemini / Perplexity / Claude）とAI Overviewsの挙動差の把握
  • 既存SEO施策との重なりと差分の整理
  • 計測方法（プロンプト設計・引用率のモニタリング）の立ち上げ

〜6ヶ月

  • クライアント単位でLLMO改善プランを立案し、実行まで担当
  • 構造化データ・エンティティ設計・一次情報コンテンツの改善を推進
  • 施策前後の引用状況を数値で示し、クライアントへ報告
  • 提案・定例MTGをメインで担当

6ヶ月以降

  • 複数クライアントを横断で担当し、成果に責任を持つ
  • 検証で得た知見を型化し、社内メソッド・提案パッケージとして整備
  • グループ各社のオウンドメディアへの横展開を主導

【このポジションの魅力】
1. 国内で先行者になれる領域を担当できる
LLMOは方法論が確立していない領域です。既存の正解をなぞる仕事ではなく、検証結果を自分で積み上げて型を作れます。数年後に希少性の高い専門性として効いてくる経験を、いま取りに行けます。

2. グループ10社のサイトを検証環境として使える
FUNDiTグループは金融・不動産・デジタル広告・EC支援など多様な事業を持ちます。クライアント案件だけでなく自社メディアでも仮説を試せるため、検証サイクルの回転速度がクライアントワーク専業と比べて速くなります。

3. SEOの経験がそのまま資産になる
エンティティ設計・構造化データ・一次情報の作り込みは、SEOで培った土台の上に積み上がります。これまでの経験を捨てずに、次の10年の主戦場へ移れます。

4. 成果を数値で示せる
引用率・言及内容の変化として結果が見えるため、「やった感」ではなく数字で語れます。提案から成果報告までを一人で完結できる裁量があります。

5. 意思決定が速い
施策の承認から実行までのリードタイムが短く、試したいことをすぐ試せます。新領域の立ち上げに必要な試行回数を確保できる環境です。

  • キーワード調査・コンテンツ企画の経験
