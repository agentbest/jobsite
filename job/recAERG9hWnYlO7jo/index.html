仕事内容

■仕事概要
お客様のシステム・業務課題に対し、AWSを中心としたクラウドアーキテクチャを企画・設計し、提案から構築までを技術面からリードするポジションです。今後は単純なAWS Migrationにとどまらず、既存システムのModernization、AIを活用したApplication開発、生成AI／LLMを利用したシステム、AI基盤／データ基盤、クラウドネイティブ化など、ApplicationとAWS、AIを横断した提案・開発に注力していきます。AI領域の専門知識がすべて必須ではなく、AWS／Applicationの知見をベースにAI領域へ専門性を広げたい方も歓迎です。

■仕事の詳細
【AWS Assessment】

  • 既存システム／インフラ環境のアセスメント、現行Architectureの分析
  • クラウド移行可能性の評価、コスト／性能／可用性／セキュリティ等の分析
  • AWS Migration／Modernization方針の策定、改善ロードマップの提案

【AWS Migration】

  • オンプレミス／既存クラウドからAWSへの移行設計、移行方式の検討
  • 移行Architectureの設計、移行計画・ロードマップの策定
  • 移行に伴う非機能要件の設計、プロジェクトの技術リード

【Application Modernization】

  • モノリシックシステムのModernization、マイクロサービス化、コンテナ化、API化、サーバーレス化
  • 既存ApplicationのArchitecture見直し

【AI基盤／AI Application】

  • Amazon Bedrock等を利用したAI基盤、生成AI／LLMやRAG等を活用したAIシステム
  • AIと既存システムとの連携、AIシステムにおけるセキュリティ／ガバナンス設計

【顧客への提案・プリセールス】

  • 顧客課題／要件のヒアリング、AWS／AI活用に関する技術提案・Architecture提案
  • 提案資料・構成図・ロードマップの作成、工数／コスト見積、技術的な顧客折衝

【Architecture設計・構築】

  • AWS Architecture設計、基本設計／詳細設計、セキュリティ設計、非機能設計
  • 構成図・設計書等の作成、設計レビュー、AWS環境の構築、技術課題の解決

【テックリード／チームマネジメント】

  • 設計／技術レビュー、社内エンジニアへの技術展開、AWS技術の標準化
  • Phase1 Philippinesやビジネスパートナーとの協業、若手エンジニアの育成

【使用ツール・環境】

  • AWS：VPC / EC2 / RDS / S3 / IAM / CloudWatch / ECS / EKS / Lambda / API Gateway / WAF / Security Hub / Organizations / Control Tower / Amazon Bedrock など
  • IaC：Terraform / CloudFormation、DevOps：Docker / Jenkins / CI/CD / GitHub
  • Application：Java / Spring Boot / C# / .NET / React / TypeScript など（案件により異なる）

【勤務地】

求める人物像

これまで培ってきた金融・保険・流通・EC等の業務システム開発分野の強みに加え、
今後は、開発力にAWS・AIの技術を組み合わせ、
「AI × Application × AWS」
を新たな成長領域として事業を拡大します。

そのためには、AWS環境を構築できるだけではなく、
顧客課題を理解し、Architectureを描き、提案し、チームを動かせる人材が必要です。

今回の募集は、これから当社のAWS・AI事業をつくっていくための中核人材の募集です。

技術選定、AWSの標準化、サービス化、人材育成、案件創出など、事業そのものを一緒につくっていただきたいと考えています。
