仕事内容

本ポジションでは、モバイルアプリ開発のプレイヤーとして開発実務に関わりながら、事業・開発・組織をつなぐ推進役として、チーム全体を前に進めていただくことを期待しています。経営や事業の方向性を開発現場に接続し、優先順位の整理、設計方針の具体化、メンバー支援まで横断的に担っていただくポジションです。

あわせて、日々の開発や運用の中で見えてくる課題や改善余地に対しても、周囲と連携しながら提案・改善を進めていただきたいと考えています。新規開発だけでなく、既存機能の改善や技術的負債への対応も含め、継続的により良い開発体制・プロダクトをつくっていく役割です。

▼具体的な業務

  • 経営・事業方針やプロダクトの優先事項を踏まえ、モバイル開発における取り組みテーマや優先順位を整理する
  • PdMや関係部署と連携し、要件整理・実現方法の検討・開発観点での意思決定支援を行う
  • モバイルアプリの設計・実装方針を整理し、必要に応じて自らも実装に関わりながら、開発を円滑に進める
  • 日々の開発・運用の中で見えてくる課題や改善余地を捉え、提案・改善を進める
  • 既存機能の保守・改善、リファクタリング、技術的負債の解消を通じて、継続的な品質向上と開発しやすい状態づくりを行う
  • メンバーへの相談対応、レビュー、判断支援を通じて、チームの推進力を高める
  • 開発の進め方や関係者間のコミュニケーションを整理し、継続的に成果が出る体制づくりを行う

  • 開発言語：Swift

  • バックエンド：PHP
  • データベース：MySQL
  • インフラ / クラウド：AWS（EC2、RDS、S3、CloudFront、ALB、CloudWatch）、Firebase

  • ソースコード管理：GitHub
  • テスト / レビュー：テストケース・テスト仕様書を用いた検証、GitHub上でのコードレビュー
  • 監視：Firebase Crashlytics、CloudWatch
  • タスク管理：Asana
  • コミュニケーション：Slack
  • ドキュメント管理：Google Docs
  • 開発端末：MacBook支給、検証用iPhone / iPadあり
  • リリース運用：必要に応じて随時リリース

【仕事の魅力】

  • モバイルアプリが事業の中核にあるため、担当領域の重要度が非常に高いポジションです。
  • 単なるiOS実装担当ではなく、事業と開発をつなぎながら、優先順位整理や開発推進まで担っていただきます。
  • プレイヤーとして手を動かしつつ、リードや改善提案にも関われる点が魅力です。

■募集要項
モバイルアプリは、同社の事業において最も重要なプロダクト領域の一つです。今後の導入拡大やプロダクト成長を実現するためには、モバイル開発をより速く、より確実に前進させられる体制づくりが欠かせません。

現在のチームには開発を進めるメンバーは在籍している一方で、経営や事業の方向性を理解し、それを開発現場に接続しながら、設計・実装・推進・チーム運営を横断的に担う役割が不足しています。その結果、実現したい構想に対して判断や推進のハブが存在せず、スピード感を持って形にしきれない場面が生まれています。

今回の募集では、モバイルアプリ開発におけるプレイヤーでありながら、チームを前に進める推進役としても機能いただけるポジションです。高い専門技術を一点突破で発揮するというよりも、技術・推進・組織のバランスを持ち、関係者をつなぎながら事業成長に必要な開発を前進させていただける方をお迎えしたいと考えています。
