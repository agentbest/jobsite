仕事内容

■仕事概要
iPadを活用したSaaS型POSシステムを提供するユビレジで、「ユビレジ」「ユビレジ ハンディ」「ユビレジ 在庫管理」等のプロダクトのiPad・iPhoneアプリケーション開発を担当します。新規機能はSwiftUIをデフォルトとしつつ、既存のObjective-C / UIKitコードベースの段階的なモダン化やSwift 6 / Strict Concurrency対応を見据えたリアーキテクチャも推進します。

■仕事の詳細

  • 各サービスのiOS向けネイティブアプリケーションの開発（SwiftUI + UIKit）
  • デザイナーと協業してのUI設計、実装
  • バックエンドと連携したAPI設計
  • 既存 Objective-C / UIKit コードベースの Swift / SwiftUI への段階的なモダン化、リファクタリング
  • Swift 6 / Strict Concurrency 対応を見据えたリアーキテクチャ
  • AIコーディングエージェント（Claude Code, GitHub Copilot, Cursor 等）を活用した開発生産性の向上
  • 開発環境・CI/CDの改善

【入社後に求められる技術の例】

  • SwiftUIを中心としたUI実装と、既存UIKitコードとの相互運用（UIHostingController / UIViewRepresentable 等）
  • Swift Concurrency（async/await, Task, Actor, Sendable）を活用した非同期処理の設計・実装
  • App Store Review Guidelines、Apple Human Interface Guidelinesへの理解
  • AIエージェントを相棒として設計・実装・レビュー・テストを効率的に進める力

【開発環境】

  • 言語：Swift（メイン）／Objective-C（既存コード保守）
  • UI：SwiftUI（新規機能のデフォルト）／UIKit（既存機能・相互運用）
  • テスト：Swift Testing / XCTest
  • ライブラリ管理：Swift Package Manager, CocoaPods／Xcode（最新安定版）
  • CI/CD：Bitrise
  • その他：GitHub, Slack, esa, Google Workspace, Mixpanel, Firebase, Miro
