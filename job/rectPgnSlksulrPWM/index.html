仕事内容

■仕事概要
出張買取・店舗買取を中心にリユース事業を展開し、M&Aによるグループ拡大と複数プロダクト展開を進める同社のPlatform Engineering Teamにて、プロダクトセキュリティを中心にグループ全体のセキュリティ課題に取り組むポジションです。各プロダクトチームの個別対応にとどまらず、プロダクト横断で方針と優先順位を定め、開発プロセスの中で継続的に改善できる仕組みを構築します。AIエージェントを活用した開発やAIエージェント自体の開発に伴う新たな課題にも、先回りしてセキュリティを組み込むことが期待されています。

■仕事の詳細
【プロダクトセキュリティ戦略と脆弱性管理】

  • 事業とプロダクトの状況を踏まえたセキュリティ戦略およびロードマップの策定と推進
  • プロダクト・システム横断での脆弱性の把握、評価、優先順位付けから、改善計画の策定支援、実行状況の確認までを継続的に行う仕組みの構築

【開発プロセスとAIエージェントへのセキュリティの組み込み】

  • 設計段階のセキュリティレビュー、脅威モデリング、認証認可、データ保護に関する設計支援
  • SAST、SCA、シークレット検知などのツール選定とCI/CDへの組み込み、検出結果のトリアージ、例外管理、継続的な改善
  • AIエージェント活用・開発に向けた権限設計、データの取り扱い、安全性評価、操作ログと監査に関する基準の策定・導入支援

【事業全体のセキュリティ体制とインシデント対応】

  • 情報システム部門やグループ各社と連携した、IT資産とサービスの把握、セキュリティ基準の整備、改善活動の推進
  • 全社・各部門・グループ会社向けセキュリティ教育と啓発施策の企画・実施・改善
  • インシデントの監視・検知要件の整理、報告から初動、影響調査、復旧、再発防止までの対応手順の整備、訓練と振り返り
  • リスク・コンプライアンス部門が推進する全社リスク管理への技術面からの参画

【配属・体制】

  • PdM・SWE・データサイエンティスト・AIエンジニアなど100名規模の技術組織。1プロダクトあたり10人未満のチーム構成
  • 本部長（プロダクト責任者）や事業部、各プロダクト開発チーム、情報システム部門、リスク・コンプライアンス部門と連携
  • 仕様がトップダウンで降りることはなく、エンジニアが「なぜつくるか」を理解して開発。tech blogや外部登壇での発信を推奨

【キャリアパス】
まずは脆弱性管理や開発プロセスへのセキュリティ組み込みを開発チームとともに推進。その後、複数プロダクト共通の設計基準や中長期の技術方針の策定へと影響範囲を広げ、プロダクトセキュリティの技術判断をリードするキャリアを想定

【使用ツール・環境】

  • 言語：Golang, React.js（Next.js）, TypeScript
  • インフラ：GCP（Cloud Run, BigQuery, Cloud SQL等）, Terraform, Docker
  • CI/CD：GitHub Actions
  • テスト：MagicPod, Storybook
  • その他：GitHub, Sentry, NewRelic, Jira, Confluence, Elastic Cloud, Terraform Cloud, Chromatic

必須条件

  • アプリケーションセキュリティ・プロダクトセキュリティ領域での3年以上の実務経験
  • Web アプリケーションの開発経験（言語問わず）、またはSRE領域の業務経験
  • プロダクト開発チームのプロセスに入り込み、システムのセキュリティを向上させた経験
  • クラウドプラットフォーム（Google Cloud / AWS 等）のセキュリティに関する知識・実務経験

  • 脅威モデリング、セキュリティ設計の経験
  • 脆弱性診断・ペネトレーションテストの実務経験
  • コーポレートセキュリティ部門と連携したセキュリティガバナンス・リスク管理の運用経験
  • 技術ブログ執筆・カンファレンス登壇・コミュニティ運営などの技術発信の経験
  • セキュリティ関連資格（情報処理安全確保支援士 / OSCP / CISSP等）
