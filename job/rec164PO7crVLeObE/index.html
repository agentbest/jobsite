企業情報

株式会社ゼレンホールディングス（XELEN Holdings Inc.）は、2023年8月設立、東京都中央区八丁堀に本社を置く、テクノロジーサービスとコンサルティングを提供するゼレングループの持株会社。エンジニアリングテクノロジーと経営テクノロジーが世界を変える力を持つと信じるクリエイティブな才能が集まり、クライアント企業のビジネスを再定義し続けるためにコンサルティングとテクノロジーによる価値を提供、サステイナブルな成長の実現を支援する。事業環境の質的・非連続的・不可逆的な変化に対し、業界への知見とテクノロジーへの理解によって長期的な視野に立ちつつ、ダウンサイドまで見極める深い分析で企業固有の課題を解決するアプローチをとる。取締役CFO、執行役員CHROなどの経営体制を持つ。

大阪エリアを中心とした製造・流通・金融など様々な業界の企業に対し、ITインフラの上流工程から携わるポジションです。
要件定義・設計フェーズの技術的統括に加え、部門全体のマネジメント・組織運営を担っていただきます。将来的には大阪支社インフラ部門の本部長として、事業成長を牽引いただくことを期待しています。

■業務範囲

  • サーバー/ネットワーク/ストレージの設計書・構成図作成
  • Windows Server / Linux を中心としたサーバー構築、ネットワーク機器設定
  • SAN・NAS構築、バックアップ方式設計・DR計画策定
