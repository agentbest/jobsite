企業情報

燈株式会社（あかり、Akari Inc.）は、東京大学・松尾研究室発のAIスタートアップ。情報革命以降、日本企業の競争力は欧米・中国などに遅れを取り、現在GAFAM5社の時価総額の合計は日本の全上場企業の時価総額の合計を上回っているという課題意識のもと、「日本の大きな燈となり、AI技術を中心とするテクノロジーを用いて産業を照らし、全ての人々の希望の光となる」ことを目指し、AIを中心とする最先端テクノロジーで日本の産業をアップデートして日本一・世界一の企業へ（We are “Akari” that illuminates Japan.）を掲げ、挑戦において「志がすべて」（It's all about ambitious.）を大切にし、使命実現のための「燈道」を持つ。AIを中心とする最先端テクノロジーの技術開発（主要モジュール、フィジカルAI要素技術）を社内で行い、企業の課題を起点としたDXの推進を、現場と経営の双方の観点を取り入れた課題抽出から技術的なアプローチへのブレイクダウン、AI開発・導入までをパートナーとして行うDX Solution事業と、最先端テクノロジーをSaaSプロダクトという形で提供するAI SaaS事業（Digital Billderシリーズ：光/Hikari、工/Takumi、運/Hakobi、商/Akinai）によって行い、建設業をはじめとする産業の生産性向上を支援する。東光電気工事との「施工計画書作成サポートシステム」（過去の施工図面の効率的な検索と対話型AIによる施工計画書作成支援・一括出力）、ニトリとの「お部屋の写真deシミュレーション」（スマホ写真1枚で約2,500点の家具を数十秒で3D配置）、オリエンタル白石とのニューマチックケーソン工法「設備配置自動化ソフトウェア」（熟練技術者の暗黙知をふまえ安全で効率的な配置案を瞬時に複数作成）、清水建設との風力発電所建設アクセス道路ルート設定の自動化・最適化などを共同開発し、秋田の次世代モーターメーカー・アスターへ出資を通じ経営参画してフィジカルAIとものづくりの融合に挑む。

仕事内容

■仕事概要
創業5年で評価額1,000億円超の東大発AIスタートアップ燈のDX Solution事業本部で、産業用ロボットアーム・協働ロボット・四足歩行ロボットなどの多様な実機とドローンを動かす「AIモデルそのもの」を開発します。建設・製造現場から得られる実データと自社開発シミュレータを武器に、モデルの設計・学習・評価から実機への展開までを一気通貫で推進し、現場導入を見据えた研究開発と実運用からのデータフライホイールの構築を担います。

■仕事の詳細
【ロボット基盤モデル・ポリシーの開発】

  • 模倣学習（Imitation Learning / Diffusion Policy / ACT等）や強化学習を用いたマニピュレーション・移動ポリシーの学習
  • VLA（Vision-Language-Action）モデルやVLM等の事前学習済み基盤モデルの、現場タスクへのファインチューニング・蒸留・軽量化
  • 視覚・言語・点群・力覚など、マルチモーダル入力を扱うモデルアーキテクチャの設計
  • 世界モデル（World Models）や動画生成モデルの、学習データ生成・行動予測への応用

【データエンジンの構築】

  • 遠隔操作（テレオペレーション）・実機ログ・シミュレーションからの学習データ収集パイプラインの設計
  • Synthetic Data生成とDomain Randomization、データ品質評価によるデータセットの拡充
  • 現場運用で得られた失敗事例を学習に戻し、モデルを継続的に改善するフィードバックループの設計

【評価と実機展開】

  • シミュレーション／実機におけるベンチマーク設計と、汎化性能・安全性の評価
  • TensorRT等を用いたエッジ推論の最適化と、実機への組み込み（ロボティクス・制御エンジニアと協働）

【開発環境】

  • 社内GPUクラスタ（H200等、Kubernetesで構成）や多様な実機ロボット・センサー類を自由に利用可能
  • 協働ロボットとドローンを製品ラインナップに加え、モーターから組み込みソフトウェア、AIシステムまで垂直統合したドローン機体の自社開発にも着手

必須条件

  • 数理・深層学習の基礎知識：線形代数、確率統計、最適化の理解と、深層学習の理論的な理解
  • 実装能力：PythonおよびPyTorch（またはJAX）を用いた、深層学習モデルの構築・学習・評価の実務経験または研究経験
  • ロボット学習／マルチモーダルAIの経験：模倣学習、強化学習、VLA / VLM、3D・動画認識のいずれかにおけるモデル開発経験
  • 学習基盤：マルチGPUでの学習、データパイプラインの構築、実験管理の経験
  • 開発プロセス：Git / GitHubを用いたチーム開発、コンテナ技術（Docker）、CI/CDの利用経験

歓迎条件

  • PyTorch / JAX等のフレームワークを用いた深層学習モデルの構築・学習経験
  • Transformer（ViT）、Diffusion Models、LLM等の最新アーキテクチャのキャッチアップと応用経験
  • 物理シミュレータ（Isaac Sim, MuJoCo, PyBullet, Gazebo等）の活用経験
  • 強化学習（PPO, SAC等）やオフラインRLを用いたロボット制御の研究・開発実績
  • 産業用ロボットアーム／協働ロボット／ヒューマノイド（FANUC, DENSO, UR等）やドローンの制御経験
  • CUDA / TensorRT等を用いたエッジ推論の高速化・最適化
  • トップカンファレンス（ICRA, IROS, CVPR, CoRL, RSS等）への論文投稿・採択経験
  • Kaggle等のコンペティション上位入賞、またはロボコン等での優勝・入賞経験
