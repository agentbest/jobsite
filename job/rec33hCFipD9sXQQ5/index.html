企業情報

株式会社PoliPoliは、2018年2月設立、代表者・伊藤和真氏が率いる政策共創プラットフォームの企業。所在地は東京都千代田区平河町（MIDORI.so NAGATACHO）、資本金35,153,660円、従業員数48名（2026年1月時点、3ヶ月以上の業務委託契約者含む）。「新しい政治・行政の仕組みをつくりつづけることで、世界中の人々の幸せな暮らしに貢献する」をミッションに、「世界規模の政策プラットフォームをつくる」ことを掲げ、政治家・行政と市民をつなぐサービスや行政が市民の声を集めるための仕組みを開発・運営する。関心のある政策をもとに政治家や政党の応援、政策リクエストの活用、情報収集などができる政策共創プラットフォーム「PoliPoli」（政治家向け）、行政からの相談や意見募集テーマに意見を届けることで行政の政策をサポートできる「PoliPoli Gov」（省庁・自治体向け）、経営課題や事業課題の解決を政策立案・政策推進の文脈からサポートする「PoliPoli Enterprise」（企業・団体向け）を提供し、民間からの投資を呼び込みソーシャル・インパクト・ボンド（SIB）による成果報酬で官民連携による社会課題の解決を推進、民間や自治体における政策の実証実験をサポートする寄付基金、政治に関するあらゆる情報をわかりやすく発信する政治情報メディアも運営する。政策プラットフォームとして関わった政策をまとめた「政策共創事例集」を公開し、PwCコンサルティングと国会議員の立法・政策実務を支える環境を巡る現状と課題について共同研究を行う。

仕事内容

■仕事概要
政治家・行政・企業・市民向けのソフトウェアを開発し、分散した政策情報を統合する「政策プラットフォーム」の構築を目指す企業で、どのプロダクトからも同じ政策データを参照できるミドルウェアとしてのデータ基盤の設計・実装を牽引します。現状はプロダクトごとのデータ処理にとどまっており、収集から正規化・構造化・検索・配信までの各レイヤーを単一プロダクトの都合から切り離して設計し直す、データ基盤とバックエンドに軸足を置くポジションです。

■仕事の詳細

  • 法人向けプロダクトの政策データ基盤の設計・構築（優先順位の判断を含む）
  • 国会、政府機関、業界団体等、多方面にわたる政策データの収集基盤の設計・構築
  • 政策データの加工・分析基盤の設計・構築

【開発環境】

  • 共通：GitHub Actions / Sentry / Claude Code・Codex・CodeRabbit
  • 法人向けプロダクト：Python / FastAPI / GraphQL（Strawberry）/ SQLModel / PostgreSQL（Cloud SQL）/ Next.js + React / TanStack Router, TanStack Query / Vite / GCP（Cloud Run, Pub/Sub, Cloud Run Jobs）/ Terraform / Scrapy / Vertex AI（Gemini）
  • PoliPoli（政治家・政党向け）／PoliPoli Gov（行政向け）：TypeScript / Angular / Nx / Bun / Firebase（Firestore, Cloud Functions, Auth）/ Algolia / BigQuery

【開発スタイル】
実装からコードレビュー、検証まで開発プロセス全体にAIエージェントを取り入れ、開発ルールや業務知識をチームで共有しています。

【働き方】
永田町オフィスもしくは在宅。毎週金曜は全社員出社、それ以外は週2〜4日出社が目安。
