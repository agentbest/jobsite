仕事内容

■仕事概要
M&A・事業投資と内部統制の領域で、企業の意思決定と業務を支えるAIプロダクト「Aidiligence」（デューデリジェンス支援）と「Aispect」（J-SOX運用評価支援）を開発するシード期スタートアップで、両プロダクトの機能開発と、それらを支える共通基盤の設計・開発の中心を担うシニアエンジニアです。開発体制は代表とエンジニア1名の2名で、何をつくるかを考える段階から設計・実装・検証・リリースまで一貫して担います。

■仕事の詳細

  • フロントエンドからAPI・データベースまで、機能に必要な範囲の一貫した開発
  • 非構造データを読み取り、情報を集め、データ同士をつなぎ、企業・業務・リスクを分析して意思決定の材料へ変える共通基盤の設計・開発
  • 今後の採用を見据えた技術選定、品質基準、コードレビューなど開発組織の土台づくり

【主な技術的課題】

  • 契約書・財務資料・業務の証跡など形式も分量も異なる大量の文書を、実務で使える速さと品質で処理する（LLMの誤り・コンテキスト量・処理時間・コストを踏まえ、AIと既存技術の処理を組み合わせる）
  • 専門家の判断を含む業務をどこまでAIに任せるかの見極め（人が確認する範囲や出力品質の検証方法まで設計）
  • 2つのプロダクトで共通化する範囲の設計。機密性の高い情報を扱うため、データ経路・外部サービスに渡す範囲・アクセス権限まで含めて設計
  • 案件、根拠資料、統制、取引先、担当者など粒度の異なる企業データをつなぎ、分析結果の根拠をたどれるデータモデルと体験の設計

【チーム・開発の進め方】

  • 代表も日常的にコードを書き、事業の方向から実装の細部まで役割で線を引かずに議論
  • 週3日出社を基本に一部リモート可。隣の席で仕様や設計の迷いをその場で相談できる距離感
  • 人とAIの作業分担や成果物の検証方法、コードレビューを含め、開発の進め方自体も継続的に改善

必須条件

  • APIとデータベースの設計から実装、リリースまでを一人で担った実務経験（5年以上）
  • 仕様が固まっていない状態から、テーブル設計やインターフェースを自分で決めてきた方（言語は問いません）
  • フロントエンドとバックエンドの両方に手を入れ、機能をリリースまで一人称で持っていった経験
  • React（Next.js）で画面を実装した経験
  • 開発でのAIの実務経験
  • Claude Code や GitHub Copilot を日常的に使ってきた経験、またはAI・LLMをプロダクトに組み込んで設計・構築・運用してきた経験
  • スタートアップ、自社プロダクト、または少人数での0→1開発の経験

歓迎条件

  • AIエージェントを設計し、実際に動かして運用した経験
  • LLMの出力品質を、評価用のデータを使って測り、改善した経験
  • 大量の文書を扱うプロダクトの開発経験（検索や読み取りの精度を上げる工程を含む）
  • M&A、監査、内部統制、会計といった領域の知識、または専門職が使うプロダクトの開発経験
  • フロントエンドの状態管理の実務経験
  • Docker、Terraform、GitHub Actions を使った開発環境の構築経験
  • Figma を見ながらUIを実装した経験、または自分でプロトタイプを作った経験
  • Python / FastAPI / PostgreSQL / Azure の実務経験
  • 技術選定やコードレビューの仕組みづくりを主導した経験

求める人物像

  • 検証したい仮説に合わせて機能の範囲を絞り、品質と機密情報の取り扱いを確認したうえで、早く届けて改善できる方
  • 「これは作らない方がいい」と判断し、そう言える方
  • AIが出した結果を鵜呑みにせず、どこを人が確認すべきか考えられる方
  • AIに任せる範囲を自分で判断し、開発の進め方ごと変えていける方
  • 相談相手が少ない状況でも、自分で調べて前に進められる方
  • 事業の目的から考え、担当の外にも手を出せる方
  • 決まっていないことが多い状況を、面白がれる方
