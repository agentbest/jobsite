仕事内容

■仕事概要
アリーナ・ドーム・大型ライブなどのエンターテイメント空間をデザイン・設計・製作・施工まで一気通貫で手掛けるSENXYAにて、Technology領域の中心として、案件・見積・発注・在庫・機材・人工・原価・請求・経営管理を統合する業務・データ基盤「SENXYA DB」のProduct Ownershipを担い、AI Nativeな開発体制そのものを0→1でつくるポジションです。AI Coding Agent・LLM・Low-Code・Workflow Automationを組み合わせ、現場・AI・社内メンバー・外部専門家をつなぎながら開発プロジェクト全体を推進していただきます。SENXYA DBはSENXYA AI、Digital Twin、Physical AI / Roboticsへと発展させる構想です。

■仕事の詳細
【最初に取り組むこと】

  • Source Code / GitHub・Database Schema・Infrastructure / Cloud環境の把握
  • Data Dictionaryの整備、API / 認証まわりの整理
  • 未実装機能・Bug・Technical Debt・Security / Permission / RLS等の確認
  • Migration方法の検討、外部開発会社への依存関係の整理
  • 既存システム活用かSENXYA DB 2.0としての再構築かを含めた技術方針の整理（残す / 改善する / 捨てる / AIで作り直す）

【SENXYA DBのProduct Ownership】

  • 社内各部署へのヒアリング、業務フローの整理・再設計
  • Product Roadmap策定、Requirement / Specification作成、UI / UX設計、Data Model設計、開発優先順位の決定

【AI Native Development】

  • AI Coding Agentを利用した開発、LLMによる仕様作成、Prototype開発
  • Test生成・自動化、Documentation生成、Code Review、Workflow Automation

【Data Infrastructure】

  • 案件・顧客・見積・原価・機材・在庫・発注・人工・請求・粗利・施工などのデータをAIが利用できる形へ構造化

【SENXYA AI / AI Agent】

  • 見積AI・原価予測AI・発注Agent・在庫最適化Agent・施工計画AI・Knowledge Agent・経営分析AIなどの開発

【Digital Twin・Physical AI（将来）】

  • 3D・CAD / BIM・点群データ・Unreal Engine・Computer VisionとSENXYA DBの接続
  • Robot Forklift・AMR・墨出しRobot・Drone・ROS / ROS2・IoTなどへの展開

【使用ツール・環境（検討中）】

  • PostgreSQL / Supabase、GitHub、AI Coding Agent、n8n、LLM API、RAG等
  • 外部専門家はSecurity Review・Architecture Review・大規模Migration・障害対応などで活用

【キャリアパス】

  • AI Native Product Lead → Head of Technology → VP of Technology → CTOなどの役割を担う可能性あり

必須条件

すべてを満たす必要はありません。
以下のいずれかについて、実務経験またはそれに準ずる専門性をお持ちの方。

  • Web Application / Software Development、Backend / API Development
  • Database設計、業務システム開発
  • AI / LLMを利用したProduct Development
  • Product Management、Data Engineering、System Architecture

また、以下のような姿勢・経験を重視します。

  • ChatGPT、Claude、Codex等のAIを日常的に利用し、AI Codingを実際の開発に使っている
  • 新しいAI Toolを自ら試す習慣があり、「人がすべてコードを書く」ことを前提としていない
  • 0→1でPrototypeをつくれ、業務を理解してSoftwareへ落とし込める
  • 現場やユーザーと直接コミュニケーションでき、Businessまで理解しようとする
  • 「AIにコードを書かせること」と「AIを盲信すること」は違うと理解し、生成されたCode / SQL / ArchitectureをSecurity・Data Integrity・Maintainability・Reliabilityの観点から「本番環境で使ってよいのか」を判断できる技術的基礎がある

歓迎条件

以下すべての経験は必要ありません。
むしろ重視しているのは「知らないTechnologyでも、AIを使いながら短期間で理解し、試し、判断できること」です。

  • Python / TypeScript / JavaScript、PostgreSQL / Supabase、AWS / GCP / Azure、GitHub
  • LLM API（OpenAI / Anthropic / Gemini等）、AI Coding Agent、AI Native Development（Lovable / Replit / Cursor等）
  • Workflow Automation（n8n / Make等）、AI Agent、RAG、Vector Database、MCP
  • Authentication / Authorization、RLS、Database Migration、CI / CD、Security
  • Vertical SaaS、ERP / 業務基幹システム、製造DX・建設DX・Logistics Tech
  • Digital Twin、Unreal Engine、Computer Vision、Robotics、ROS / ROS2、IoT / PLC

求める人物像

■この仕事に向いている方

  • AIによってSoftware Developmentのあり方自体が変わると考えている
  • 1週間考えるより、1日でPrototypeをつくって試したい
  • SaaSを導入するだけでなく、自分たちの仕組みをつくりたい
  • BusinessとTechnologyの両方が好きで、現場・ユーザーの隣でつくりたい
  • 未完成な環境を楽しめ、自分で課題を見つけられる
  • AIを「検索ツール」ではなく「開発チームの一員」として使っている
  • 将来的にPhysical AI / Roboticsにも関わりたい

■この仕事に向かない可能性がある方

  • 完成した仕様書がないと開発を始められない
  • 担当領域以外の業務や、ユーザー・現場とのコミュニケーションに興味がない
  • コードを書くこと自体が仕事の目的になっている
  • AI Codingに否定的、またはほとんど利用していない
  • AIが生成したものを確認せず、そのまま本番投入する
  • 完成された開発組織を求めている
