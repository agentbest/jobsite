企業情報

弁護士ドットコム株式会社は、国内弁護士の67％が登録する日本最大級の弁護士・法律ポータルサイト「弁護士ドットコム」を運営する上場のリーガルテック企業。「人にやさしいサービスをつくる」ことを創業から続くオリジンとし、最新のテクノロジー×リーガルデータで「次の常識をつくる」ことを掲げる。「弁護士ドットコム」は無料で弁護士に法律相談ができるQ&Aサービスと、取扱分野や営業時間・支払い方法など様々な条件で弁護士を探せる弁護士検索を提供し、プレミアムサービスでは専門家の回答が見放題になる。日本で初めて主務官庁によって電子署名法上の「電子署名」に該当することが確認されたクラウド型電子署名サービス「クラウドサイン」は電子契約ツールベンダーシェア国内No.1（富士キメラ総研「ソフトウェアビジネス新市場2025年版」2024年度実績）で、グレーゾーン解消制度の活用や規制改革推進会議への参加などを通じてクラウド型電子契約の社会実装に大きく貢献したリーディングカンパニーであり、愛媛県今治市をはじめ多くの地方自治体に導入されている。統合型・法務AIエージェント「LegalBrain エージェント」など革新的なリーガルサービスを開発し、初のユーザーカンファレンス「弁護士ドットコム PARADIGM 2026」や「BUSINESS LAWYERS AWARD 2026」を開催。運営するニュースメディアは社会的話題の法律的論点を弁護士の解説とともに発信し、Yahoo!ニュース等にも配信される。

仕事内容

> 募集背景

導入社数が250万社を突破し、国内シェアNo.1のクラウドサイン®︎。エンタープライズ向けの機能拡充や行政のデジタル化支援など、市場からクラウドサインへのご期待が非常に高い状況です。

「取引AXプラットフォーム」への進化に向けたマルチプロダクト化に伴い、同時に走るプロジェクトの数も、関わるチーム・職能の数も増え続けています。一方で、プロジェクトの進め方はチームごとの経験や個人の頑張りに依存している部分が残っており、「今このプロジェクトがどういう状態にあるのか」がチーム内外から見えづらくなる場面も生じています。

そこで、開発チームの現場に入り込み、プロジェクトを確実に前進させながら、チームが自律的に改善サイクルを回せる状態へと導く Project Manager を募集します。

> ポジションについて

契約マネジメントプラットフォーム「クラウドサイン」における開発プロセスの設計・改善をお任せします。

Value Stream (プロジェクトの企画から開発・リリースまでの一連の流れ) をなめらかに接続し、プロダクトメンバー全員が「顧客への価値最大化」に集中できる環境を構築していただきます。仕組みと文化の両輪でアップデートをリードし、事業戦略の達成を牽引するポジションです。

  • 【二つの駆動エンジン】*

「各チームに伴走する現場支援」と「組織全体を支える中央基盤」の2軸で、クラウドサインのプロダクト組織をアップデートします。
なお、本ポジションでは、以下の駆動エンジンの内 ①現場駆動 を主軸とし、②中央駆動 はチームとの連携を通じて関与いただくことを想定しています。

  • ① 現場駆動（ボトムアップ・アプローチ / メイン領域）*

チームに深く入り込み、課題の直接的な解決から、チーム単独で改善サイクルを回せる状態（自律化）へと段階的に導きます。さらに、伴走支援を通じて得られた現場の成功事例を抽出し、組織全体の標準プロセスとして還元・横展開します。

  • ② 中央駆動：統制とスケール可能な基盤構築（トップダウン・アプローチ / 関与領域）*

「理想から逆算」した組織のグランドデザインの策定と、事業成長をさらに加速させる環境を構築します。

  • 全体最適・スケールアップ：

個別最適から一歩引き、「全体としていかに効果的に機能するか」を基準としたベストプラクティスを設計・浸透させ、組織のスケーラビリティを高めます。

  • ナレッジの資産化・SSoTの形成：

各現場の優れたナレッジを形式知へ変換し、組織全体で共有すべき「SSoT（信頼できる唯一の情報源）」として資産化。誰もが常に最新の手法へアクセスできる学習環境を構築します。

  • Trustの自動担保：

「標準的な開発プロセスに乗ってさえいれば、自動的に高レベルなTrust（ISMAP/SOC2等）が満たされる」仕組みを構築し、価値創造に没頭できるセキュアな環境を実現します。

自律的かつ非連続な成長を実現し、顧客に対して高水準のTrustと最大級のアウトカムを創出し続けるプロダクト組織を目指します。

Mission（日々の使命）
Value Stream上の「ボトルネック」や「属人化」を排除し、分断されがちなマネジメント・職能・チーム間を「仕組み」で繋ぎます。メンバーが価値創造に100%集中でき、事業の生命線であるTrust（信頼）が自然と担保される環境を創り出します。

求める人物像

  • 「あるべき論」を語るだけでなく、現場での「実行と完遂」できる方

評論家やアドバイザー的な立ち位置ではなく、当事者として現場のリアルなペイン（泥臭い課題）に寄り添い、自ら手を動かしながら「新しい仕組み」の定着まで伴走できる、強い実行力をお持ちの方。

  • 特定のフレームワークを目的化せず、「価値の最大化」から逆算できる方

スクラム等の特定の手法を教科書通りに導入することに固執せず、チームの状況やクラウドサインの既存の文化を尊重したうえで、その時々の最適解を柔軟に模索できる方。

自分がプロジェクトを回すことだけをゴールとせず、チームメンバーへのフィードバックやコーチングを通じて、最終的にチームが自走できる状態をつくることに喜びを感じる方。

  • 複雑な課題を構造化し、図解（ダイアグラム）を用いてステークホルダーを巻き込める方

事象を分析・整理するだけでなく、最適なダイアグラム（フローチャート、シーケンス図等）を活用して現状と理想を可視化し、異なる背景を持つ関係者間で目線を合わせながら解決へと導けるファシリテーション能力をお持ちの方。
