企業情報

株式会社ブリッジワン（Bridge One Co., Ltd.、旧社名：株式会社ビーバーズ）は、2020年3月設立、代表取締役・山本大輔氏が率いる建設・不動産・製造・士業・電気保安業界に特化した総合人材・総合コンサルティング企業。所在地は東京都渋谷区恵比寿（恵比寿ガーデンプレイスタワー21階）、資本金980万円（資本準備金480万円）、従業員数264人（2025年10月31日時点）。2025年9月にブリッジホールディングスを設立し商号を「ビーバーズ」から「ブリッジワン」に変更。「人の力で世界最高峰を再興する」をミッション、「世界で最も頂きを望む会社」を掲げ、あらゆる産業において挑戦の出発点となり人と人をつなぐ架け橋になることを使命とする。時代とともに企業が抱える課題は変化するが、効率や収益性以上に「人」が持つ力を最大限に引き出し熱中できる環境をつくることこそが未来を切り拓く原動力になると信じ、産業を支え伸ばしその繁栄に貢献し続けようとする「社会的基点」と、個人と組織の成長をどこまでも追い求める「野心的基点」が真正面から向き合った時にブリッジワンという橋が架かるとする。かつて世界を動かすモノを生み出してきた日本の、失われた30年の向こうにまだ諦めていない人たちのために共に橋を架けることを掲げ、前例のないイノベーションへの挑戦、すべての課題を「自分事」として捉える主体性、最速の行動と判断、「1秒1円」の価値最大化、妥協せずNo.1を目指すことをバリューとする。多様なソリューションを束ねた「ワンデスクソリューション」で企業の成長と人の可能性をともに広げ、顧問弁護士に森＆パートナーズ法律事務所、和田倉門法律事務所。有料職業紹介事業許可番号 13-ユ-312163、労働者派遣事業許可番号 派13-316300。

仕事内容

■仕事概要
クライアント企業の経営課題を解決する「ワンデスクソリューション事業」を展開するブリッジワンで、3月にスタートした社内システム開発プロジェクトの中核メンバーとして、要件定義から実装まで幅広く携わります。これまでkintoneで管理していた社内システムを内製化し、自社の成長を加速させる次世代社内システムを開発します。

■仕事の詳細

  • フロントエンド（React／Next.js）からバックエンド（Go）まで、領域を横断した開発
  • AIエージェント（Claude Code／Cursor）と協働しながら、仕様策定から実装・テストまでを一貫して推進
  • 必要に応じて周囲を巻き込みながら開発工程のディレクション

【配属・体制】

  • 少数精鋭のチームで、高い裁量を持って開発
  • 「No brilliant Jerks」をテーマに、個人の技術力よりもチームパフォーマンスの最大化を重視

必須条件

  • React / Go / TypeScript いずれかの実務経験
  • チーム開発での実務経験

歓迎条件

  • フロントエンドとバックエンドの両方の開発経験
  • RDBを用いたバックエンド開発経験
  • GCPを用いたインフラ構築の経験
  • 要件定義やプロジェクトマネジメントの経験
  • Claude Code / Cursor 等のAIツールを開発に活用した経験
  • リーダーシップを発揮し、チームを牽引できる方
  • 上記に当てはまらなくても、他のスキルや経験で補える方は歓迎します

求める人物像

  • 主体的に事業成長を担いたい方
  • 社内システム開発に情熱を持って取り組める方
  • 個人プレーよりもチームでの成果を大切にし、多様なバックグラウンドを持つメンバーと協力できる方
  • AIツールを積極的に取り入れ、開発生産性を追求したい方
  • フロント・バックエンドの垣根を越えて、フルスタックエンジニアとして成長したい方
