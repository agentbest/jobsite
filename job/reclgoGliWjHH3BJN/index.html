■具体的な業務内容
Trusted Execution Environment（TEE）を活用した秘密計算基盤のコアエンジン、ミドルウェア、アプリケーションの開発を担当していただきます。
Intel SGX や Intel TDX、AWS Nitro Enclaves などの Confidential Computing 技術を用いて、機密データやAIモデルを保護したまま安全に処理・共有・連携できるソフトウェア基盤を開発します。金融、化学、物流、エネルギーなど、機密性の高いデータを扱う業界において、データの安全な利活用、プライバシー保護AI、AIモデル共有、MLOps、鍵管理などを実現する共通プラットフォームの中核技術を担うポジションです。
Rust やC/C++ を用いて、TEE 上で動作するアプリケーション開発、例えば、リモートアテステーション、鍵管理、セキュア通信、データ暗号化・復号、機密データ処理機能などを実装していただきます。
主な担当業務は以下のとおりです。
安全性改善のための機能実装
TEE 上での処理性能・運用性改善
Confidential Computing 技術の研究開発およびプロダクト応用
■Job Description
You will be responsible for developing the core engine, middleware, and applications for a secure computation platform leveraging Trusted Execution Environments (TEEs).
Using Confidential Computing technologies such as Intel SGX, Intel TDX, and AWS Nitro Enclaves, you will develop a software platform that enables sensitive data and AI models to be processed, shared, and integrated securely while keeping them protected.
This position plays a key role in developing the core technology of a common platform for industries that handle highly sensitive data, such as finance, chemicals, logistics, and energy. The platform supports secure data utilization, privacy-preserving AI, AI model sharing, MLOps, key management, and related use cases.
You will develop applications that run inside TEEs using Rust and/or C/C++. Example areas include remote attestation, key management, secure communication, data encryption and decryption, and confidential data processing.
Your main responsibilities will include:
Implementing features to improve security
Improving processing performance and operational efficiency within TEEs
Conducting research and development on Confidential Computing technologies and applying them to products

Trusted Execution Environment (TEE) をはじめとする、Confidential Computing領域の先進技術を用いたプラットフォーム開発を経験できます。
C/C++、Rustを用いたプラットフォーム開発を通じて、低レイヤ領域の専門性を向上できます。
Intel SGX/Intel TDXなどを活用し、暗号・認証・鍵管理を支えるプラットフォームの設計・開発を経験できます。

暗号・AI分野の研究者、システムソフトウェアやWebプロダクトの開発経験を持つエンジニアが多数在籍しており、勉強会や技術共有の機会があります。
■What Makes This Position Attractive
You will gain experience developing platforms using advanced technologies in the Confidential Computing field, including Trusted Execution Environments (TEEs).
You will deepen your expertise in low-level software development through platform development using C/C++ and Rust.
You will gain hands-on experience designing and developing platforms that support encryption, authentication, and key management using technologies such as Intel SGX and Intel TDX.
You will have opportunities to stay up to date with the latest research trends by participating in conferences in the fields of cryptography and security, as well as opportunities to present at conferences and write academic papers.
You will work alongside researchers in cryptography and AI, as well as engineers with experience in system software and web product development. The environment provides opportunities for study sessions and technical knowledge sharing.
