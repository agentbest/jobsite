仕事内容

＜募集背景＞
当社の提供する自社B2B SaaS「MEO Dashboard byGMO」は、多機能化と多プロダクト化のフェーズに入り、日々の開発要望・不具合報告・機能追加依頼がかなりの量で寄せられています。
この一つひとつに優先度をつけ、要件に落とし込み、お客様をはじめ営業・CS・オフショアの開発パートナー間の利害を調整しながら、よりよいプロダクトへと育てていく。その実務の中心を担っていただきます。
AI活用の進む今、限られた人数でプロダクト開発を回す必要性は高まっており、AIを道具として使いこなすことが前提になりつつあります。PDCAを止めずにプロダクトを加速させる開発ディレクターを募集します。

■主な業務内容
MEO Dashboard byGMOに日々寄せられる要求・要望の取りまとめ、要件定義、プロジェクト・リリース管理、サポート業務に渡る、プロダクト開発の一連の実務を担っていただきます。

  • 日々寄せられる様々な開発要望・不具合・機能追加依頼の優先度判断と要件定義
  • 競合機能の調査と自社プロダクトとの比較
  • 機能改善の企画と、外部開発を通じた改善ディレクション
  • 機能利用データの可視化と、それを踏まえた改善企画
  • 関連部署やプロダクトを利用するお客様などステークホルダーとの折衝
  • 施策の優先度づけと、KPIに基づく効果検証
  • AIを用いた企画書および仕様書の作成
  • 日々のお問い合わせ対応（CSからエスカレーションされる挙動の仕様確認や不具合調査など）

■ポジションの魅力：
MEO Dashboard byGMO の開発ディレクションを、要件定義から外部開発の統括、リリースまで一貫して担えます。自分の判断が直接プロダクトの成長に関わります。
日々多くの要求が寄せられる中で、一つひとつをさばくだけでなく、開発の進め方そのものを見直し、より回りやすい形へ整えていくことにも関われます。
企画書や仕様書の作成をはじめ、AIを日常的に使いながら業務を進める環境です。

■就業環境：
必要な連携をしながら自律して仕事を進めるスタイルで、一人ひとりが担う範囲は広く、自分の裁量で働けます。
GMOグループのAI活用推進制度（AIブースト支援金等）により、AIツールを業務で使う環境が支援されています。
GMO Yours（社員食堂）やGMO Bears（託児所）など、GMOグループならではの福利厚生も利用できます。

■当社について
GMO TECH株式会社は、2006年12月の創業以来、GMOインターネットグループの一員として、インターネットを活用した集客支援事業を展開してまいりました。現在は「AIで未来を創る WebマーケティングDX」をビジョンに掲げ、店舗集客DX SaaS「MEO Dashboard byGMO」を中核としたAI・SaaS事業を推進しています。

必須条件

  • 自社プロダクトまたは受託開発において、要件定義〜リリースを自分で回した開発ディレクション経験

（単発ではなく、複数の案件・要望が同時並行で動く中で優先度をつけて捌いた経験）

  • 営業・CS・開発など立場の異なる関係者の間に立ち、 意見の対立を調整して意思決定を前に進めた経験
  • API・データベースの挙動を自分の言葉で説明でき、不具合の切り分けや簡単な仕様確認を、自分で行えるレベルのWeb実務理解
  • AIを日常業務に組み込み、調査・要件整理・文書作成などの進め方を、AIを前提に自分で作り替えている実績

歓迎条件

  • 0から1ではなく、1から100にプロダクトを大きくした経験
  • 日々発生する開発要望、不具合報告、仕様確認、問い合わせエスカレーションを整理し、事業インパクト、顧客影響、緊急度、開発工数、運用負荷を踏まえて対応方針を判断した経験
  • 曖昧な依頼や現場からの要望を、背景、目的、課題、仕様、画面挙動、データ条件、受け入れ条件、テスト観点まで具体化し、開発可能なチケットまたは仕様書に落とし込める方
  • 外部開発会社またはオフショア開発チームに対して、仕様説明、進行管理、レビュー、検収、不具合切り分け、再現確認、修正指示を行った経験
  • 生成AIを組み込んだプロダクト機能(RAG・チャットボット・LLMパイプライン等)の企画・開発経験
  • MCP(Model Context Protocol)やAIエージェントに関する知見
  • SQL・BigQuery等を用いたデータ分析の実務経験
