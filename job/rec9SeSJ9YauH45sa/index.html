事業紹介
「企業価値の中に、未来を見つける。」をミッション、「中小企業にテクノロジーを届けよう。」をバリューに掲げ、中小企業の経営支援のための事業を行っている会社です。
2018年にサービスを開始した経営支援SaaSプロダクトである「Big Advance」は、全国80の金融機関様を通じて約6万社の会員企業様にご利用いただいています。 (2025年4月現在)
■募集背景
これまで当社サービスのモバイルアプリは、スピード感を重視し他社サービスを活用して提供してきました。しかし、サービス規模の拡大に伴い、より高度なUXの実現や独自機能の開発が求められるようになり、完全内製によるネイティブアプリ（iOS／Android）へのリプレイスを進めてきました。
現在は主要機能の開発を終え、QA検証と改善を重ねながら、リリースに向けた最終段階にあります。リリース後は、多くのユーザーが日常的に使うアプリとして、安定した運用と機能拡張を進めていくフェーズに入ります。
アプリ開発はこれまで少人数体制で立ち上げてきたため、リリース後の運用・改善を中長期で担っていただける中心メンバーを募集します。リリース前後の重要な時期に参画いただき、現在の開発メンバーから引き継ぎを受けながら、自社のアプリを自ら育てていける、裁量の大きいポジションです。
■業務内容
『Big Advance』のモバイルアプリ（iOS/Android）の設計・開発・運用に関わっていただきます。
現在はリプレイスの初期フェーズであり、技術選定や開発プロセスの策定から裁量を持って取り組んでいただけます。
■具体的な業務

  • 自社サービスの iOS／Android アプリ（React Native／Expo）の設計・実装・機能追加
  • コンポーネント設計、状態管理、パフォーマンスチューニング
  • EAS Build／EAS Update を活用したビルド・配信、OTA 更新の運用
  • App Store Connect／Google Play Console でのリリース、審査対応
  • OS・ライブラリのバージョンアップへの追随（脆弱性対応を含む）
  • アプリと連携する Web の基幹システム側 API の設計・実装
  • Web 開発チームとの API 仕様の調整、プロダクトマネージャー・デザイナーとの仕様検討
  • 開発・運用ドキュメントの整備、および社内への技術共有
  • その他、スキルや経験に応じた業務
