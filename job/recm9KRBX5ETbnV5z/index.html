仕事内容

事業概要

チャネルトークは「企業と顧客の間にあるコミュニケーションの問題を解決する」をミッションに、顧客といつでもどこでも会話できる環境を作る「All in One AIメッセンジャー」を提供しています。CRMデータを元にした問い合わせ対応の設計やAIを通じた問い合わせ対応業務の自動化を通じて、CS効率化から顧客体験までチャネルトーク1つで解決します。現在は日本、韓国、アメリカで展開をしています。240,000以上の企業に利用されており、B2B企業の中では、アジアで最も早い水準で成長をしています。

なぜ募集するのか

チャネルトークのクライアントは日本企業・日本人担当者が圧倒的多数を占めています。これまでは韓国本社で培った仕様をそのまま日本に展開してきましたが、現場に向き合う中で、日本の顧客・商習慣にフィットした開発体制の必要性が見えてきました。今回、チームメンバーとともにアジャイル開発を推進し、日本仕様でのプロダクト開発にゼロから向き合えるプレイングマネージャーを募集します。Apps開発に加えて、大手パートナー企業と連携したマーケティング機能の開発も担っていただく予定です。将来的には開発チームの拡大に伴い、5名程度のメンバーをまとめるマネジメント役としての成長も見据えたポジションであり、日本における開発組織の土台を自らの手で作っていただける方を求めています。
■業務内容
チャネルトークの App Store / Commerce Protocol 上で、外部サービス連携アプリをオーナーシップを持って開発します。

  • 2名のチームメンバーとともに進めるアジャイル開発体制の中での、プレイングマネージャーとしての開発業務
  • 日本の顧客・商習慣に合わせたアプリケーションの開発・改善
  • パートナー企業と連携したマーケティング機能の開発
  • 韓国本社の仕様を日本向けに最適化するための開発方針の立案・実行
  • 将来的な開発チーム拡大を見据えたチームビルディング（将来的に5名程度のマネジメントを想定）

■このポジションの魅力

  • 日本仕様のプロダクト開発を、ゼロから自分の手で作り上げられる裁量の大きさ
  • 少数精鋭のメンバーと、距離の近いアジャイル開発を経験できる
  • Apps開発とマーケティング機能開発という2つの領域に横断的に関われる
  • チームの立ち上げから携わり、将来的にマネージャーとして組織を拡大していけるキャリアパス
  • 日本・韓国・アメリカで展開するグローバルB2B SaaSのコア機能に携われる
  • AIエージェントの能力拡張の最前線——作った連携が、そのままAIの自動対応範囲になる
  • 日本市場の立ち上げフェーズで、どのアプリを作るかから関われる大きな裁量
  • アプリを"量産"する仕組み（App Studio / App Factory）そのものの進化にも貢献可能
  • 23万社の実トラフィックが流れる環境で、コマース×AIのドメイン知識が深く身につく
  • 韓国本社のコアエンジニアリングチームと直接協働するグローバルな開発環境

  • 言語：TypeScript / Go
  • アプリ基盤：App Store、App Studio、App Factory、Commerce Protocol（Extension）、Open API、Custom Function
  • インフラ：AWS、Kubernetes、Docker、Pub/Sub・SQS、BigQuery
  • 連携方式：REST API、Webhook、OAuth 2.0、polling extension
