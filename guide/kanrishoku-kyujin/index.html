求人票の用語

「管理職」の求人と残業代｜管理監督者にあたるかは肩書きでなく実態で決まる

公開 2026-11-23　監修：株式会社エージェントベスト（有料職業紹介 13-ユ-316964）

「管理職」と書かれた求人でも、残業代が出ないとは限りません。労働基準法第41条で労働時間・休憩・休日の規定が外れるのは「管理監督者」にあたる人だけで、あたるかどうかは役職名ではなく、職務内容・責任と権限・勤務態様・賃金などの待遇の実態で判断されます。また、管理監督者であっても、深夜の割増賃金と年次有給休暇は一般の労働者と同じように扱われます。

この記事の制度の説明は、2026年11月時点の労働基準法と厚生労働省の資料にもとづいています。

社内の「管理職」と法律上の「管理監督者」は同じではない

労働基準法第41条第2号は、「監督若しくは管理の地位にある者」について、労働時間・休憩・休日に関する規定を適用しないと定めています。これがいわゆる管理監督者です。

厚生労働省のパンフレットでは、管理監督者を「労働条件の決定その他労務管理について経営者と一体的な立場にある者」と説明しています。そのうえで、企業の中で管理職とされていても、判断基準に照らして管理監督者にあたらない場合は、時間外割増賃金や休日割増賃金の支払いが必要になるとしています。

つまり、会社が「課長以上は管理職」と決めていることと、法律上の管理監督者にあたることは別の話です。同じパンフレットには、「課長」「リーダー」といった肩書きがあっても、自分の裁量で使える権限が少なく多くの事項で上司の決裁を仰ぐ人や、上司の命令を部下に伝えるだけの人は管理監督者とは言えない、と書かれています。

管理監督者かどうかを見る4つの視点

厚生労働省のパンフレットは、次の4つを総合的に見て判断するとしています。

視点パンフレットでの説明（要旨）求人を読むときの着眼点
職務内容労働時間などの規制の枠を超えて活動せざるを得ない重要な職務を持っている経営や組織運営の判断にどこまで関わるか
責任と権限経営者から重要な責任と権限を委ねられている採用・評価・部下の勤務管理を自分で決められるか
勤務態様時を選ばず経営上の判断や対応を求められ、労働時間を厳格に管理されていない出退勤の時刻が決められ、遅刻や早退で不利益があるか
賃金等の待遇定期給与・賞与などで一般の労働者と比べて相応の待遇がある基本給や役職手当が、残業代がなくなる分に見合っているか

チェーン店の店長について示された判断要素では、アルバイトなどの採用や解雇、部下の人事考課、勤務割表の作成に実質的に関わっていないことが、管理監督者性を否定する重要な要素とされています。長時間働いた結果、時間単価に直すとアルバイトなどの賃金に満たない場合も同じです。業種は違っても、「肩書きに見合う権限と待遇が実際にあるか」という考え方は共通しています。

管理監督者にも適用されるルール

管理監督者に適用されないのは、労働時間・休憩・休日の規定です。そのため、法定時間外の割増賃金や法定休日の割増賃金は発生しません。一方で、次のルールは管理監督者にも適用されます。

  • 深夜の割増賃金：午後10時から午前5時までの労働には、2割5分以上の割増賃金が必要です（労働基準法第37条）。厚生労働省のパンフレットにも、管理監督者であっても深夜業（22時から翌日5時まで）の割増賃金は支払う必要があると書かれています
  • 年次有給休暇：一般の労働者と同様に与える必要があります
  • 健康への配慮：パンフレットは、管理監督者についても長時間の過重な労働にならないよう求め、長時間労働となった場合には医師による面接指導などの措置が必要になる場合があるとしています

このため、管理監督者として扱われる人でも、深夜割増の支払いや健康管理のために労働時間を把握されることはあります。パンフレットでは、こうした目的で労働時間を把握・管理されていることは、管理監督者性を否定する要素にはならないとされています。

似た言葉との違い

管理職の求人では、管理監督者と混同しやすい言葉がいくつか出てきます。どれも残業代の扱いに関わるので、分けて読みます。

言葉中身残業代との関係
管理監督者労働基準法第41条で労働時間・休憩・休日の規定が適用されない人法定時間外・法定休日の割増はなし。深夜割増はあり
固定残業代一定時間分の時間外手当を定額で払う仕組み決められた時間を超えた分は別に支払いが必要
裁量労働制対象業務について、決めた時間働いたものとみなす制度残業代の扱いは、みなし時間など制度の内容による。管理監督者とは別の制度
労働組合法の「監督的地位にある労働者」労働組合に入れない立場の人労働基準法の管理監督者とは別の判断

最後の点について、厚生労働省のパンフレットは、人事・労務の機密に接する上級職員などが労働組合法では非組合員になる場合でも、自ら労務管理を行う権限がない、勤務時間を厳格に制限されている、ふさわしい待遇がないといった場合には、労働基準法の管理監督者にはあたらないと説明しています。「組合を抜けたから管理監督者」とはならない、ということです。裁量労働制の求人については裁量労働制の求人で確認したいことで整理しています。

求人票の書かれ方から読み取れること

管理職の求人票では、残業代について次のような書き方が見られます。

  • 「管理監督者のため時間外手当の支給なし」
  • 「役職手当を支給（時間外手当は支給対象外）」
  • 「固定残業代◯時間分を含む」

最初の2つは、会社がそのポジションを管理監督者として扱う前提で書かれています。ただし、その扱いが法律上の判断と一致するかどうかは、入社後の実際の権限や勤務の仕方で決まります。3つ目のように固定残業代が書かれていれば、時間外の割増賃金を払う前提の給与設計と読めます。固定残業代の読み方はみなし残業（固定残業代）の求人の読み方、役職手当との関係は役職手当と残業代の関係で整理しています。

「管理職候補」「マネージャー候補」と書かれた求人は、入社の時点では管理職でないことを前提にした書き方です。入社時の役職と、昇格の時期や条件、昇格したあとに残業代の扱いが変わるのかを分けて確かめておくと、年収の見通しを立てやすくなります。

なお、求人を出す会社には、職業安定法にもとづいて「所定労働時間を超える労働の有無」を求職者に示すことが求められています。管理職の求人でも、残業があるかどうか自体は求人票で読み取れるはずです。読み取れない場合は、残業の有無と、その時間が割増賃金の対象になるかを分けて確かめます。

年収の幅が広い管理職求人では、提示額が役職や権限の大きさに応じて決まることもあります。年収を比べるときは、残業代が出る求人と出ない求人とで、総額の意味が違う点に注意します。年俸制の求人なら年俸制の求人で確認したいこともあわせてご覧ください。

エージェントベストの見解

求人をご紹介する中では、同じ「マネージャー」という職種名でも、部下の人数、採用や評価にどこまで関わるか、勤怠をどう管理されるかが会社ごとに大きく違う様子をよく見ます。求人票に書かれていない役割の範囲や、そのポジションを管理監督者として扱うかどうかは、ご質問いただければ企業に確認できます。

面接・内定で確かめたいこと

管理職の求人では、次の点を順に確かめておくと、入社後の食い違いを防ぎやすくなります。

  1. 管理監督者として扱うポジションか：時間外手当・休日手当の対象かどうか
  2. 権限の範囲：部下の人数、採用・評価・勤務管理に自分で決められることがどこまであるか
  3. 出退勤の管理：始業・終業の時刻の決まり、遅刻や早退の扱い
  4. 待遇の内訳：基本給と役職手当の額、賞与の決まり方
  5. 深夜労働の扱い：深夜に働いた場合の割増賃金の支払い方
  6. 書面の記載：労働条件通知書で、所定時間外労働の有無や割増賃金率がどう書かれているか

残業代の話は聞きにくいと感じる方もいますが、「入社後の役割と権限を正しく理解したい」という聞き方にすれば、条件の確認として自然に尋ねられます。権限の範囲と待遇はセットで決まるものなので、片方だけでなく両方を聞くのがポイントです。

マネジメント経験を求める書き方の読み方は求人票の「マネジメント経験」の読み方、内定時の書面の見方は労働条件通知書で確認する項目の一覧で整理しています。

入社後に扱いへ疑問を感じたら

管理監督者にあたるかどうかは、個々のケースごとに実態から総合的に判断されます。厚生労働省のパンフレットには、店長やマネージャーなどについて管理監督者にあたらないとされた民事の裁判例がいくつも紹介されています。管理監督者にあたらないのに時間外・深夜の割増賃金を払っていなかったとして、労働基準法第37条違反で罰金刑となった刑事の裁判例があることも書かれています。

入社後、実際には権限がほとんどなく勤務時間も細かく管理されているのに残業代が出ない、といった疑問があるときは、勤務記録や給与明細を手元に残したうえで、労働基準監督署や社会保険労務士などにご相談ください。

エージェントベストの見解

管理職のポジションは、役割の範囲が求人票だけでは読み切れないことが多い求人です。サイトに載せていない求人もあるので、マネジメントの人数や裁量の大きさについての希望を伺ったうえで、掲載外の求人も含めて個別にお探しできます。面談はオンラインまたは電話で受けています。

よくある質問

課長に昇進すると残業代は出なくなりますか？

課長という役職だけで残業代がなくなるわけではありません。労働基準法上の管理監督者にあたるかどうかは、職務内容・責任と権限・勤務態様・待遇の実態で判断されます。管理監督者にあたらなければ、法定時間外や法定休日の労働には割増賃金が必要です。

管理監督者でも深夜に働いたら割増賃金はもらえますか？

もらえます。午後10時から午前5時までの深夜労働の割増賃金は、管理監督者にも支払う必要があると厚生労働省のパンフレットに書かれています。年次有給休暇も一般の労働者と同じように与えられます。

管理職の求人で残業代の記載がないときはどうすればよいですか？

そのポジションを管理監督者として扱うのか、時間外手当の対象なのかを、面接か内定時に確かめます。あわせて、深夜労働の扱いと、役職手当・基本給の額を聞いておくと比べやすくなります。最終的な条件は労働条件通知書でも必ずご確認ください。

あわせて読みたい

求人票の用語

みなし残業（固定残業代）の求人の読み方｜何時間分か・超えた分はどうなるか

固定残業代の求人は「何時間分でいくらか」「それを除いた基本給」「超えた分を追加で払う旨」の3点で読みます。決められた時間を超えた残業には割増賃金が別に支払われます。2026年11月時点の制度で整理しました。

求人票の用語

年俸制の求人で確認したいこと｜残業代・賞与の扱いと毎月の支払われ方

年俸制の求人は、年俸に賞与や残業代が含まれるか、毎月いくら払われるか、翌年の年俸の決め方を確認します。年俸制でも賃金は毎月1回以上払われ、原則として残業代も出ます。2026年11月時点の制度で整理しました。

求人票の用語

業務委託の求人と雇用の求人の違い｜労働者性・社会保険・税金の考え方

業務委託の求人は雇用ではなく、事業者として仕事を受ける契約の募集です。労働基準法や会社の社会保険は前提になりませんが、実態が労働者なら労働基準法が適用されます。2024年11月施行のフリーランス法も整理します。

求人票の用語

業務内容の「変更の範囲」の読み方｜職種が変わる可能性を求人票で知る

業務の「変更の範囲」は、入社後に配置転換などで担当しうる仕事の範囲です。「会社の定める業務」なら職種が変わる可能性があり、「変更なし」なら同じ仕事が続く見込みです。書かれ方の型と確かめ方を2026年11月時点で整理しました。

求人票の用語

求人票に書くことが決まっている項目｜職業安定法の労働条件明示のルール

求人を出す会社や職業紹介事業者は、業務内容・契約期間・就業場所・労働時間・賃金・加入保険などを求職者に示す義務があります。2024年4月に加わった3項目と、書かれていないときの確かめ方を整理します。

求人票の用語

無期転換ルールと求人票｜有期契約の求人で更新上限と転換後の条件を読む

無期転換ルールは、同じ会社との有期契約が通算5年を超えると、本人の申込みで期間の定めのない契約に変わる仕組みです。有期の求人では更新上限と無期転換後の条件を確かめます。2026年11月時点で整理しました。
