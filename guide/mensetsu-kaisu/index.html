中途採用の面接は何回あるか｜一次・二次・最終の段階ごとに見られること

公開 2026-11-23　監修：株式会社エージェントベスト（有料職業紹介 13-ユ-316964）

中途採用の面接は、求人票では「面接2〜3回」と書かれていることが多く、1回で終わる会社や、それより多く重ねる会社もあります。回数よりも大事なのは、段階ごとに面接官が変わり、見られることが変わる点です。一次面接は実務の経験、二次面接は役割やチームとの相性、最終面接は会社の方針との合い方と入社の意思が中心になります。

求人票の選考欄はどう書かれているか

求人票の「選考プロセス」や「選考フロー」の欄には、選考のステップが書かれています。書き方は会社によってさまざまですが、よく見る形は次のようなものです。

  • 書類選考 → 面接（2〜3回）→ 内定
  • 書類選考 → 一次面接 → 適性検査 → 最終面接 → 内定
  • 書類選考 → 面接（1〜複数回）→ 内定
  • 書類選考 →（カジュアル面談）→ 一次面接 → 二次面接 → 最終面接 → 内定

面接の回数を幅で書いている会社が多いのは、応募するポジションや候補者の経験によって、回数を変えることがあるためです。「面接回数は状況に応じて変わる場合がある」と添えている求人もよく見ます。選考欄が空欄の求人も少なくありません。

また、面接以外のステップが入ることもあります。

ステップ中身
適性検査性格や能力をはかる検査。オンラインで受けることが多い
課題選考実務に近い課題に取り組み、提出や発表をする
リファレンスチェック前の職場の上司や同僚に、働きぶりを聞く
録画面接質問に答える様子を録画し、あとで面接官が見る
オファー面談内定後に条件や役割を説明する場。選考ではないことが多い

適性検査の位置は、書類選考の前、面接の間、最終面接の前など、会社によって違います。合否に使わず、面接の参考にするだけと書いている会社もあります。準備の考え方は適性検査・筆記試験がある選考の準備にまとめています。

段階ごとに面接官と見られることが変わる

面接の回数が複数あるのは、それぞれの段階で、違う立場の人が違う観点で見ているからです。一般的な分担は次のとおりです。

段階面接官になりやすい人中心になる観点
一次面接人事、配属先の現場の担当者これまでの経験が求人の仕事に合うか
二次面接配属先の管理職、部門の責任者役割を任せられるか、チームと合うか
最終面接役員、社長会社の方針と合うか、入社の意思があるか

面接が2回の会社では、一次と二次の役割がまとめられ、最終面接で役員が見る形が多くなります。面接が1回の会社では、現場の責任者と役員が同席して一度に見ることもあります。逆に回数が多い会社では、別の部署の人がカルチャーの相性を見る面接が加わることもあります。

この分担はあくまで一般的な傾向で、会社によって違います。人事が最初から最後まで同席する会社もあれば、一次から役員が出てくる会社もあります。社員の少ない会社では、早い段階から経営に近い人が面接に出てくることもあります。

面接の形も段階によって変わることがあります。一次・二次はオンライン、最終面接だけは対面、という組み方は求人票でもよく見ます。対面の段階では移動の時間も要るので、在職中の人は休みの取り方も含めて予定を立てておきます。

一次面接で見られること

一次面接は、書類に書かれた経験を、言葉で確かめる場です。面接官は、職務経歴書の内容が求人の仕事にどうつながるかを知りたいと考えています。

  • どんな仕事を、どのくらいの範囲で担当してきたか
  • 成果を出すために何をしたか
  • 求人票の必須要件に関わる経験の中身
  • 転職を考えた理由

一次面接は、現場の担当者が面接官になることが多いため、仕事の中身について具体的な質問が出やすい段階です。こちらからも、求人票の仕事内容のうち分からないところを確かめるよい機会になります。詳しくは一次面接で見られることにまとめています。

二次面接で見られること

二次面接は、入社後に一緒に働く上司になりそうな人が面接官になることが多い段階です。経験の確認から一歩進んで、「この人に役割を任せられるか」を見ています。

  • 求人のポジションで期待する役割を担えるか
  • チームの中でどう動くか、周りとどう関わるか
  • 仕事の進め方や考え方が、チームと合うか
  • 入社後に伸ばしてほしい部分があるか

こちらにとっては、配属先のチームの様子や、上司になる人の考え方を知る場です。評価のされ方や、入社後に最初に任される仕事を聞いておくと、入社後の姿が具体的になります。詳しくは二次面接で見られることにまとめています。

最終面接で見られること

最終面接は、役員や社長が面接官になることが多い段階です。経験や能力はそれまでの面接で確かめられているため、会社の方針との合い方や、入社の意思が中心になります。

  • 会社の事業の方向性と、本人がやりたいことが合うか
  • 長く働く見通しがあるか
  • 内定を出したら入社してもらえそうか
  • 入社できる時期

最終面接で、希望年収や入社可能時期、他社の選考状況を聞かれることもよくあります。内定を出す前の確認として聞かれるので、答えをあらかじめ整理しておきます。詳しくは最終面接で見られることにまとめています。

エージェントベストの見解

当社が企業から求人をお預かりする中でよく見るのは、面接の回数が同じでも、各段階で誰が面接官になるかは会社によってかなり違う、ということです。求人票に「面接2回」とだけ書かれていて、面接官の立場や面接の進め方までは分からないことも多くあります。当社経由で応募された求人で、次の面接で誰が出てくるのか、どのくらいの時間かといった点は、ご質問いただければ企業に確認できます。

回数が多いか少ないかで判断しない

面接の回数が多いと、「選考が厳しい会社」「時間がかかる会社」と感じるかもしれません。回数が少ないと、「すぐに決まりそう」と感じるかもしれません。どちらも、回数だけでは判断できません。

回数が多い会社は、複数の立場の人と話す機会がある、ということでもあります。入社前に、上司になる人や一緒に働く人の話を聞けるのは、こちらにとっても判断の材料が増えることになります。

回数が少ない会社は、選考が早く進む一方で、会社のことを知る機会が少なくなりがちです。面接で聞けなかったことは、内定後のオファー面談などで確かめます。早く進む選考で確かめたいことは選考が早く進むときに確認したいことにまとめています。

面接の回数は、選考にかかる期間にも関わります。面接が1回増えるごとに、日程の調整と結果の連絡を待つ時間が加わるからです。期間の見通しは選考期間はどのくらいかにまとめています。

段階ごとに準備の重心を変える

面接が複数回ある場合、毎回同じ準備をするより、段階に合わせて重心を変えるほうが効率的です。

段階準備の重心
一次面接の前職務経歴を具体的に話せるようにする。求人票の仕事内容と自分の経験の重なりを整理する
二次面接の前一次面接で聞かれたこと・答えたことを振り返る。チームや役割について聞きたいことを用意する
最終面接の前会社の事業の方向性を調べ直す。希望年収・入社可能時期・他社の状況の答えをそろえる

面接官は、前の段階の面接の記録を見たうえで次の面接に臨むことが多くあります。前の面接で話した内容と、次の面接で話す内容が食い違わないよう、面接が終わるたびに、聞かれたことと答えたことを書き残しておきます。

面接と面接の間にすること

面接が終わってから次の面接までの間にも、やっておくことがあります。

  1. 聞かれたこと・答えたこと・聞けなかったことを書き残す
  2. 面接で分かった仕事内容や条件を、求人票と照らし合わせる
  3. 志望度を見直し、次の面接に進むかを判断する
  4. 次の面接で確かめたいことを書き出す

面接を受けるたびに、会社について分かることが増えていきます。分かったことを書き残しておけば、最終面接や内定後の判断のときに、印象ではなく中身で比べられます。振り返りの進め方は面接の後にすることにまとめています。

面接で聞かれることの範囲

面接では、仕事に関わる経験や考え方が聞かれます。厚生労働省は「公正な採用選考の基本」で、採用選考は応募者の適性・能力に基づいた基準で行うこと、適性と能力に関係のない事項を尋ねないよう留意することを示しています。本籍や出生地、家族の職業、宗教や支持政党などは、就職差別につながるおそれのある事項として挙げられています。

面接の段階が進んでも、この考え方は変わりません。答えにくい質問をされたときの考え方は面接で聞いてはいけない質問とはにまとめています。

回数が途中で変わるとき

選考の途中で、面接の回数が変わることがあります。

  • 予定になかった面接が追加される
  • 二次面接と最終面接がまとめられる
  • 別のポジションでの面接を提案される

面接が追加される理由は、もう少し話を聞きたい点がある、別の部署の人にも会ってほしい、などさまざまです。追加されたこと自体を悪い知らせと受け取る必要はありません。気になる場合は、追加の面接で何を確かめたいのかを聞いておくと、準備がしやすくなります。

エージェントベストの見解

選考の回数や進み方は、同じ会社でもポジションや時期によって変わることがあります。求人票の選考欄は目安として読み、実際の流れは応募後に確かめるのがおすすめです。当社経由での応募はお申し込み（無料）のうえ、当社から企業へ推薦する形で選考が進みますので、選考の途中で流れが変わったときも、気になる点があればご質問ください。企業に確認できます。

よくある質問

面接が1回だけの会社は、選考が甘いのでしょうか

そうとは限りません。1回の面接に現場の責任者と役員が同席して、まとめて判断する会社もあります。回数が少ない分、1回で聞かれる範囲が広くなることもあるので、準備は丁寧にしておきます。

最終面接まで進めば、内定はほぼ決まりですか

最終面接で見送られることもあります。最終面接では、会社の方針との合い方や入社の意思が見られるため、それまでの面接とは別の観点で判断されます。最後まで準備をして臨んでください。

面接の回数は、応募前に確かめられますか

求人票の選考欄に書かれていることが多いですが、幅があったり空欄だったりする求人もあります。書かれていない場合は、応募の前後で確かめてください。書類選考の通過の連絡と一緒に、選考の流れが案内されることもあります。

参考にした公的情報・資料

  • 公正な採用選考の基本（厚生労働省）

記事の内容は公開日時点の情報にもとづきます。制度は変わることがあるため、手続きの前に各機関の最新情報をご確認ください。

求人票だけでは分からないことを、面談でお伝えします

同じ職種名でも、企業ごとに仕事の範囲や求める経験は違います。希望を送っていただければ、掲載外の求人も含めて個別にお探しします。ご利用は無料です。

選考の進み方

適性検査・筆記試験がある選考の準備｜形式の確かめ方と当日までにすること

適性検査や筆記試験がある選考では、まず検査の種類・受け方・期限を案内で確かめ、能力を測る検査は問題の形式と時間配分に慣れておき、性格を見る検査は正直に答えるのが準備の基本です。受検の段取りと注意点を整理します。

選考の進み方

選考期間はどのくらいか｜応募から内定までの目安と長くなる理由、待ち方

応募から内定までの選考期間は、会社や面接の回数、日程の合わせやすさで大きく変わり、決まった長さはありません。段階ごとにかかる時間を分けて見通しを立て、目安は応募先に確かめるのが確かな方法です。長くなる理由と待ち方も整理します。

選考の進み方

カジュアル面談と面接の違い｜選考との関係・準備・聞いてよいことを整理する

カジュアル面談は、会社と候補者がお互いを知るための場で、合否を決める面接とは目的が違います。ただし会社によって選考との関係はさまざまです。位置づけを確かめ、経歴の短い説明と聞きたいことを用意して臨むのが基本です。

選考の進み方

課題選考・ワークサンプルがある求人の進め方｜案内で確かめることと提出まで

課題選考の案内を受けたら、期限と想定時間、提出形式、評価の観点、使ってよい資料やツール、成果物の扱いを最初に確かめます。そのうえで求人票の仕事内容と結びつけて取り組むのが進め方の基本です。準備から提出、発表までを整理します。
