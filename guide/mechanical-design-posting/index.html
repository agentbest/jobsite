機械設計の求人票の読み方｜設計の対象と段階・設計以外の仕事で確かめたいこと

機械設計の求人票は、「量産する製品を設計するのか、工場で使う設備や装置を設計するのか」「構想設計から製図までのどの段階を担当するのか」「解析・試作・部品の手配・組立・現地での立ち上げなど、設計以外の仕事をどこまで持つのか」の3点で読むと、仕事の中身が見えてきます。同じ「機械設計」でも、図面を描く時間が長い仕事と、仕様を決めて社内外と調整する時間が長い仕事では、求められる経験がまったく違います。この記事では、求人票のどこから何を拾えばよいかを順に整理します。

設計の対象：製品か、設備・装置か

機械設計の求人は、何を設計するかで大きく2つに分かれます。仕事内容の最初に出てくる製品名や事業の説明で見分けられます。

設計の対象求人によく出る言葉仕事の特徴
量産する製品自動車部品、家電、医療機器、ロボット、モビリティ、筐体、量産化同じものを多く作るため、コスト・組立のしやすさ・品質のばらつきが重い
生産設備・装置搬送装置、自動化ライン、検査装置、半導体製造装置、受注設計顧客ごとに仕様が違う一品物が多く、仕様決めから現地での立ち上げまで続く
治具・金型・設備の部品治具設計、金型、設備の改造製造の現場に近く、短い期間で形にすることが多い

製品の設計では、「量産を前提にしたコストや組立のしやすさの検討」のように、試作から量産へ移る段階の仕事が書かれることがあります。装置の設計では、仕様の検討から設計、部品の購入、組立、納品先での立ち上げまでを並べて、1つの案件を最初から最後まで持つ書き方がよく見られます。装置設計の求人は産業機械・装置設計の求人の読み方、製品分野ごとの違いは機械設計の求人の製品分野の読み方で扱っています。

設計の段階：構想・基本・詳細・製図のどこを持つか

機械設計の仕事は、おおまかに次の段階に分かれます。

  1. 構想設計：製品や装置の仕様をもとに、全体の構成や機構を考える
  2. 基本設計・計画設計：構成を具体化し、主要な部品の寸法や強度、機構の動きを決める
  3. 詳細設計：部品ひとつひとつの形状、材料、加工方法、公差を決める
  4. 製図：3D CADでのモデル作成や、2Dの図面への展開

段階の呼び方は会社によって少しずつ違います。参考として、一般社団法人日本機械設計工業会が実施する機械設計技術者試験では、1級の対象を「基本設計業務ができる技術者」、2級を基本設計をもとに機能・構造・機構を具体化する「計画設計業務ができる技術者」、3級を「詳細設計の補佐や関連製図などの業務ができる技術者」と位置づけています（2026年11月時点・同会のサイトで確認）。

求人票では、「構想設計から一連の開発工程」とあれば上流から関わる仕事です。「設計補助」「既存品の改良設計・修正設計」「図面作成」が中心なら、詳細設計と製図の比重が高い仕事です。「経験に応じた工程から入り、慣れたら一連の工程を持つ」という書き方は、入社直後は一部の段階から入り、範囲を広げていく想定を示しています。段階ごとの違いは構想設計と詳細設計の求人の違いで詳しく扱っています。

設計以外の仕事をどこまで持つか

機械設計の求人では、設計そのもの以外の仕事が仕事内容に並ぶことがよくあります。どれが含まれるかで、1日の時間の使い方が変わります。

  • 解析：強度・熱・振動・流体などのシミュレーション（CAE）。専任の解析担当がいる会社もある
  • 試作と評価：試作品の手配と組立、評価試験、不具合の原因調査と対策
  • 部品の手配と外注の管理：部品の購入、加工を頼む会社への発注、納期の管理
  • 組立と現地での立ち上げ：装置を組み立て、納品先で据え付けて調整する。出張や現場作業を伴う
  • 量産に向けた社内外との調整：製造を担う工場や外部の会社、海外の部品メーカーとの仕様のすり合わせ
  • 品質と文書：技術文書、製造仕様書、設計変更の管理、品質保証部門とのやり取り

装置の設計の求人で「組立」「納品立ち上げ」が仕事内容にあり、必須要件に普通自動車免許が書かれていれば、現場に出る時間がある仕事と考えられます。解析の比重が大きい求人はCAE・解析の求人の読み方も参考にしてください。

エージェントベストの見解

求人をご紹介する中でよく見るのは、機械設計の求人で、設計そのものと、試作・組立・現地対応などの周辺の仕事の割合が会社ごとに大きく違うことです。図面に向かう時間と、現場や社外とのやり取りの時間がどれくらいの割合か、出張がどのくらいあるかは求人票に書かれていないことが多いので、ご質問いただければ企業に確認できます。

働き方の形：メーカー・設計受託・技術派遣

機械設計の求人は、どこで誰の製品を設計するかでも分かれます。

  • 製品・装置のメーカー：自社の製品や装置を設計する。担当する製品が決まっていて、長く同じ製品群に関わりやすい
  • 設計の受託：取引先から設計を請け負い、自社の拠点で設計する
  • 技術派遣・取引先の開発現場での勤務：「取引先にて」「アサイン先を決定」「無期雇用派遣（正社員）」とあれば、雇用主は応募先の会社で、実際に働く場所と担当する製品は案件によって決まる

受託や派遣の形の求人では、自動車・医療機器・航空宇宙・ロボットなど複数の分野のプロジェクト例が並ぶことが多く、経験できる製品の幅は広くなります。一方で、初めの配属先や担当する製品は入社時点で決まっていないことがあります。違いはメーカーと設計受託の機械設計の求人の違いで扱っています。

労働条件の欄では、「変更の範囲」の書き方も見ておきます。労働基準法施行規則第5条では、労働契約を結ぶときに明示する労働条件に「就業の場所及び従事すべき業務に関する事項（就業の場所及び従事すべき業務の変更の範囲を含む。）」があります（2026年11月時点・e-Gov法令検索で確認）。機械設計の求人では、勤務地の変更の範囲として転勤の可能性や、業務の変更の範囲として評価・解析・生産技術・品質保証などへの配置換えの可能性が書かれていることがあります。勤務地の読み方は勤務地の「変更の範囲」とは何かを参考にしてください。

応募条件の欄で見ておくこと

機械設計の応募条件は、次のような項目の組み合わせで書かれます。

  • 設計の実務経験：機械設計の年数、担当した設計の対象（駆動機構、筐体、フレーム、搬送装置など）
  • CADの経験：3D CADでのモデリング、2D CADでの製図。特定のCADの名前が書かれることもあるが、同じ種類のCADの経験で入社後に覚えられると考える会社もある
  • 基礎の知識：材料力学などの力学、製図の知識、加工方法（溶接・プレス・樹脂成形など）の知識
  • 業界の経験：自動車、航空宇宙、医療機器など。必須か歓迎かで重さが違う

資格は、必須に入ることは多くありません。機械設計技術者試験は日本機械設計工業会が実施する試験で、1級・2級・3級に分かれ、3級は実務経験がなくても受験できます（2026年11月時点・同会のサイトで確認）。同会のサイトには資格手当を支給している企業の案内もあり、会社によっては評価や手当の対象になります。CADの書かれ方は機械設計の求人に書かれるCADの読み方、条件の読み分けは機械設計の求人の必須要件・歓迎要件にまとめています。

選考欄は、書類選考と面接1〜2回の書き方が多く見られます。面接では、設計した部品や機構について、なぜその形・材料・構成にしたのかを説明できるかを見られることがあります。社外に出せない図面は持ち出さず、製品名を伏せて、設計の考え方と自分の担当範囲を話せるように準備しておくと安心です。

読み終えたら書き出したい確認リスト

  1. 設計の対象（量産する製品・生産設備や装置・治具や金型）
  2. 担当する段階（構想・基本・詳細・製図）と、入社直後に入る段階
  3. 設計以外に持つ仕事（解析・試作評価・部品手配・組立・現地立ち上げ・量産の調整）
  4. 働き方の形（メーカー・設計受託・技術派遣）と配属が決まる時期
  5. 勤務地と業務の「変更の範囲」、出張の有無
  6. 電気設計やソフトウェアの担当との分担

エージェントベストの見解

機械設計の求人は、設計の対象と段階によって、これまでの経験が活きる度合いが変わります。サイトに載せていない非公開の求人もあるため、設計してきた製品や装置、担ってきた段階、次に関わりたい分野を伺ったうえで、掲載外の求人も含めて個別にお探しできます。面談はオンラインまたは電話でお受けしています。

よくある質問

CADオペレーターの経験で、機械設計の求人に応募できますか

応募の対象になる求人はあります。「設計補助」「図面作成」「既存品の修正設計」が中心の求人や、「機械系の設計や評価、CADの操作の経験」を歓迎要件に並べる求人では、CADの経験がそのまま活きます。構想設計から任せる求人では、形や寸法を自分で決めた経験が問われるので、どこまでを自分で決めてきたかを整理しておくと判断しやすくなります。

製品の設計と装置の設計は、行き来できますか

どちらも機構や強度、材料と加工の知識が土台になるので、経験は共通する部分が多くあります。違うのは、量産のためのコストや組立のしやすさを重く見るか、顧客ごとの仕様決めや現地での立ち上げを重く見るかです。応募先がどちらに比重を置いているかを仕事内容で確かめ、自分の経験のどこが活きるかを考えてください。

機械設計技術者試験を持っていないと不利になりますか

必須要件に資格を入れている機械設計の求人は多くありません。選考では、担当してきた製品や段階、設計の考え方が中心に見られます。資格は知識を体系的に示す手段の1つで、会社によっては手当や評価の対象になります。応募先で資格がどう扱われるかは、応募前に必ずご確認ください。
