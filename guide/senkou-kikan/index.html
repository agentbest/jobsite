選考期間はどのくらいか｜応募から内定までの目安と長くなる理由、待ち方

公開 2026-11-23　監修：株式会社エージェントベスト（有料職業紹介 13-ユ-316964）

応募から内定までの選考期間は、会社や面接の回数、日程の合わせやすさで大きく変わり、決まった長さはありません。求人票に目安を書いている会社では「数週間」や「1か月程度」といった書き方が見られますが、同じ会社でも時期や候補者によって前後します。見通しを立てるときは、書類選考・面接・内定の段階ごとにかかる時間を分けて考え、分からない部分は応募先に確かめるのが確かな方法です。

選考期間は段階の足し算で考える

選考期間は、いくつかの段階にかかる時間を足し合わせたものです。全体の長さを一つの数字で覚えるより、段階ごとに分けて考えると、今どこにいて、あとどのくらいかかりそうかが見えてきます。

段階かかる時間を左右すること
書類選考応募の数、書類を見る人の忙しさ
面接の日程調整面接官と候補者の予定の空き具合
面接の結果待ち社内で話し合う人数、ほかの候補者との比較
適性検査・課題受検や提出の期限、採点の時間
リファレンスチェック推薦者との日程調整
内定の連絡条件の決定、社内の承認の手続き

面接が1回増えるごとに、「日程調整」と「結果待ち」が一組ずつ加わります。面接の回数が多い会社ほど、全体の期間は長くなりやすいということです。面接の回数と各段階の中身は中途採用の面接は何回あるかにまとめています。

求人票に書かれている目安の読み方

求人票の選考欄に、応募から内定までの目安を書いている会社もあります。「応募から内定まで〇週間程度」「選考は1か月以内を予定」のような書き方です。

この目安は、会社が想定している進み方で、すべての候補者に当てはまるわけではありません。読むときは次の点に気をつけます。

  • 「最短」と書かれている場合は、日程がすべて合ったときの長さ
  • 「予定」「想定」と書かれている場合は、状況で前後する前提
  • 書類選考の期間が含まれているかどうか
  • 内定後の回答期限や、入社までの期間は含まれていない

選考欄に期間の記載がない求人も多くあります。その場合は、選考のステップの数から、おおよその長さを見込みます。書類選考、面接の回数、適性検査やリファレンスチェックの有無を数え、ステップが多いほど長くなると考えておきます。

また、適性検査やリファレンスチェックは、面接と同時に進むこともあれば、面接のあとに順番に進むこともあります。順番に進む場合は、そのぶん期間が延びます。選考欄の矢印や番号の並びを見ると、どの順番で進むのかがある程度読み取れます。

エージェントベストの見解

選考のスピードは、会社ごと、また同じ会社でもポジションや時期ごとに違います。求人票に選考期間が書かれていない場合や、書かれていても実際の進み方が気になる場合は、ご質問いただければ企業に確認できます。応募の前に、全体でどのくらいの期間を見込めばよいかを知っておくと、並行して受ける会社との予定も立てやすくなります。

書類選考にかかる時間

書類選考は、選考の最初の関門です。結果が出るまでの時間は、会社の体制や応募の数によって違います。

早い会社では、応募から数日で結果が出ることもあります。一方で、書類を見る人が現場の管理職で、日々の業務と並行して見ている場合や、応募が集中している時期には、結果が出るまでに時間がかかることがあります。

書類選考の結果を待つ間は、ほかの求人への応募を進めておきます。1社の結果を待ってから次に応募すると、活動全体が長くなるためです。待ち方は書類選考の結果が出るまでの期間と待ち方にまとめています。

面接の段階で時間がかかる理由

面接の段階では、日程調整と結果待ちの両方に時間がかかります。

日程調整に時間がかかるのは、面接官が複数いる場合や、役員が面接官になる最終面接の場合です。役員の予定は埋まっていることが多く、候補日が先になりがちです。候補者が在職中で、面接に使える時間が限られている場合も、日程が先に延びやすくなります。

結果待ちに時間がかかるのは、社内で話し合う人数が多い場合や、ほかの候補者の面接が終わるのを待ってから比べて決める場合です。同じポジションに複数の候補者がいると、全員の面接が終わるまで結果が出ないこともあります。

時間がかかりやすい場面理由
面接官が多い全員の予定を合わせる必要がある
最終面接役員の予定が先まで埋まっていることがある
候補者が多い全員の面接が終わってから比べる
年末年始・長期休暇の前後社内の人が休んでいて手続きが止まる
採用の方針の見直し募集の条件や人数を社内で決め直している

内定が出るまでにかかる時間

最終面接が終わってから内定が出るまでにも、時間がかかることがあります。会社は、内定を出す前に、提示する年収や役割、入社日の見込みを決め、社内の承認を得る必要があるためです。

提示する条件を決めるのに時間がかかるのは、候補者の経験に合わせて年収を調整する場合や、配属先を複数の部署で検討する場合などです。最終面接で希望年収や入社可能時期を聞かれるのは、この手続きを進めるためでもあります。

内定のあとには、回答期限が設けられることが多くあります。選考期間とは別に、回答までの時間と、退職から入社までの時間も見込んでおく必要があります。回答期限の考え方は内定の返事はいつまでにするか、入社日の決め方は入社日の決め方にまとめています。

候補者の側でできる、期間を延ばさない工夫

選考期間の多くは会社の都合で決まりますが、候補者の側の動き方で延びるのを防げる部分もあります。

  • 連絡にはその日のうちに返す：面接の候補日は、返事が遅いほど先の日程になりやすい
  • 候補日を多めに出す：幅のある候補を出すと、面接官の予定と合わせやすい
  • オンラインでの面接を相談する：移動の時間がない分、日程を組みやすい
  • 適性検査や課題は期限より早めに済ませる：次の段階に早く進める
  • 入社可能時期と希望年収を整理しておく：内定の条件を決める手続きが早く進む

特に、面接の日程の返事は、選考期間に直接響きます。在職中で日中に返せない場合は、返せる時間帯を決めておき、返事が遅くなりそうなときは「〇日までにお返しします」と先に伝えておきます。

待っている間にすること

選考の結果を待つ時間は、何もしないで過ごすと長く感じます。待っている間にも、進められることがあります。

  1. 終わった面接の振り返りを書き残す
  2. 次の面接で確かめたいことを準備する
  3. ほかの求人への応募を進める
  4. 内定が出たときに確かめる条件を整理しておく

1社の結果に気持ちを預けすぎないことも大切です。並行して応募を進めておけば、1社の結果が遅れても、活動全体は止まりません。

選考期間から逆算して計画を立てる

選考期間の見通しが立てば、転職活動全体の計画を逆算できます。入社したい時期が決まっているなら、そこから次の順にさかのぼります。

  1. 入社したい時期
  2. 退職と引き継ぎにかかる期間（今の会社の就業規則と仕事の状況で決まる）
  3. 内定の回答と条件の確認にかかる期間
  4. 選考にかかる期間
  5. 求人を探して応募書類を整える期間

在職中の人は、2の退職と引き継ぎの期間が加わるため、退職済みの人より全体が長くなります。在職中の時間の作り方は在職中に転職活動を進めるときの時間の作り方、活動全体の計画の立て方は転職活動の期間の目安と計画の立て方にまとめています。

複数の会社の選考期間がずれるとき

並行して複数の会社を受けていると、会社ごとに選考のスピードが違うため、内定の時期がずれることがあります。先に内定が出た会社の回答期限までに、ほかの会社の結果がそろわないこともあります。

ずれを小さくするには、選考が遅い会社に早めに応募する、結果の目安が分からない会社には次の連絡の時期を聞いておく、といった工夫をします。詳しくは複数の選考の進み具合をそろえる方法にまとめています。

選考が長引いているときの確かめ方

予定より連絡が遅いと感じたときは、まず、前回の連絡で示された目安の日を過ぎているかを確かめます。目安の日を過ぎていなければ、もう少し待ちます。過ぎている場合は、状況を問い合わせてかまいません。

問い合わせるときは、催促ではなく、状況の確認として伝えます。ほかの会社の選考が進んでいて、回答の時期を考える必要がある場合は、その事情も添えると、会社も対応を考えやすくなります。

連絡が遅れる理由は、選考の結果とは関係ないことも多くあります。面接官の出張や社内の手続きの遅れ、ほかの候補者との日程調整など、外からは見えない事情で止まっていることもあります。長引くときの考え方は選考が長引くときの考え方と確認、連絡が来ないときは面接の結果連絡が来ないときの考え方にまとめています。

エージェントベストの見解

当社が企業から求人をお預かりする中でよく見るのは、選考の早さを打ち出している会社もあれば、時間をかけて複数の人と会ってもらう方針の会社もある、ということです。早いか遅いかだけでは会社の良し悪しは決まりません。選考の進み方を気にされている求人があれば、ご質問いただければ企業に確認できます。サイトに掲載していない求人も含めて、希望の時期に合わせて個別にお探しすることもできます。

よくある質問

選考が早く進む会社は、急いで人を探しているのでしょうか

そういう場合もありますが、選考の手順を短くまとめている会社や、決める人が少ない会社でも、早く進みます。早く進むときは、判断の材料が少なくなりがちなので、確かめたいことを早めに聞いておきます。

選考期間が長い会社は、見送られる可能性が高いのでしょうか

選考期間の長さと合否は、直接は関係しません。面接の回数が多い会社や、社内の手続きが多い会社では、期間が長くなるのはふつうのことです。気になる場合は、次の連絡の目安を確かめてください。

入社したい時期が決まっている場合、いつごろ応募を始めればよいですか

選考期間に加えて、内定の回答、退職と引き継ぎの期間を見込んで逆算します。どれも人や会社によって変わるため、余裕を持って始めるのがおすすめです。応募先に選考期間の目安を確かめておくと、計画が立てやすくなります。

求人票だけでは分からないことを、面談でお伝えします

同じ職種名でも、企業ごとに仕事の範囲や求める経験は違います。希望を送っていただければ、掲載外の求人も含めて個別にお探しします。ご利用は無料です。

中途採用の面接は2〜3回とする求人が多く、1回で終わる会社や、それより多い会社もあります。段階ごとに面接官が変わり、一次は実務、二次は役割とチームとの相性、最終は方針と入社の意思が中心になります。回数の読み方を整理します。

カジュアル面談と面接の違い｜選考との関係・準備・聞いてよいことを整理する

カジュアル面談は、会社と候補者がお互いを知るための場で、合否を決める面接とは目的が違います。ただし会社によって選考との関係はさまざまです。位置づけを確かめ、経歴の短い説明と聞きたいことを用意して臨むのが基本です。
