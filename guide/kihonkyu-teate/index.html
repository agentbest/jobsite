基本給と手当の違い｜求人票の給与欄で月給の内訳と残業代の基礎をどう読むか

求人票の「月給」は、多くの場合、基本給と各種手当を足した額です。基本給は仕事や等級に対して決まる給与の土台で、手当は役職・資格・住宅・通勤など、特定の条件や目的に対して払われる上乗せです。同じ月給でも配分が違えば、残業代の単価や、条件が変わったときに手当がなくなるかどうかが変わるので、月給の合計だけでなく内訳を見ることが大切です。

この記事では、基本給と手当の違い、手当の種類ごとの読み方、固定残業代の書かれ方、確かめたい項目を説明します。

基本給と手当の違い

基本給手当
何に対して払われるか仕事の内容・等級・経験役職、資格、住まい、通勤、家族など特定の条件
変わるとき昇給・降給、等級の変更条件に当てはまらなくなると減る・なくなることがある
残業代の計算基礎に入る一部の手当は基礎から外れる
賞与・退職金会社によっては計算の基礎になる基礎に入れるかは会社の規程による

賞与や退職金の計算方法は会社の規程で決まるので、基本給を基礎にしているかどうかは会社ごとに確かめます。

手当の種類と読み方

仕事や役割に対する手当

役職手当、資格手当、職務手当などです。役職や資格の条件を満たしている間だけ払われるものが多く、役職を外れると減ることがあります。資格手当は、資格を持っていれば払われるのか、その資格を使う業務についている場合だけ払われるのかが会社によって違います。入社時点で対象になるかどうか、入社後に資格を取った場合はいつから払われるかも確かめておくと、年収の見積もりがずれにくくなります。管理職の求人では、役職手当と残業代の関係を確かめます（→「管理職」の求人と残業代）。

生活に対する手当

住宅手当、家族手当、通勤手当などです。住む場所や家族の状況で金額が変わるため、求人票の月給には含めず「別途支給」と書く会社もあります。月給に含まれているのか別に払われるのかで、比べ方が変わります（→住宅手当・家賃補助の求人の読み方、交通費支給の書かれ方）。

働き方に対する手当

固定残業代（みなし残業手当）、在宅勤務手当などです。固定残業代は時間外労働の対価として払うもので、ほかの手当とは性格が違います。後の章で詳しく説明します。

エージェントベストの見解

求人をご紹介する中でよく見る傾向として、同じ職種・同じくらいの月給でも、基本給を厚くしている会社と、手当の比率が高い会社があります。どちらが良いとは一概に言えませんが、手当の比率が高い場合は、どの手当がどんな条件で払われるかを確かめておくと、入社後に想定と違ったということが起きにくくなります。求人票に内訳が書かれていない場合は、ご質問いただければ企業に確認できます。

残業代の計算に入る手当・入らない手当

残業代は「1時間あたりの賃金×割増率×時間」で計算します。厚生労働省の説明では、時間外労働と深夜労働は2割5分以上、法定休日の労働は3割5分以上の割増が必要です（2026年11月時点で確認）。

この「1時間あたりの賃金」の計算では、次の7つを除くことができるとされています。

  1. 家族手当
  2. 通勤手当
  3. 別居手当
  4. 子女教育手当
  5. 住宅手当
  6. 臨時に支払われた賃金
  7. 1か月を超える期間ごとに支払われる賃金

ただし、名前ではなく実質で判断されます。たとえば家族の人数に関係なく一律に払う家族手当や、距離に関係なく一律に払う通勤手当は、計算の基礎に入るとされています。役職手当や資格手当は上の7つに入っていないので、基礎に入ります。

計算のしかたの詳細は残業代の計算のしかたで説明しています。個別の手当が基礎に入るかどうかの判断が必要な場合は、労働基準監督署や社会保険労務士などにご相談ください。

固定残業代の書かれ方

月給に固定残業代が含まれている場合、厚生労働省のリーフレットでは、募集の段階で次のように書く例が示されています（2026年11月時点で確認）。

  • 基本給 ◯◯円（固定残業代の手当を除く額）
  • ◯◯手当（時間外労働の有無にかかわらず、◯時間分の時間外手当として◯◯円を支給）
  • ◯時間を超える時間外労働分の割増賃金は追加で支給

月給の合計が同じでも、固定残業代の時間数が多いほど基本給の部分は小さくなります。固定残業代が何時間分か、超えた分が払われるかは、みなし残業（固定残業代）の求人の読み方で詳しく説明しています。

注意

「月給◯◯万円（固定残業代含む）」とだけ書かれていて、時間数や金額がわからない求人もあります。その場合は、応募前か面接の早い段階で内訳を確かめるのがおすすめです。

社会保険料と手当の関係

健康保険や厚生年金の保険料は、毎月の給与をもとにした「標準報酬月額」にかかります。日本年金機構の説明では、標準報酬月額の対象は基本給だけでなく、残業手当や通勤手当なども含めた税引き前の給与です（2026年11月時点で確認）。残業代の計算からは外れる通勤手当も、社会保険料の計算には入る点が違いです。手取りへの影響は年収と手取りの違いで説明しています。

給与の支払い方の決まり

労働基準法では、賃金は原則として、通貨で、全額を、直接本人に、毎月1回以上、一定の支払日を決めて払うこととされています。手当も賃金なので、月々の給与と一緒に払われるのが一般的です。給与の締め日と支払日は求人票や労働条件通知書で確かめます。

給与明細の見方とのつながり

入社後に受け取る給与明細は、おおむね「支給」「控除」「勤怠」の3つに分かれています。求人票の給与欄は、このうち「支給」の欄を前もって示したものと考えると読みやすくなります。

給与明細の欄主な項目求人票との対応
支給基本給、各種手当、固定残業代、残業代月給の内訳、別途支給の手当
控除健康保険料、厚生年金保険料、雇用保険料、所得税、住民税求人票には書かれない
勤怠出勤日数、残業時間、有給休暇勤務時間、残業の見込み

求人票の月給は「支給」の額で、そこから「控除」が引かれた額が手取りです。控除の仕組みは年収と手取りの違いで説明しています。

同じ月給の求人を比べるとき

月給の合計が同じ2つの求人でも、内訳が違えば中身は変わります。比べるときは次の順で見ていきます。

  1. 固定残業代を除いた額をそろえる：固定残業代は時間外労働の対価なので、ほかの給与と分けて比べます。固定残業代が何時間分かも並べます
  2. 条件つきの手当を分ける：住宅手当や家族手当など、自分に当てはまるかどうかで変わる手当は、当てはまる場合の額で見積もります
  3. 基本給を比べる：昇給の幅、賞与や退職金の計算の基礎になるかどうかを確かめます
  4. 別途支給の手当を足す：通勤手当など、月給の外で払われるものを加えます

こうすると、「月給は同じだが、片方は固定残業代が大きい」「片方は住宅手当が大きく、自分は対象外」といった違いが見えてきます。

基本給と昇給・評価の関係

昇給は、多くの会社で基本給（または等級ごとの給与）を上げる形で行われます。昇給の有無や決め方は、労働条件の明示のルール上、書面でなくてもよい事項とされていますが（2026年11月時点で確認）、会社の規程で決まっています。昇給の時期や、評価との関係は面接やオファー面談で確かめておくと、入社後の見通しが立てやすくなります。

役職手当の比率が高い給与体系では、昇格したときに手当が上がる形で年収が増える会社もあります。どちらの形かで、評価が年収にどう表れるかが変わります。年収の幅の読み方は求人の年収の幅はどう決まるのか、賞与との関係は賞与の書かれ方の読み方を参考にしてください。

求人票で確かめたい項目

  • 月給のうち、基本給はいくらか
  • 月給に含まれている手当の名前と金額
  • 手当が払われる条件（役職、資格、住まい、家族など）
  • 固定残業代の有無、時間数と金額、超えた分の扱い
  • 月給に含まれず「別途支給」とされている手当
  • 賞与や退職金を基本給で計算するかどうか

エージェントベストの見解

当社の求人への応募は、当社への申し込み（無料）で、当社から企業へ推薦する形で選考が進みます。基本給と手当の内訳や、手当が払われる条件など、求人票だけでは読み取れないことは、ご質問いただければ企業に確認できます。サイトに載せていない非公開の求人もあり、希望を伺ったうえで掲載外の求人も含めて個別にお探しできます。

よくある質問

基本給が低く手当が多い求人は避けたほうがよいですか

一概には言えません。手当の中身によります。役職手当や資格手当のように仕事に結びついた手当は残業代の計算の基礎に入りますが、住宅手当などは条件によって基礎から外れます。手当が払われる条件と、賞与・退職金を何で計算するかを確かめて判断するのがおすすめです。

求人票に基本給が書かれていません。どう確かめればよいですか

月給の合計だけが書かれている場合は、面接や内定時に内訳を確かめます。内定時の労働条件通知書には、賃金の決め方・計算・支払い方法などが書面で示されます（→内定通知書と労働条件通知書の違い）。

入社後に手当がなくなることはありますか

手当が払われる条件に当てはまらなくなった場合（役職を外れた、転居した など）は、規程にもとづいて減ったりなくなったりすることがあります。どんな条件で払われるかは、就業規則や賃金規程で決まっています。入社後に条件が違うと感じた場合は入社後に条件が違ったときの確かめ方と相談先を参考にしてください。

参考にした公的情報・資料

  • 残業、早出や休日出勤による割増賃金のチェック方法を教えてください｜確かめよう労働条件（厚生労働省）
  • 企業から受ける労働条件明示のルールが変わります！（厚生労働省）
  • 労働条件の明示｜確かめよう労働条件（厚生労働省）
  • 厚生年金保険の保険料（日本年金機構）
  • 労働基準法のあらまし（賃金支払いの原則、出来高払制）（茨城労働局）

記事の内容は公開日時点の情報にもとづきます。制度は変わることがあるため、手続きの前に各機関の最新情報をご確認ください。

給与・年収の書き方

「理論年収」「想定年収」の読み方｜賞与・残業代がどこまで含まれるか

理論年収・想定年収は、賞与や残業代を一定の前提で見込んだ年収の目安で、受け取りが約束された額ではありません。月給×12との違い、賞与・固定残業代・インセンティブの含まれ方、内定時に確かめる内訳を解説します。

求人票の用語

みなし残業（固定残業代）の求人の読み方｜何時間分か・超えた分はどうなるか

固定残業代の求人は「何時間分でいくらか」「それを除いた基本給」「超えた分を追加で払う旨」の3点で読みます。決められた時間を超えた残業には割増賃金が別に支払われます。2026年11月時点の制度で整理しました。

給与・年収の書き方

インセンティブ・歩合の求人の読み方｜固定給との割合と確かめる計算式

インセンティブや歩合のある求人は、固定給と成果で変わる部分の割合を分けて読むのが基本です。年収例の前提、計算式・支払い時期、歩合給の保障給や残業代の決まり、面接で確かめたい項目を解説します。

給与・年収の書き方

求人の年収の幅（400〜800万円など）はどう決まるのか｜下限と上限の読み方

求人票の年収の幅は、会社がそのポジションに用意した給与の範囲で、どこに決まるかは選考での評価と前職の条件で変わります。下限と上限の意味、幅が広くなる理由、提示額を確かめるタイミングを解説します。

給与・年収の書き方

賞与の書かれ方の読み方｜「年2回」「業績連動」「前年実績」は何を示すか

求人票の賞与欄は、支給の回数・決め方・過去の実績を示すもので、将来の支給額を約束するものではありません。「年2回」「業績連動」「前年実績」の読み方、初年度の扱い、賞与から引かれる社会保険料と所得税を解説します。

給与・年収の書き方

年収と手取りの違い｜社会保険料と税金で給与から引かれるものと計算の仕組み

手取りは、額面の給与から社会保険料（健康保険・厚生年金・雇用保険など）と税金（所得税・住民税）を引いた額です。2026年11月時点の保険料率をもとに、引かれるものの仕組みと簡易な目安の計算、転職時の注意点を解説します。
