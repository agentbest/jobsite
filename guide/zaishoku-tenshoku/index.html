在職中に転職活動を進めるときの時間の作り方｜平日の使い方と休みの取り方

在職中に転職活動を進めるときは、作業を細かく分けて平日のすき間時間に割り振り、まとまった時間が要る面接だけを調整の対象にするのが基本です。面接はオンラインや業務時間外の枠を相談でき、休みが必要なら早めに申し出ます。今の仕事を続けながら進めるので、収入が途切れず、焦らずに会社を選べるのが在職中に動く利点です。

この記事の制度の説明は、2026年11月時点の法令で確かめた内容です。

在職中の活動で時間がかかるのはどこか

転職活動の作業を分けてみると、まとまった時間が要るものと、すき間時間でできるものがあります。

作業必要な時間の性質向いている時間帯
求人を探す・読む短く区切れる通勤中、昼休み
応募書類を作る最初だけまとまった時間休日
求人ごとに書類を直す短く区切れる平日の夜
連絡を返す・日程を決める短いが早さが要る昼休み、終業後
面接を受けるまとまった時間・時間帯が決まる調整が必要
面接の準備中くらい前日の夜、休日

この表で分かるように、在職中に一番調整が要るのは面接です。それ以外の作業は、時間帯を選ばずに細かく進められます。最初に職務経歴書の土台を休日に作っておくと、あとは求人ごとの手直しで済むので、平日の負担が軽くなります。

始める前に決めておくこと

在職中の活動は、走りながら考えると時間が足りなくなります。応募を始める前に、次のことを決めておくと、あとの迷いが減ります。

  • 転職したい理由と、譲れない条件：求人を読むたびに迷わないための物差しです
  • 活動にかけられる時間：平日に何分、休日に何時間を使えるか
  • 面接に使える休みの日数：残っている有給休暇と、取りやすい時期
  • 入社したい時期の目安：今の仕事の区切りや、繁忙期を避けたい時期

特に、休みを取れる日数と時期は、面接の日程を決めるときの制約になります。今の仕事の繁忙期が分かっているなら、その時期に面接が重ならないよう、応募を始める時期を前後にずらすことも考えます。始める時期の考え方は転職活動を始める時期の考え方にまとめています。

平日の時間の使い方

在職中は、平日にまとまった時間を取るのが難しいものです。1日の中で使える時間を決めて、作業を割り振ります。

  • 始業前・通勤中：求人を探す、気になる求人を保存する、連絡を確認する
  • 昼休み：急ぎの連絡に返事をする、日程の候補を返す
  • 終業後：書類の手直し、面接の準備、オンライン面接

すき間時間で求人を読むときは、気になった求人をその場で判断しようとせず、保存だけしておくのがコツです。比べたり応募を決めたりするのは、時間の取れる夜や休日にまとめて行います。

毎日すべてをこなす必要はありません。「平日は連絡の返事と求人を読むだけ、書類と準備は休日」のように、曜日で役割を分けておくと続けやすくなります。

連絡の返事は、その日のうちに返すことを目安にします。面接の日程の候補をもらったら、早く返すほど希望の日時が取りやすくなります。返事に時間がかかりそうなときは、いつまでに返すかだけ先に伝えておきます。

面接の時間をどう作るか

面接は、時間帯が会社の都合で決まることが多いため、在職中の人にとって一番の調整どころです。次のような方法を組み合わせます。

  1. オンライン面接を相談する：移動の時間がかからないので、終業後や昼休みをずらして受けやすくなります
  2. 業務時間外の枠を相談する：始業前や終業後の時間に面接を設けてもらえないか聞いてみます
  3. 面接を同じ日にまとめる：休みを取る日に、複数社の面接を入れます
  4. 休みを取る：対面の面接や長い選考がある日は、休みを取って臨みます

求人票の選考欄に「在職中の方は面接日を相談に応じる」といった一文を添えている会社もあります。書かれていなくても、相談すれば調整してもらえることは多くあります。最終面接など、対面を求められる段階もあるので、選考の流れの中でどこが対面になりそうかを早めに把握しておくと、休みの予定が立てやすくなります。オンライン面接を職場の近くや昼休みに受ける場合は、周りに声が聞こえない場所を確保できるかも考えておきます。また、面接は予定の時間より長くなることもあるので、前後の予定には余裕を持たせます。面接のすぐあとに大事な会議を入れるような組み方は避けたほうが安心です。日程の決め方は面接の日程調整の進め方にまとめています。

エージェントベストの見解

当社との面談は、オンラインまたは電話でお受けしています。在職中の方でも、移動の時間をかけずにお話しいただけます。また、企業の面接をオンラインで受けられるか、業務時間外の時間帯を相談できるかといった点は、求人票に書かれていないことが多くあります。ご質問いただければ企業に確認できます。

休みを取るときに知っておきたいこと

面接のために休みを取るときは、年次有給休暇を使うことが多くなります。労働基準法39条5項は、会社は有給休暇を労働者が請求する時季に与えなければならないと定めています。ただし同じ項で、請求された時季に休ませると事業の正常な運営を妨げる場合には、会社がほかの時季に変えることができるとされています。

有給休暇の取得に、転職活動のためという理由を伝える必要は通常ありません。とはいえ、繁忙期や大事な会議の日に急に休むと、職場に負担がかかり、時季の変更を求められることもあります。面接の日程が決まったら、なるべく早めに申し出ます。

半日単位や時間単位で休めるかどうかは、会社の就業規則や制度によって違います。今の会社の制度を確かめておくと、面接の前後だけ休む、といった使い方ができる場合があります。個別の扱いで判断に迷うときは、労働基準監督署や社会保険労務士にご相談ください。

選考の段階ごとに時間の使い方は変わる

在職中の活動は、選考がどこまで進んでいるかで、時間の使い方の重心が変わります。

段階時間の重心
応募を始めたころ求人を読む、書類を作る・直す（休日と夜）
書類選考から一次面接連絡の返事、日程の調整、面接の準備（平日のすき間）
二次面接から最終面接休みを取っての面接、準備の深掘り（休日と休暇）
内定のころ条件の確認、回答の判断、退職の準備

応募を始めたころは書類に、選考が進むと面接と休みの調整に、時間の重心が移っていきます。後半になるほど休みを取る場面が増えるので、有給休暇は前半で使い切らないように配分しておくと安心です。

今の会社に知られないための注意

在職中の活動では、今の会社に知られないように進めることも大切です。

  • 会社のパソコンやメールアドレス、会社の電話で転職活動の連絡をしない
  • 職場で求人サイトを開かない、書類を印刷しない
  • 面接の服装や外出で、急に周りと違う動きをしない
  • 同僚に転職の話をしない

連絡先は、個人のメールアドレスと携帯電話にそろえておきます。連絡を取る時間帯も、職場にいない時間に寄せると安心です。注意点は現職に知られずに転職活動を進める注意点にまとめています。

今の仕事との両立で無理をしない

在職中の活動は、今の仕事を続けながら進めるので、負担が積み重なりがちです。無理が続くと、仕事にも選考にも影響が出ます。

両立のために、最初に活動の期間と、応募する社数の目安を決めておきます。並行して受ける会社が多すぎると、面接の日程が詰まり、休みを取る回数も増えます。受ける社数は、今の仕事の忙しさと相談して決めます。並行して受けるときの進め方は複数の会社を並行して受けるときの進め方を参考にしてください。

活動の期間を決めるときは、内定から入社までの時間も見込みます。在職中の人は、内定が出たあとに退職の手続きと引き継ぎが必要です。入社日は、今の会社の退職の時期と合わせて決めることになります。活動全体の計画の立て方は転職活動の期間の目安と計画の立て方にまとめています。

仕事が忙しい時期に入って活動が止まってしまうこともあります。そのときは、無理に応募を続けるより、進んでいる選考だけを続けて新しい応募はいったん止める、といった形でペースを落とします。進めている会社には、次の面接の日程に余裕がほしいことを早めに伝えておけば、相談に応じてもらえることがあります。止めた期間も、気になる求人を保存しておくなど、再開しやすい状態を残しておくと、忙しさが落ち着いたときにすぐ動き出せます。

内定が出たあとの段取り

在職中の活動では、内定が出てからも今の会社での仕事が続きます。内定から入社までの段取りを、あらかじめ頭に入れておきます。

  1. 内定の条件を確かめ、承諾するかを決める
  2. 今の会社に退職を伝える
  3. 引き継ぎを進め、残った有給休暇の扱いを決める
  4. 入社日を迎える

退職を伝えるのは、内定を承諾してからにします。承諾の前に退職を伝えると、もし条件が合わずに辞退した場合に、戻る場所がなくなるためです。退職の伝え方は退職の伝え方と時期、入社日の決め方は入社日の決め方にまとめています。

エージェントベストの見解

在職中の方の転職では、活動を始めた時点で退職までの見通しも立てておくことをおすすめします。選考が順調に進んでも、引き継ぎの期間が足りずに入社日の相談が長引くことがあるためです。どのくらいの入社時期を想定しているかは求人によって違いますので、気になる求人があれば、ご質問いただければ企業に確認できます。

よくある質問

面接の日程が平日の日中しか空いていないと言われたらどうすればよいですか

オンラインでの実施や、ほかの時間帯の候補がないかを一度相談してみます。それでも難しい場合は、休みを取って受けることになります。休みは早めに申し出てください。

在職中だと、退職済みの人より選考で不利になりますか

在職中であること自体が不利になるとは限りません。ただし、入社できる時期は退職済みの人より遅くなることが多いため、面接で入社可能時期を聞かれたときに、退職の手続きにかかる期間を見込んで答えられるようにしておきます。

転職活動の期間は、どのくらいを見込めばよいですか

人によって、また受ける会社によって大きく違います。応募から内定までの期間に加えて、在職中の人は退職と引き継ぎの期間も要ります。選考の期間の考え方は選考期間はどのくらいかにまとめています。

内定・条件確認・入社

退職の伝え方と時期｜民法と就業規則の関係・引き止めにあったときの対応

退職は、就業規則の申出の時期を確かめ、直属の上司に口頭で伝えるのが基本です。期間の定めのない雇用は民法627条で申入れから2週間で終了します。伝える順番、退職届の出し方、引き止めへの対応を2026年11月時点で整理します。

応募の判断・書類

職歴に空白期間があるときの応募の考え方｜書類の書き方と伝え方の準備

職歴に空白期間があっても、求人の必須要件に合う経験があれば応募を見送る理由にはなりません。期間は事実どおりに書き、何をしていたかと今は働ける状況かを短く説明できるようにします。書類での書き方と準備の順番をまとめます。

応募の判断・書類

応募するか迷ったときの判断のしかた｜条件を3つに分けて求人票を読み直す

応募するか迷ったら、条件を「譲れない条件」「あればうれしい条件」「確かめないと分からない条件」の3つに分けて求人票を読み直します。応募は入社の約束ではないため、分からない点は選考の中で確かめる前提で判断できます。

応募の判断・書類

応募書類で求人ごとに変えるところ・変えないところ｜使い回しを防ぐ手順

応募書類で求人ごとに変えるのは、志望動機、職務経歴書の要約と経験の並べ方、自己PRの切り口、希望条件の書き方です。在籍期間や役職、実績の数字など事実は変えません。求人票から合わせる先を抜き出す手順を整理します。

応募の判断・書類

何社に応募するのがよいか｜並行して進める数を自分の時間から決める

応募する社数に正解の数はありません。面接の準備にかけられる時間から、同時に選考を進められる社数を先に決め、書類の結果を見ながら応募を足したり絞ったりするのが進め方の基本です。数の決め方と見直し方を整理します。
