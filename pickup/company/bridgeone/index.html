01COMPANY

どんな会社か

「人の力で世界最高峰を再興する」を掲げ、企業の経営課題を解決する「ワンデスクソリューション事業」を展開する会社です。2020年3月の設立で、本社は東京・恵比寿、大阪と名古屋に支店があります。

  • 営業ひとりが、多様な解決策を組み合わせる

    単一の商材を売るのではなく、営業ひとりが窓口になり、社内にそろえた複数のソリューションを組み合わせて提供するモデルです。

  • 人材・コンサル・金融を一社で

    人材紹介やヘッドハンティング、採用・人事・DX・財務などのコンサルティング、保険・ファクタリング・リースなどの金融サービスを展開しています。

  • M&Aは社内外から案件が届く

    M&A事業部では、社内の営業部門や、金融機関・会計事務所・税理士法人などのパートナーから案件が届く体制だと、求人票に書かれています。

設立2020年3月／資本金980万円／従業員数343名／本社：東京都渋谷区恵比寿。出典：同社の公開求人票（2026年11月時点）

02WORK

ブリッジワンで募集している仕事

M&A、コンサルティング、人材紹介、法人営業のほか、エンジニアやバックオフィスなど、幅広い職種を募集しています。

POINT 1M&A

M&A事業部は、トスアップされた案件から初期段階を担当するポジションと、M&Aの全プロセスを担当するポジションがあります。自社のM&Aを担うポジションもあります。

POINT 2コンサルタント・金融

採用、人事・組織、DX、AI、財務などのコンサルティングと、保険などの金融コンサルティングがあります。

POINT 3人材紹介・法人営業

ヘッドハンター、キャリアアドバイザー、リクルーティングアドバイザーなどの人材紹介と、東京・関西・中部・福岡の営業開発事業部があります。

POINT 4社内の仕組みをつくる

社内システムのエンジニア、経営企画、経理・財務、広報、人事、法務など、会社を支えるポジションも募集しています。

M&A事業部メンバー（テレアポ・書類作成なし）は、テレアポは一切なく、確度の高い案件に集中できると求人票に書かれています。

06FIT

応募条件と、合う人

応募条件はポジションによって異なります。ここでは、主なポジションの求人票の記載をまとめました。

応募条件（主なもの）

  • M&A事業部メンバー（テレアポ・書類作成なし）：BtoBの営業経験（新規開拓や高い営業目標を追った経験）、または金融機関・不動産・コンサル・人材などの営業経験
  • M&A事業部_メンバー：法人営業の経験（証券、保険、銀行系、商社系、コンサル営業など）
  • 企業再生アドバイザリー：財務・会計の基礎知識と、金融機関またはコンサルティングファームなどでの実務経験
  • 自社M&A事業部：M&A仲介会社でのコンサルタント／アドバイザーの実務経験、またはM&A関連業務（DD、バリュエーション、契約交渉など）の経験が1年以上
  • ヘッドハンター：法人営業の経験（2年以上・業界不問）

合う人

  • 営業ひとりで複数のソリューションを組み合わせ、経営課題に向き合いたい人
  • 高い目標を追い、成果を出すことにこだわれる人
  • 社内の他の部署と、円滑にコミュニケーションをとれる人
  • 成長できる環境を求め、素直に物事に取り組める人
07WHY AGENT BEST

エージェントベストに相談する理由

エージェントベストは、M&A・コンサル・人材紹介・金融に特化した転職エージェントです。

1求人票に書かれていない、募集の背景をお伝えします

なぜ今採用しているのか、どんな経験の人が求められているのか。企業から直接聞いた話をもとに、応募するかどうかを判断していただけます。

2ほかの会社の求人とも比べられます

1万件以上の求人を扱っています。ブリッジワンに応募するかどうかに関わらず、近い条件の会社も一緒に検討できます。

3連絡方法はご希望に合わせます

転職活動を周りに知られたくない方も安心してください。メール・電話・LINEなど、連絡の手段や時間帯はご希望に合わせます。

4平日夜・土日も面談できます

仕事のあとや休日にも、面談の時間を取れます。

08FAQ

よくある質問

M&Aの経験がなくても応募できますか？

M&A事業部メンバー（テレアポ・書類作成なし）は、BtoBの営業経験などが応募条件で、M&A仲介の経験は歓迎条件です。ポジションによって条件が異なります。

M&A事業部は、テレアポがありますか？

M&A事業部メンバー（テレアポ・書類作成なし）の求人票では、テレアポは一切なく、社内やパートナーからトスアップされた案件に取り組むと書かれています。

勤務地はどこですか？

本社は東京・恵比寿です。営業開発事業部には、関西・中部・福岡の支社を希望できるポジションがあります。ポジションごとの勤務地は、相談のときにお伝えします。

選考にはどのくらいかかりますか？

同社の求人票には選考の流れの詳しい記載がないため、相談のときにお伝えします。

相談したら必ず応募しないといけませんか？

いいえ。話を聞いてから決めていただいて大丈夫です。ブリッジワン以外の選択肢も一緒に検討できます。
