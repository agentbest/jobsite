01COMPANY

どんな会社か

「スマートデータ社会の実現」をミッションに、データマーケティングのSaaSを開発・提供する会社です。2010年設立、本社は東京・西新宿、福岡にも拠点があります。

  • ノーコードでデータを扱える

    主力の「b→dash」は、データの取り込み・加工・統合・抽出・活用までを、SQLを書かずに1つのツールで行えると同社は説明しています。現場のマーケターが自分で使えることを目指しています。

  • マーケと経営管理の2つの柱

    マーケティングの「b→dash」に加え、経営管理のDXを支える「kpiee」を展開しています。ツールの提供だけでなく、業務の代行まで含めて支援します。

  • AIの機能を次々に追加

    2024年10月に「b→dash AI」の提供を始めました。2025年以降も、ABテストの自動最適化やメール・LINEのAIレコメンド、AI接客エージェントなどを発表しています。

設立2010年4月／資本金1億円／従業員406人（2026年5月時点・正社員・契約社員・アルバイトの合計）。2021年に株式会社フロムスクラッチから社名を変更。出典：同社の会社情報・採用サイト・ニュース

03WORK

データXのカスタマーサクセスとセールスの仕事

クライアントは旅行・人材・アパレル・不動産・金融など幅広い業界の企業です。ツールの使い方を教えるだけでなく、マーケティングの課題を一緒に解く立場で関わります。

POINT 1課題から聞く提案

カスタマーサクセスは、担当企業のマーケティング課題を聞き取り、b→dashを使った施策の提案・PDCAの設計・実行まで支援します。

POINT 2週1回の定例で伴走

担当企業とは週に1回ほど定例の打ち合わせを持ちます。1日に3〜5社ほどと話し、それ以外の時間で次の提案を準備します。

POINT 3分業したセールス

電話での営業は別の部門が担い、フィールドセールスはオンラインや対面の商談に集中します。新規プロダクトでは、CEO直下で営業組織を立ち上げる募集もあります。

POINT 4IT未経験からも入れる

営業やカスタマーサクセスなど顧客と向き合ってきた経験を活かし、IT・マーケティングの知識を身につけられる募集があります。

仕事の進め方は、同社の公開求人票（カスタマーサクセス・法人営業）にもとづきます。

合う人

  • データやITを使って、お客様の売上や業務を良くする仕事がしたい人

08WHY AGENT BEST

エージェントベストに相談する理由

エージェントベストは、SaaS・データ活用・IT・スタートアップに特化した転職エージェントです。

1求人票に書かれていない、募集の背景をお伝えします

なぜ今採用しているのか、どんな経験の人が求められているのか。企業から直接聞いた話をもとに、応募するかどうかを判断していただけます。

2ほかの会社の求人とも比べられます

1万件以上の求人を扱っています。データXに応募するかどうかに関わらず、近い条件の会社も一緒に検討できます。

3連絡方法はご希望に合わせます

転職活動を周りに知られたくない方も安心してください。メール・電話・LINEなど、連絡の手段や時間帯はご希望に合わせます。

4平日夜・土日も面談できます

仕事のあとや休日にも、面談の時間を取れます。

09FAQ

よくある質問

ITやマーケティングの経験がなくても応募できますか？

カスタマーサクセス・インサイドセールス・マーケター・エンジニアなどに、未経験から応募できる募集があります。営業や接客など、顧客と向き合ってきた経験が活かせる求人もあります。

働き方はどうなっていますか？

勤務は9時〜18時です。同社の求人票によると、20時には完全に退社し、PCの持ち帰りや土日の出勤は原則禁止です。四半期の最終日を有給の取得日にする「クオーターピットイン」もあります。

勤務地はどこですか？

多くの求人は東京・西新宿のオフィスです。福岡（天神）のテクニカルサポートの募集もあります。

選考はどのように進みますか？

書類選考と面接で進みます。面接の回数はポジションによって異なるため、詳しくは相談時にお伝えします。

相談したら必ず応募しないといけませんか？

いいえ。話を聞いてから決めていただいて大丈夫です。データX以外の選択肢も一緒に検討できます。
