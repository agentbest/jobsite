求人票の交通費は、「全額支給」「月◯円まで支給」「規定により支給」のどれで書かれているかで、自分の通勤で実際にいくら出るかが変わります。所得税では、電車・バス通勤なら最も経済的かつ合理的な経路の定期代などが月15万円まで非課税で、車や自転車の通勤は片道の距離ごとに限度額が決まっています。一方で、通勤手当は社会保険料を決める報酬には含まれるので、手取りへの影響は税と保険料で分けて考えます。

この記事の制度の説明は、2026年11月時点で国税庁・日本年金機構・厚生労働省の資料と法令を確認したものです。国税庁のタックスアンサーは「令和8年4月1日現在」の内容です。

## 求人票の交通費の書き方は3つに分かれる

交通費の欄は、短い言葉で書かれることもある項目です。よく見る書き方ごとに、確かめたいことを整理します。

| 求人票の書き方 | 読み取れること | 確かめたいこと |
|---|---|---|
| 全額支給・実費支給 | 通勤にかかる額をそのまま払う考え方 | 対象になる経路の決め方（最短・最安など）、新幹線や特急を使える場合があるか |
| 月◯円まで支給 | 上限を超えた分は自己負担 | 上限の額と、自分の通勤経路の定期代との差 |
| 規定により支給・会社規定に準ずる | 会社の規程で決まる | 規程の中身（上限、経路、車通勤の可否） |

「全額支給」と書かれていても、どの経路の運賃を基準にするかは会社の規程で決まります。遠回りの経路や、会社が認めていない交通手段の分まで払われるとは限りません。引っ越しを予定している場合は、新しい住所からの通勤費が対象になるか、上限に収まるかを先に確かめておくと安心です。

### 月給に含まれているか、別に払われるか

交通費は月給とは別に「交通費別途支給」と書かれる一方で、月給に含めて書く会社もあります。月給の額だけで求人を比べると、交通費を含めた額と含めない額を比べてしまうことがあります。月給の内訳の読み方は[基本給と手当の違い](/guide/kihonkyu-teate/)にまとめています。

:::view
求人をご紹介する中でよく見る傾向として、交通費の欄が「規定により支給」の一行だけで、上限や車通勤の扱いが書かれていない求人は少なくありません。遠方から通う予定の方や、車で通勤したい方は、内定前に規程の中身を確かめておくと入社後のずれを防げます。求人票に書かれていない点は、ご質問いただければ企業に確認できます。
:::

## 所得税の非課税限度額（2026年11月時点）

通常の給与に上乗せして払われる通勤手当や通勤定期券は、一定の額まで所得税がかかりません。国税庁の説明をもとに、通勤の方法ごとに整理します。

### 電車・バスだけで通勤する場合

非課税になるのは、運賃・時間・距離などから見て、最も経済的かつ合理的な経路と方法で通勤した場合の定期代などの額です。その額が月15万円を超える場合は、15万円が限度になります。

- 新幹線や特急の料金も、その経路と方法が「最も経済的かつ合理的」に当たれば含まれる
- グリーン料金は含まれない
- 電車・バスに加えて車や自転車も使う場合は、定期代と、車・自転車の距離に応じた限度額を足した額が限度（こちらも月15万円まで）

### 車・自転車などで通勤する場合

車や自転車などの交通用具を使う人の非課税限度額は、片道の通勤距離（通勤経路に沿った長さ）で決まります。国税庁のタックスアンサー（令和8年4月1日現在）では、1か月あたり次の額です。

| 片道の通勤距離 | 1か月の非課税限度額 |
|---|---|
| 2km未満 | 全額課税 |
| 2km以上10km未満 | 4,200円 |
| 10km以上15km未満 | 7,300円 |
| 15km以上25km未満 | 13,500円 |
| 25km以上35km未満 | 19,700円 |
| 35km以上45km未満 | 25,900円 |
| 45km以上55km未満 | 32,300円 |
| 55km以上65km未満 | 38,700円 |
| 65km以上75km未満 | 45,700円 |
| 75km以上85km未満 | 52,700円 |
| 85km以上95km未満 | 59,600円 |
| 95km以上 | 66,400円 |

勤務先の周辺や、通勤で使う駅などの周辺にある駐車場を使う場合は、上の額に駐車場の料金相当額（月5,000円まで）を足した額が限度になります。有料道路を使う場合は、合理的な料金の額を足せますが、合計で月15万円が上限です。

### 2025年の改正

国税庁によると、2025年11月19日に所得税法施行令の一部を改正する政令が公布され、車などの交通用具を使う人の通勤手当の非課税限度額が引き上げられました。改正は2025年11月20日に施行され、2025年4月1日以後に支払われるべき通勤手当に適用されています。片道2km以上10km未満の区分は改正の前後で同じ額で、10km以上の区分が引き上げの対象でした。電車・バスの月15万円は変わっていません。

改正前の限度額で計算していた分は、2025年分の年末調整で調整が必要になる場合があると国税庁は説明しています。前の勤務先での扱いについて疑問がある場合は、源泉徴収票を手元に用意して、税務署や税理士にご相談ください。

### 限度額を超えた分

限度額を超えて払われた分は、給与として所得税の対象になります。払われた月の給与に上乗せして源泉徴収されます。非課税の限度額は、パートやアルバイトなど短い期間の雇用でも月単位で計算します。

### 近い距離の車・自転車通勤

片道2km未満の車・自転車通勤は、通勤手当の全額が所得税の対象です。会社の近くに住んで自転車で通う場合、手当が出ても非課税にはなりません。金額は小さくても、給与明細の課税対象の額に含まれることを知っておくと、明細を見たときに戸惑いません。

## 交通費の書き方が違う求人を比べる手順

交通費の書き方は求人ごとにそろっていないので、月給や年収と同じ土台で比べるには、自分の通勤に当てはめて計算し直します。

1. 応募先ごとに、自宅からの経路と1か月の定期代（車なら片道の距離）を調べる
2. 求人票の上限と比べ、上限を超える分を自己負担として書き出す
3. 月給に交通費が含まれている求人は、交通費の分を引いた額で他の求人と比べる
4. 在宅勤務が多い求人は、出社の日数をもとに実際に払われる額を見積もる

自己負担が出る求人では、その分だけ手元に残るお金が減ります。年収の差が小さい求人どうしでは、交通費の自己負担で順位が入れ替わることもあります。上限や払い方が求人票から読み取れないときは、応募前か面接の場で確かめておくと、内定後に比べ直す手間が減ります。

## 社会保険料と残業代での扱い

所得税では非課税でも、ほかの制度では扱いが違います。ここを混同すると、手取りの見積もりがずれます。

| 制度 | 通勤手当の扱い |
|---|---|
| 所得税 | 限度額までは非課税 |
| 厚生年金保険・健康保険 | 標準報酬月額の対象になる報酬に含まれる |
| 残業代（割増賃金）の計算 | 基礎となる賃金から除くことができる。ただし距離に関係なく一律に払うものは基礎に入る |

日本年金機構の説明では、標準報酬月額は基本給だけでなく残業手当や通勤手当なども含めた税引き前の給与で決まります。通勤費の高い経路で通うと、通勤手当が増えた分、保険料の計算のもとになる額も上がる場合があります。手取り全体の考え方は[年収と手取りの違い](/guide/tedori/)で説明しています。

残業代の計算では、労働基準法第37条と施行規則第21条により、通勤手当などは割増賃金の基礎から除かれます。ただし厚生労働省の「確かめよう労働条件」では、名称ではなく実質で判断し、距離に関係なく払われる通勤手当は計算の基礎に入るとしています。計算の詳細は[残業代の計算のしかた](/guide/zangyodai-keisan/)をご覧ください。個別の手当が基礎に入るかどうかの判断が必要な場合は、労働基準監督署や社会保険労務士にご相談ください。

## 在宅勤務がある求人の交通費

出社と在宅勤務を組み合わせる求人では、交通費の払い方が通常と違うことがあります。定期代ではなく出社した日の実費で払う、在宅勤務の日数が多い月は定期代を払わない、といった形です。求人票では「出社時の交通費支給」のように短く書かれることもあるので、次の点を確かめます。

1. 定期代で払うのか、出社した日の実費で払うのか
2. 出社の頻度が変わったときに払い方が切り替わる基準
3. 在宅勤務手当がある場合、交通費とは別に払われるか

在宅勤務の求人の読み方は[リモートワークの求人の読み方](/guide/remote-kyujin/)、福利厚生の欄との関係は[福利厚生の読み方](/guide/fukuri-kosei/)で取り上げています。

## 内定前に確かめたいこと

交通費は金額が小さく見えても、毎月のことなので年間では差が出ます。内定の前後で、次の点を確かめておくと安心です。

- 支給の上限と、自分の通勤経路の定期代
- 経路の決め方と、車・自転車通勤の可否
- 出社の頻度による払い方の違い
- 労働条件通知書や賃金の規程に、通勤手当の決め方がどう書かれているか

入社後に引っ越す予定がある場合は、住所が変わったときの届け出の方法と、通勤手当がいつの分から新しい経路で計算されるかも聞いておきます。転居の時期によっては、最初の数か月の自己負担が変わるためです。住まいにかかわる手当の読み方は[住宅手当・家賃補助の求人の読み方](/guide/jutaku-teate/)もあわせてご覧ください。

## よくある質問

### 「交通費全額支給」なら、新幹線通勤の費用も払われますか？

会社の規程によります。所得税では、新幹線の料金も最も経済的かつ合理的な経路と方法に当たれば非課税の範囲に含まれますが、会社が新幹線通勤を認めるかどうかは別の話です。新幹線を使う予定がある場合は、会社が認める経路と上限の額を、内定前に規程で確かめてください。

### 交通費が月15万円を超えたらどうなりますか？

電車・バス通勤の場合、月15万円を超えた分は給与として所得税の対象になり、払われた月の給与に上乗せして源泉徴収されます。会社が15万円を超える分を払うかどうかは、会社の規程で決まります。

### 交通費が多いと手取りは減りますか？

所得税は限度額まで非課税ですが、通勤手当は社会保険料を決める報酬に含まれます。通勤手当が増えると標準報酬月額が上がり、保険料が増える場合があります。自分の場合にどうなるかは、給与明細と標準報酬月額の区分をもとに確かめてください。
