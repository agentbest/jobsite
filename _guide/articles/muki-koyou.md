無期転換ルールは、同じ会社との有期労働契約が更新されて通算5年を超えると、本人が申し込むことで期間の定めのない契約（無期労働契約）に変わる仕組みです（労働契約法第18条）。有期の求人を見るときは、更新上限が5年より短く設けられていないか、無期転換したあとの条件がどうなるかを確かめると、長く働けるかどうかの見通しが立ちます。転職すると相手の会社が変わるので、前の会社での契約期間は通算されません。

この記事の制度の説明は、2026年11月時点の労働契約法・労働基準法施行規則と厚生労働省の資料にもとづいています。正社員と契約社員の求人の違い全体は[正社員と契約社員の求人の違い](/guide/seishain-keiyaku/)で整理しているので、ここでは無期転換に関わる部分に絞ります。

## 通算5年は「同じ使用者」との契約で数える

労働契約法第18条は、「同一の使用者」との間で結んだ2つ以上の有期労働契約の期間を通算して5年を超える場合に、申込みの権利が生まれると定めています。厚生労働省の無期転換サイトのQ&Aでは、同一の使用者かどうかは事業場ごとではなく、法人や個人事業主の単位で判断するとされています。同じ会社の中で部署や職種が変わっても、期間は通算されます。

反対に、別の会社に転職すれば使用者が変わります。前の会社で有期契約を何年続けていても、新しい会社での通算はその会社との最初の契約から数え始めます。有期の求人に応募するときは、「この会社で5年を超えて働けるか」を考えることになります。

申込権が生まれる時期は、契約期間によって変わります。

| 1回の契約期間 | 申込権が生まれる時期 |
|---|---|
| 1年 | 5回目の更新後の1年間 |
| 3年 | 1回目の更新後の3年間 |

対象は2013年4月1日以降に始まった有期労働契約です。契約と契約の間に一定の空白期間があると、それより前の期間は通算されません（クーリング）。直前の通算期間が1年以上なら、空白が6か月以上でクーリングされます。直前の通算期間が1年未満のときは、必要な空白の長さが短くなります。

| 空白の前の通算期間 | クーリングされる空白の長さ |
|---|---|
| 2か月以下 | 1か月以上 |
| 2か月超〜4か月以下 | 2か月以上 |
| 4か月超〜6か月以下 | 3か月以上 |
| 6か月超〜8か月以下 | 4か月以上 |
| 8か月超〜10か月以下 | 5か月以上 |
| 10か月超 | 6か月以上 |

無期転換サイトのQ&Aでは、このルールはパートタイマーや60歳以上の人などにも適用されるとされています。一方、高度な専門知識を持ち一定期間のプロジェクトに従事する人や、定年後に引き続き雇用される人について、都道府県労働局長の認定を受けた会社では申込権が生まれない特例があります。大学や研究開発法人の研究者・教員などには、申込権が生まれるまでの期間を5年から10年とする特例もあります。特例の対象になる求人では、そのことを原則として書面で示し、説明することが会社に求められています。研究職や、定年後の再雇用の求人に応募するときは、特例の対象かどうかを確かめておきます。

### 派遣で働く場合

無期転換サイトのQ&Aでは、派遣社員の場合、申込みの相手は派遣先ではなく、雇用契約を結んでいる派遣元の会社だとされています。成立するのも派遣元との無期労働契約です。

## 有期の求人票で見る「更新上限」

2024年4月1日から、有期契約の求人では、更新する場合の基準とあわせて、通算契約期間または更新回数の上限がある場合はその上限を示すことになりました。厚生労働省の求職者向けリーフレットの記載例では、「通算契約期間は4年を上限とする」「契約の更新回数は3回を上限とする」のような書き方が示されています。

無期転換との関係で見たいのは、上限が通算5年を超えるかどうかです。上限が5年以内なら、上限まで更新されても無期転換の申込権は生まれません。

### 上限の数え方と書かれ方

労働基準法施行規則のQ&Aでは、更新回数の上限は、労働者と会社の認識が一致する書き方であれば、最初から数えた回数でも残りの回数でもよいとされています。混乱を避ける観点からは、最初から数えた上限を書き、そのうえで今が何回目の更新かを示すことが考えられるとしています。「最長◯年◯月◯日まで」のように雇用期間の終わりの日を示す書き方も、通算契約期間の明示として認められています。

上限がない場合に「上限なし」と書く義務はありません。ただし、同じQ&Aでは、上限の定めがあるのに書面で示されていなかった場合でも、それだけで上限のない契約になるわけではなく、最終的には合意の内容などから司法で判断されるとしています。求人票や労働条件通知書に上限の記載がないときは、「上限はない」という意味か、念のため確かめておきます。

### 更新上限を設けることは違法か

無期転換サイトのQ&Aでは、更新の年限や回数の上限を設けること自体が、直ちに違法になるわけではないとしています。一方で、無期転換を避ける目的で、申込権が生まれる前に雇止めをすることは望ましくないとされ、雇止め法理（労働契約法第19条）によって無効になる場合もあるとされています。雇止めについて困ったときは、都道府県労働局の雇用環境・均等部（室）に設けられた「無期転換ルール特別相談窓口」や、労働基準監督署、社会保険労務士などにご相談ください。

:::view
有期契約の求人をご紹介する中では、更新上限の書き方と、上限のあとの道（正社員登用、無期転換後の職種など）の説明の詳しさが、会社ごとにかなり違う様子をよく見ます。同じ職種で無期転換した方がいるか、転換後にどのような条件で働いているかは、ご質問いただければ企業に確認できます。
:::

## 入社後に会社が示すこと

2024年4月の改正で、無期転換に関して会社が示す事項が増えました。入社してからの更新の場面で行われることですが、応募の段階で知っておくと、更新のときに何が示されるはずかを自分で確かめられます。厚生労働省の無期転換サイトによると、次のとおりです。

| 場面 | 会社が行うこと |
|---|---|
| 最初の契約のあとで更新上限を新しく設ける・短くする | その前に理由を説明する |
| 申込権が生まれる更新のたび | 無期転換を申し込めることを示す |
| 申込権が生まれる更新のたび | 無期転換後の労働条件を示す |
| 申込権が生まれる更新のたび | 正社員などとのバランスを考えた事項（業務の内容、責任の程度、異動の有無・範囲など）の説明に努める |

労働基準法施行規則のQ&Aでは、更新上限を設ける理由の説明は、労働者が納得することまで求められているものではないとされています。また、無期転換の権利を使わないと表明している人にも、申込みができることの明示は必要だとしています。

## 無期転換後の条件をどう読むか

無期転換は契約期間の定めがなくなることで、正社員になることと同じではありません。労働契約法第18条では、転換後の労働条件は、就業規則などで別の定めをしない限り、契約期間を除いて直前の有期契約と同じとされています。

そのため、有期の求人に応募するときは、次の点を面接や内定時に聞いておくと、5年後の姿を考えやすくなります。

- 無期転換した人の労働条件を定めた就業規則があるか
- 転換後に、業務や勤務地の変更の範囲が変わるか
- 正社員登用の制度と、無期転換の関係（どちらを先に選べるか）
- 昇給・賞与・退職手当の有無が、転換後に変わるか

厚生労働省のパンフレットでは、無期転換で業務内容や責任が変わる場合、社内の他の労働者とのバランスを考えた条件にすることを会社に求めています。転換後の勤務地や業務の範囲の読み方は、[勤務地の「変更の範囲」の読み方](/guide/kinmuchi-henko/)と[業務内容の「変更の範囲」の読み方](/guide/gyoumu-henko/)をご覧ください。

## 申込みの方法と転換の時期

無期転換サイトのQ&Aによると、申込みは口頭でも法律上は有効ですが、トラブルを防ぐため書面で行うことがすすめられています。会社に所定の様式があればそれを使い、なければサイトに参考様式があります。

申込みができるのは、通算5年を超える契約期間の初日から末日までの間です。申し込んだ時点で無期労働契約が成立し、実際に無期契約に切り替わるのは、そのときの有期契約が満了した日の翌日からです。会社は申込みを断ることができません。申込権が生まれた契約期間中に申し込まずに更新した場合も、次の契約期間中にいつでも申し込めます。

## 有期の求人の面接で聞いておきたいこと

無期転換を考えて有期の求人に応募するなら、求人票の4項目（契約期間・更新の有無・判断の基準・更新上限）に加えて、次の点を確かめておくと判断しやすくなります。

1. 同じ職種で、通算5年を超えて働いている人がいるか
2. 無期転換を申し込んだ人がいるか、転換後はどの区分で働いているか
3. 無期転換社員に適用される就業規則はどれか
4. 更新の判断で、何がどのように評価されるか

聞きにくい場合は、「長く働きたいと考えているので」と働き続ける意思を先に伝えると、質問の意図が伝わりやすくなります。

:::view
当社への応募は無料で、当社から企業へ推薦する形で選考が進みます。契約社員の求人も含めて検討したい方、反対に期間の定めのない求人に絞りたい方など、雇用形態のご希望を伺ったうえで、サイトに載せていない求人も含めて個別にお探しできます。
:::

## よくある質問

### 前の会社で有期契約を4年続けました。転職先では1年で無期転換できますか？

できません。通算は同じ使用者との契約で数えるので、転職先では、その会社との最初の有期契約から改めて数えます。転職先で通算5年を超えたときに、申込みの権利が生まれます。

### 求人票に「更新上限：通算5年」と書かれていたら、無期転換はできませんか？

通算5年ちょうどで終わる契約なら、5年を超えないため申込権は生まれません。上限まで更新されるとは限らず、各回の更新は書かれた判断の基準で決まります。無期転換を前提に長く働きたい場合は、上限のあとに正社員登用などの道があるか、面接で確かめておきます。上限が設けられた理由を聞いておくと、職種の性質による上限なのか、会社全体の方針なのかが分かります。

### 無期転換を申し込んだら、会社から契約を打ち切られることはありますか？

申し込んだ時点で、無期労働契約が成立していると考えられています。無期転換サイトのQ&Aでは、その後の雇止めでは無期労働契約は終わらないと考えられ、無期労働契約の解雇には客観的に合理的な理由と社会通念上の相当性が必要だとしています。個別の事情については、労働基準監督署や社会保険労務士などにご相談ください。
