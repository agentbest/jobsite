新規事業・事業開発の仕事の範囲は、「仕事がどこから始まるか（起点）」「どこまで持つか（終点）」「営業や開発、契約、運営といった周辺の仕事をどこまで自分で担うか」の3つで、求人ごとに大きく違います。同じ事業開発の求人でも、顧客との議論で事業の種を見つけ、具体化したら別の部署に引き渡す仕事もあれば、テーマ探しから事業の運営と損益（PL）の責任まで1人で持つ仕事もあります。求人票では範囲の境目がはっきり書かれないことが多いため、起点と終点を意識して読むと違いが見えてきます。

## 範囲は「起点」と「終点」で決まる

事業開発の仕事は、どこから始まり、どこで手を離すかで中身が変わります。求人票の書き方から、それぞれ次のように読み取れます。

| | 求人票によく出る書き方 | 範囲の意味 |
|---|---|---|
| 起点：テーマ探索 | 「課題探索から」「自社のアセットを生かした構想」 | 何をやるかを決めるところから担う |
| 起点：決まったテーマ | 「◯◯領域の新規事業」「マーケットプレイスの立ち上げ」 | 領域は決まっており、形にするところから担う |
| 起点：顧客の課題 | 「顧客の業務・経営課題のヒアリング」「顧客との議論から」 | 特定の顧客の課題から事業の種を探す |
| 終点：構想・提案まで | 「提案を固め、他部署へ引き渡すまで」 | 具体化した後は別の担当が進める |
| 終点：検証まで | 「PoC」「プロトタイプ」「価値検証」 | 事業として成り立つかを確かめるところまで |
| 終点：立ち上げまで | 「ローンチ」「初期顧客の獲得」 | 最初の顧客と収益をつくるところまで |
| 終点：運営・PLまで | 「事業責任者」「PL・KPIの設計と達成」「スケール」 | 事業を伸ばし、数字の責任まで持つ |

起点が手前にあるほど、何をやるかを決める責任が重くなります。終点が奥にあるほど、事業の数字や組織の運営まで仕事に入ります。「新規事業のプロジェクトマネジメントから事業責任者へ」のように、入社時と将来で終点が変わる道筋を書く求人もあります。0→1と1→10の段階の違いは[0→1と1→10の求人の違い](/guide/bizdev-zero-to-one/)で扱っています。

## 自社の事業をつくるか、他社の事業づくりを支えるか

事業開発の求人には、自社の新規事業をつくる仕事と、他社の新規事業を支援する仕事の2種類があります。範囲の考え方がかなり違うので、最初に見分けておきます。

- **自社の事業をつくる**：事業会社の新規事業部門や、スタートアップの次の事業づくりです。事業がうまくいくかどうかを自分たちで引き受け、続けるか見直すかの判断にも関わります
- **他社の事業づくりを支える**：新規事業の支援を専門にする会社や、デザイン・開発を請け負う会社の仕事です。事業の最終的な判断は顧客が持ち、自分の範囲は提言、伴走、プロダクト開発などの支援です。支援の案件を獲得する営業の役割が範囲に入ることもよくあります

支援する側の求人は、職種名が「事業開発コンサルタント」「プロデューサー」「パートナー」などになっていることがあります。多くの顧客の事業づくりに関われる一方、事業を自分で持ち続ける経験は積みにくい面があります。また、支援する会社の中でも、顧客との最初の議論と提案を担う役割、プロダクトの開発を進める役割、立ち上げ後の伴走を担う役割のように、範囲を分けて募集していることがあります。自分が支援のどの場面を受け持つのかを確かめておきます。社内で新規事業を担う求人の読み方は[社内新規事業の求人で求められること](/guide/bizdev-intrapreneur/)をご覧ください。

## 周辺の仕事をどこまで自分で持つか

新規事業は少人数で進むことが多く、事業開発の担当者が周辺の仕事を兼ねることがよくあります。仕事内容に次の言葉があれば、その仕事も範囲に入ると考えます。

| 周辺の仕事 | 求人票によく出る書き方 |
|---|---|
| 営業・提案 | 「法人顧客への営業・ソリューション提案」「事業開発セールス」 |
| プロダクト開発 | 「エンジニア・研究者と連携したプロトタイプ設計」「要件定義」 |
| 提携・契約 | 「アライアンスの構築」「契約交渉」 |
| 導入・運営 | 「クライアント導入の推進」「利用促進から保守まで」「事業運営」 |
| マーケティング | 「集客」「市場への浸透」 |
| 組織・人 | 「採用」「メンバーのマネジメント」「チームの立ち上げ」 |

営業や導入の比重が大きい求人では、企画の仕事よりも顧客と向き合う時間が長くなります。開発チームと組む求人では、要件づくりや優先順位の判断に時間を使います。どの周辺の仕事を自分が持ち、どれを他の担当が持つのかは、チームの体制とあわせて確かめます（[配属先とチーム体制の読み方](/guide/bizdev-team-structure/)）。

:::view
事業開発の求人をご紹介していると、求人票では「事業開発」とひとくくりに書かれていても、実際には営業や導入支援の比重が大きいもの、反対に企画と検証が中心で顧客に売る場面が少ないものがあり、範囲の差が大きいと感じます。周辺の仕事の配分や、入社直後に担当するテーマは、ご質問いただければ企業に確認できます。
:::

## 「事業開発」の名前で募集される別の仕事

事業開発や新規事業企画に分類される求人の中には、一般に思い浮かべる新規事業づくりとは中身が違うものもあります。

- **不動産や施設の企画開発**：用地の情報を集め、建物の計画や収支を企画し、開発を進める仕事です。不動産や建築の実務の知識が前提になります
- **拠点の開発**：新しい施設や店舗の場所を探し、地域や関係者と調整して開設まで進める仕事です
- **ライセンス・IPの事業**：キャラクターや作品などの権利を使った商品化や展開を企画し、権利者と交渉する仕事です
- **新規事業のエンジニア**：新しいサービスを開発する技術職で、職種名に「新規事業開発」が付いているものです
- **技術提案・導入推進**：自社の製品を新しい顧客に提案し、導入を進める仕事です

いずれも事業を新しくつくる点は共通していますが、求められる専門性が違います。仕事内容と必須要件を読み、自分の経験と結びつくかを確かめてください。

## 範囲の広さと、求められる経験の関係

範囲の広さは、必須要件の書き方にも表れます。範囲の広い求人と、範囲を絞った求人では、見られる経験が違います。

- **範囲の広い求人**：構想から検証、リリース、成長までを主体となって通して進めた経験を求めます。1つ1つの工程の深さより、全体を通して判断した経験が見られます
- **前半の工程に絞った求人**：大企業との商談の経験や、議論の場で仮説やアイデアを示せる力など、事業の種を見つけて形にする場面の力を求めます。顧客との議論の質が問われます
- **後半の工程に絞った求人**：「事業運営」「KPIの管理」「組織のマネジメント」の経験を求めます。立ち上がった事業を大きくする力が見られます

自分の経験がどの工程に厚いかを整理しておくと、範囲が合う求人を選びやすくなります。全工程の経験がなくても、得意な工程に絞った求人なら、その経験を生かせることがあります。必須要件の読み方は[新規事業・事業開発の求人の必須要件・歓迎要件](/guide/bizdev-requirements/)をご覧ください。

## 範囲が広がる・変わるタイミング

事業開発の範囲は、入社後に変わることが少なくありません。求人票の次のような書き方は、範囲が動く可能性を示しています。

- **「複数の領域の中から担当を決める」**：候補になる事業がいくつかあり、選考や入社後に担当が決まります
- **「既存事業の担当になる可能性もある」**：新規事業ではなく、既にある事業の運営を任される可能性があります
- **「経験に応じて部下をつける」**：入社当初から人の管理が範囲に入ることがあります
- **事業の見直し**：事業を閉じたり方向を変えたりしたときは、担当の範囲も変わります

「（変更の範囲）会社の定める業務」と書かれている場合の読み方は、[業務内容の「変更の範囲」の読み方](/guide/gyoumu-henko/)で扱っています。

## 範囲を確かめるための質問

求人票から範囲が読み切れないときは、面接で次の点を聞いておくと、入社後の仕事が具体的に見えてきます。

1. 担当するテーマは決まっているか。決まっていなければ、いつ、誰が決めるか
2. 自分の担当はどの段階までか。その後はどの部署や担当に引き継ぐか
3. 営業、開発、契約、運営のうち、自分が持つ仕事と、他の担当が持つ仕事
4. 事業の数字（売上やKPI）について、どこまで責任を持つか
5. 一緒に動くメンバーの人数と、報告先
6. 事業を見直すことになった場合、担当の範囲や配属がどう変わるか

事業開発と事業企画の違いは[事業開発と事業企画の求人の違い](/guide/bizdev-vs-planning/)、求人票全体の読み方は[新規事業・事業開発の求人票の読み方](/guide/bizdev-posting/)にまとめています。

:::view
当社からの応募は当社への申し込み（無料）で、当社から企業へ推薦する形で選考が進みます。サイトに載せていない非公開の求人もあり、関わりたい段階や、営業寄り・企画寄りといった範囲のご希望を伺ったうえで、掲載外の求人も含めて個別にお探しできます。
:::

事業開発の求人は[事業企画・経営企画の求人一覧](/jobs/business-planning/)で探せます。求人の動向は[事業企画・経営企画の求人・年収動向](/jobs/business-planning/market/)やページ下の掲載データもご覧ください。

## よくある質問

### 企画や検証の仕事が中心の事業開発の求人を探すには、どこを見ればよいですか？

仕事内容に「市場調査」「仮説の立案」「PoC」「事業計画」などの言葉が多く、「営業」「新規開拓」「受注」の言葉が少ない求人が近いです。ただし少人数の新規事業では、検証のために自分で顧客を訪ねたり、試作の段階で最初の顧客に提案したりする場面もあります。顧客と向き合う比重は面接で確かめてください。

### 法人営業の経験しかありませんが、範囲の広い事業開発の求人に応募できますか？

営業や提案の比重が大きい求人では、法人営業の経験が範囲の一部と重なります。顧客の課題を聞き取り、提案の形にまとめた経験があれば、具体的に説明できるようにしておきます。足りない範囲は、入社後にどう補うかを面接で話せると伝わりやすくなります。

### 他社の新規事業を支援する会社と、事業会社の事業開発では、どちらを選べばよいですか？

どちらが良いということではなく、身につけたい経験で選びます。支援する会社では多くの顧客とテーマに関われ、事業会社では1つの事業を自分で持ち続ける経験を積めます。将来どちらの立場で働きたいかを先に考えておくと、選びやすくなります。
