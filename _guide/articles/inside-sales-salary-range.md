インサイドセールスの求人の年収は、月給の内訳（基本給と、固定残業代を含む手当）、賞与や等級による反映、インセンティブの有無と条件の3つに分けて読むと比べやすくなります。給与欄が「想定年収◯◯〜◯◯万円」だけのことも多いため、その額に残業代・賞与・インセンティブのどれが含まれているかを確かめるのが最初の一歩です。マネージャー候補の求人では、上の帯が管理職の扱いになる書き方もあるので、その意味も読んでおきます。

年収の幅そのものの考え方は[求人の年収の幅はどう決まるのか](/guide/nenshu-haba/)、求人票全体の読み方は[インサイドセールスの求人票の読み方](/guide/inside-sales-posting/)にまとめています。ここではインサイドセールスの給与欄に絞って見ていきます。

## インサイドセールスの給与欄によく出る書き方

掲載中のインサイドセールスの求人では、給与欄に次のような書き方が見られます。

| 書き方 | 読むときのポイント |
|---|---|
| 想定年収の幅だけ | 残業代・賞与・インセンティブが含まれるかが分からない |
| 応相談・経験により決定 | 前職の条件と選考の評価で個別に決める |
| 年収を12分割して月給で支給 | 賞与が別にあるか、残業代が含まれるか |
| 職務手当＝固定残業代 | 何時間分か、超えた分が支払われるか |
| 固定残業代なし・想定残業込みの想定年収 | 何時間の残業を見込んだ額か |
| 年俸制・グレード（等級）制 | 入社時にどの等級に入るかで額が決まる |
| 賞与なし・決算賞与・入社2年目から賞与 | 1年目の受取額に賞与が入るか |
| インセンティブあり | 何の指標で、どの水準から付くか |
| 試用期間中は別の条件 | 期間中の雇用形態や月給が変わるか |

同じ幅の求人でも、固定給だけの幅か、インセンティブを含めた幅かで、受け取り方は大きく変わります。額を比べる前に、何が入った額かをそろえておきます。

## 「想定年収」の前提を読む

インサイドセールスの求人では、「想定年収」「理論年収」という書き方がよく使われます。この額は、ある前提で計算した見込みです。前提として書かれやすいのは、次のようなものです。

- 月に何時間の残業を見込んでいるか（「月平均10時間の時間外勤務が発生した場合の想定年収」など）
- 賞与を標準的な評価で計算しているか
- インセンティブを目標を達成した場合で計算しているか

固定残業代の制度を採っていない求人では、想定年収に一定時間の残業代を足して計算していることがあります。この場合、実際の残業が少なければ年収も想定より下がります。前提の読み方は[「理論年収」「想定年収」の読み方](/guide/riron-nenshu/)でも扱っています。

## 固定残業代と職務手当

インサイドセールスの求人では、「職務手当」「固定残業手当」の名前で、一定時間分の残業代を月給に含める書き方がよく見られます。等級や役職によって、固定残業の時間数や額が変わる書き方もあります。

厚生労働省のQ&Aでは、固定残業代を支払う場合、募集の段階で、固定残業代の計算方法（何時間分でいくらか）、固定残業代を除いた基本給の額、その時間を超えた時間外・休日・深夜の労働に割増賃金を追加で払うことを示す必要があるとしています。固定残業代が法律の計算で出る割増賃金より少ない場合は、差額を支払う必要があるとも説明しています（2026年11月時点で確認）。給与欄の手当がこの3点をそろえて書かれているかを見ておきます。詳しくは[みなし残業（固定残業代）の求人の読み方](/guide/minashi-zangyo/)にまとめています。

## 年俸制・12分割の書き方

年俸制や、年収を12分割して毎月払う書き方では、賞与が別にあるのか、年俸に残業代が含まれるのかを確かめます。厚生労働省の「確かめよう労働条件」では、年俸制であっても、実際の労働時間が法定労働時間を超えれば、原則として割増賃金を支払う必要があると説明しています。年俸に残業代を含める場合は、その部分が区別でき、法定の額以上であることが前提とされています（2026年11月時点）。年俸制の全体像は[年俸制の求人で確認したいこと](/guide/nenpousei/)を参照してください。

:::view
求人をご紹介する中でよく見る傾向として、インサイドセールスの求人は、給与欄が想定年収の幅だけで、賞与やインセンティブの扱いまで書かれていないことが少なくありません。年収の幅に何が含まれているか、入社時の等級の目安が分かるかは、ご質問いただければ企業に確認できます。
:::

## 成果の反映のされ方：インセンティブか、評価と賞与か

インサイドセールスの成果が給与に反映される形は、求人によって分かれます。

- **評価と賞与・昇給で反映する**：商談の数や質を評価の材料にし、賞与や等級の見直しで報いる
- **目標の達成でインセンティブを払う**：「目標を100%達成した場合に支給」のように、達成したときに付く
- **件数や売上に応じて払う**：目標を超えた商談の件数や、新しい契約の月額の売上に応じて付く

インセンティブがある場合は、何の指標で付くかを確かめます。商談を設定した数で付くのか、受注まで進んだ数で付くのかで、追う仕事の中身も変わるためです。指標の読み方は[インサイドセールスのKPIの読み方](/guide/inside-sales-kpi/)、評価のされ方は[インサイドセールスの評価のされ方](/guide/inside-sales-evaluation/)で扱っています。

## 賞与の書き方：1年目の受取額を見る

インサイドセールスの求人の賞与は、「年2回」「業績により決算賞与を支給」「賞与なし」「入社2年目から支給」など、書き方が分かれます。1年目の年収を考えるときは、次の点を確かめます。

- 想定年収に賞与が含まれているか、含まれている場合は何か月分を見込んでいるか
- 賞与が会社の業績、部署の達成度、個人の評価のどれで決まるか
- 入社した時期によって、最初の賞与の算定期間に在籍が足りず、満額にならないことがあるか

「賞与なし」と書かれた求人は、その分を月給に含めていることもあります。月給の水準と合わせて見ると、他の求人と比べやすくなります。賞与の書かれ方は[賞与の書かれ方の読み方](/guide/shoyo-kyujin/)でも扱っています。

## ストックオプションが書かれている場合

成長段階の会社のインサイドセールスの求人では、給与欄にストックオプションが書かれていることがあります。ストックオプションは、将来の株価や上場などの条件によって価値が変わるもので、年収の見込みとは分けて考えます。付与の対象になる時期や、行使の条件を確かめておくとよいでしょう。詳しくは[ストックオプションのある求人の読み方](/guide/stock-option/)にまとめています。

## マネージャー候補の求人：管理職の帯の読み方

マネージャー候補の求人では、年収の幅の上の帯について「この額以上は管理監督者とする」のように書かれていることがあります。労働基準法41条2号は、監督若しくは管理の地位にある者について、労働時間・休憩・休日の規定を適用しないと定めています（2026年11月時点。e-Gov法令検索で確認）。

ただし、管理監督者にあたるかどうかは、肩書きや給与の帯で決まるものではありません。厚生労働省の「確かめよう労働条件」の裁判例の解説では、名称にとらわれず、職務の内容、責任と権限、出退勤を含む労働時間の裁量、地位にふさわしい待遇といった実態に即して判断すべきものとしています。入社時にどの帯で採用されるのか、その場合の残業代の扱いを確かめ、個別の判断が必要なときは労働基準監督署や社会保険労務士などにご相談ください。詳しくは[「管理職」の求人と残業代](/guide/kanrishoku-kyujin/)にまとめています。

## 試用期間中の条件

インサイドセールスの求人の中には、試用期間中は契約社員として雇用し、その後に正社員へ切り替える、試用期間中は月給が異なる、といった書き方もあります。期間の長さと、期間中と期間後の条件の違いを確かめておきます。試用期間の読み方は[試用期間の読み方](/guide/shiyou-kikan/)を参照してください。

## 幅のどこに決まるか：インサイドセールスで見られる材料

求人票には「経験・スキル・前職給与を考慮して決定」と書かれることがよくあります。インサイドセールスの場合、選考で見られやすい材料は次のようなものです。

- インサイドセールスの経験と、追ってきた指標（商談の数、商談から受注に進んだ割合など）
- 法人営業や商談の経験があるか
- リストや施策を自分で作り、改善してきた経験があるか
- 顧客管理の仕組みを整えた経験があるか
- チームの運営や後輩の育成を担ってきたか

等級の制度がある会社では、これらをもとに入社時の等級が決まり、等級の給与の範囲の中で額が決まります。

## 内定時に確かめたい項目

1. 基本給と手当の内訳（固定残業代を兼ねる手当があるか、何時間分か）
2. 想定年収の前提（残業時間、賞与の評価、インセンティブの達成率）
3. 賞与の有無と、入社1年目の扱い
4. インセンティブの指標、支払いの周期、試用期間中の扱い
5. 入社時の等級と、次の評価・昇給の時期

内定時の確かめ方は[インサイドセールスの内定で確認したい条件](/guide/inside-sales-offer-check/)にまとめています。営業の求人や年収の傾向は[営業の求人・年収動向](/jobs/sales/market/)とページ下の掲載データも参考にしてください。

:::view
当社の求人への応募は、当社へのお申し込み（無料）のあと、当社から企業へ推薦する形で選考が進みます。「固定給を中心に安定させたい」「成果がインセンティブで返ってくる環境がよい」のように給与の組み立てに希望がある場合は、面談（オンラインまたは電話）でお伺いし、サイトに掲載していない非公開の求人も含めて個別にお探しできます。
:::

## よくある質問

### インセンティブが無いインサイドセールスの求人は、成果が給与に反映されないのですか

反映されないとは限りません。インセンティブの代わりに、評価を通じて賞与や等級、昇給に反映する求人もあります。評価の時期と基準、評価が賞与と昇給のどちらにどう結びつくかを確かめると、成果の返り方が見えてきます。

### 想定年収に残業代が含まれているか、どこで分かりますか

給与欄の注記を見ます。「固定残業代◯時間分を含む」「月平均◯時間の残業を見込んだ想定年収」のように書かれていれば、残業代を含んだ額です。書かれていない場合は、何が含まれた額なのかを面接や内定の段階で確かめてください。

### マネージャー候補で応募すると、残業代は出なくなりますか

一律には言えません。管理監督者にあたるかどうかは、肩書きではなく、職務の内容や権限、労働時間の裁量、待遇などの実態で判断されます。入社時にどの帯で採用されるかと、残業代の扱いを内定の段階で確かめてください。
