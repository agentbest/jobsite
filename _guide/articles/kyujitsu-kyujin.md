年間休日は、会社が就業規則などで「働かなくてよい日」と決めた休日の1年分の合計で、年次有給休暇は含みません。120日・125日といった数字は、土日の休みに、祝日・年末年始・夏季休暇などをどれだけ足しているかで決まるので、日数だけでなく内訳を確かめることが大切です。厚生労働省の令和7（2025）年就労条件総合調査では、2024年1年間の年間休日総数は1企業平均112.4日、労働者1人平均116.6日でした。

この記事の制度と統計の説明は、2026年11月時点で厚生労働省の資料と法令を確認した内容です。

## 年間休日に含まれるもの・含まれないもの

厚生労働省の就労条件総合調査では、年間休日総数を「企業1年間分の休日の合計日数」と定義しています。ここでいう休日は、就業規則・労働協約・労働契約などで労働義務がないとされた日です。

| 区分 | 例 | 年間休日に含むか |
|---|---|---|
| 週休日 | 日曜日、土曜日など会社が決めた休日 | 含む |
| 週休日以外の休日 | 国民の祝日・休日、年末年始、夏季休暇、会社の記念日などで会社の休日とされている日 | 含む |
| 年次有給休暇 | 本人が取得する有給休暇 | 含まない |
| 休業 | 雇用調整・生産調整のための休業 | 含まない |

求人票の「年間休日120日」も、この考え方で数えられていることが一般的です。ただし、求人票の書き方には決まった様式がないので、夏季休暇や年末年始が年間休日の中に入っているのか、別に付与されるのかは会社によって書き方が違います。

:::caution
夏季休暇を「年次有給休暇の計画的付与」で取る会社もあります。計画的付与は、労使協定で有給休暇の取得日をあらかじめ割り振る制度で、使うのは本人の有給休暇です。会社の休日ではないので、年間休日には含まれません。「夏季休暇あり」と書かれていたら、会社の休日か、有給休暇の計画的付与かを確かめてください。
:::

## 120日・125日はどう組み立てられているか

1年は52週と1〜2日なので、土日を休みにすると、それだけで年間104日前後になります。ここに、祝日（土日と重ならない日）、年末年始、夏季休暇などが加わって、120日や125日といった数字になります。

暦の並びによって、祝日が土日と重なる日数は年ごとに変わります。そのため、同じ「土日祝休み」の会社でも、年間休日の日数は毎年少しずつ変わります。求人票の日数が前年の実績か、今年の予定かを確かめておくと、数字の見方がはっきりします。

逆にいえば、同じ「年間休日120日」でも、組み立て方は会社によって違います。

- 土日祝が休みで、年末年始・夏季休暇を足して120日前後
- 祝日は出勤日で、その分を年末年始や夏季休暇を長くして120日前後
- 平日に休みを取るシフト制で、年間の休日数を120日に合わせている

働き方に合うかどうかは、日数よりも「いつ休めるか」で変わることがあります。家族の予定や通院など、休みの曜日が大事な人は、日数と一緒にカレンダーを確かめるのがおすすめです。シフト制の求人は[シフト制・交代勤務の求人の読み方](/guide/shift-kyujin/)で解説しています。

## 公的な調査の平均と比べる

厚生労働省の令和7（2025）年就労条件総合調査（常用労働者30人以上の民営企業が対象。年間休日は2024年1年間の実績）の結果は次のとおりです。

| 項目 | 結果 |
|---|---|
| 1企業平均の年間休日総数 | 112.4日 |
| 労働者1人平均の年間休日総数 | 116.6日 |
| 年間休日120〜129日の企業の割合 | 37.3% |
| 年間休日130日以上の企業の割合 | 2.0% |

企業規模別の1企業平均は、1,000人以上が117.7日、300〜999人が116.2日、100〜299人が114.5日、30〜99人が111.2日でした。1企業平均・労働者1人平均とも、1985年以降で最も多い日数です。

なお、この調査の平均は、それぞれの企業で最も多くの労働者に適用される年間休日総数をもとにしています。同じ会社の中でも、部署や職種によって休日の決まり方が違うことがあります。

:::view
求人をご紹介する中でよく見る傾向として、求人票の年間休日は会社全体の制度として書かれていることが多く、職種や部署によって休みの曜日や日数が違う場合があります。特に、顧客の営業日に合わせて動く仕事や、交代で対応する仕事では、配属先の休日の決まり方を確かめておくと入社後の違和感を減らせます。求人票に書かれていない配属先の休日は、ご質問いただければ企業に確認できます。
:::

## 法律で決まっている休日は「週1日」

労働基準法第35条では、会社は労働者に毎週少なくとも1回の休日を与えなければならないとされています（4週間を通じて4日以上の休日を与える場合は、この限りではありません）。この法律上の休日を「法定休日」と呼びます。

土日休みの会社で、日曜を法定休日としていれば、土曜は会社が決めた「所定休日」です。この違いは、休日に働いたときの扱いに関わります。法律上の休日労働は法定休日に働いた時間で、割増率は35%以上です。所定休日に働いた時間は、その週の労働時間が40時間を超えた分が時間外労働（割増率25%以上）として扱われます。

祝日を休日にすることは、法律で義務づけられているわけではありません。祝日が休みかどうかは会社の決め方によるので、求人票の「土日祝休み」「土日休み（祝日は出勤の場合あり）」といった書き方の違いを見てください。

## 年間休日と働き方の関係

年間休日は、1日の所定労働時間とも関係します。法定労働時間は週40時間なので、1日の所定労働時間が短い会社ほど、週あたりの出勤日数や年間の休日数の組み方に幅が出ます。年間休日の日数だけでなく、1日の所定労働時間と並べて見ると、年間で働く時間の見当がつきます。勤務時間の書き方は[勤務時間の書かれ方](/guide/kinmu-jikan/)で解説しています。

休みの取りやすさは、年間休日だけでは分かりません。同じ調査では、2024年1年間に付与された年次有給休暇は労働者1人平均18.1日、取得日数は12.1日、取得率は66.9%でした。有給休暇の付与日数と取りやすさの確かめ方は[有給休暇の付与日数と取りやすさの確かめ方](/guide/yukyu/)を参考にしてください。

## 求人票の休日欄でよく見る書き方と読み方

求人票の休日欄は、短い言葉で書かれることが多く、言葉の組み合わせで意味が変わります。よく見る書き方と、そこから読み取れること・確かめたいことを整理します。

| 書き方 | 読み取れること | 確かめたいこと |
|---|---|---|
| 年間休日120日以上 | 年間の休日数の目安 | 内訳と、休みの曜日 |
| 完全週休2日制（土日） | 毎週土日が休み | 祝日が休みかどうか |
| 週休2日制 | 月に1回以上、週2日の休みがある週がある | 毎週2日休めるのか、月に何回か |
| 土日祝休み | 土日と祝日が休み | 年末年始・夏季休暇の日数 |
| 会社カレンダーによる | 会社が年ごとに休日を決める | 前年のカレンダーで休日の配置 |
| 夏季休暇・年末年始休暇 | 長期の休みがある | 会社の休日か、有給休暇の計画的付与か |

会社カレンダーで休日を決める会社では、前年や今年のカレンダーを見せてもらうと、土曜出勤の有無や長期休暇の時期が具体的に分かります。内定後であれば、労働条件通知書や就業規則で休日の定めを確かめることもできます。

「休日」と似た言葉に「休暇」があります。休日はもともと働く義務がない日、休暇は働く義務がある日に申請などで休む日を指すのが一般的です。年次有給休暇のほか、慶弔休暇やリフレッシュ休暇などの会社独自の休暇は、年間休日とは別に書かれていることが多いので、休日欄と休暇欄を分けて読むと整理しやすくなります。

## 面接・オファー面談で確かめたいこと

1. 年間休日の内訳（週休日、祝日、年末年始、夏季休暇など）
2. 夏季休暇や年末年始が年間休日に入っているか、有給休暇の計画的付与か
3. 休みの曜日は固定か、シフトや会社カレンダーで決まるか
4. 祝日が出勤日になる場合があるか
5. 配属予定の部署で、休日出勤がどのくらいあるか。その場合の振替休日や代休の扱い
6. 1日の所定労働時間

週休2日制の書かれ方の違いは[「完全週休2日制」と「週休2日制」の違い](/guide/kanzen-shukyu/)にまとめています。

:::view
当社経由の応募は、当社へのお申し込み（無料）のうえで、当社から企業へ推薦する形で選考が進みます。年間休日の内訳や休日出勤の実態など、面接で聞きにくい項目もご質問いただければ企業に確認できます。サイトに載せていない非公開の求人もあるので、「土日祝休み」「年間休日125日以上」など休日の希望を伺ったうえで、掲載外の求人も含めて個別にお探しできます。
:::

休日の扱いが法律に照らして適切かどうか判断に迷うときは、労働基準監督署や社会保険労務士などにご相談ください。

## よくある質問

### 年間休日120日は多いほうですか

厚生労働省の令和7（2025）年就労条件総合調査では、2024年の年間休日総数は1企業平均112.4日、労働者1人平均116.6日でした。120日は、この平均を上回る水準です。ただし、日数が同じでも、土日祝休みか、平日休みのシフト制かで休み方は大きく違います。内訳とカレンダーも合わせて確かめてください。

### 年間休日に有給休暇は含まれますか

一般的には含まれません。就労条件総合調査の定義でも、年間休日総数には年次有給休暇は含まれないとされています。夏季休暇などを有給休暇の計画的付与で取る会社では、その日は年間休日ではなく有給休暇を使う日になります。求人票の書き方だけで判断がつかないときは、内訳を確かめてください。

### 年間休日が少ない求人は避けたほうがよいですか

日数だけで判断する必要はありません。1日の所定労働時間、残業の実態、有給休暇の取りやすさなどで、実際の働き方は変わります。年間休日が少なめでも1日の所定労働時間が短い会社もあります。何を優先したいかを決めたうえで比べると判断しやすくなります。条件の優先順位の付け方は[希望条件の優先順位の付け方](/guide/kibou-joken/)を参考にしてください。
