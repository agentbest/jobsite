中途採用では、複数の会社を並行して受けるのはふつうの進め方で、会社もそれを前提に選考しています。進めるときの要点は、応募先ごとの選考段階と期限を一つの表で管理すること、選考の進み具合をなるべくそろえること、他社の状況を聞かれたら正直に答えることの3つです。内定が出たときに比べて選べる状態を作るのが、並行して受ける目的です。

## 並行して受けるのはなぜか

1社ずつ順番に受けると、結果が出るまで次に進めないため、転職活動の期間が長くなります。また、内定が1社だけだと、比べる相手がないまま承諾するかどうかを決めることになります。

並行して受けると、次のような利点があります。

- 活動の期間を短くできる
- 内定が出たときに、条件や仕事内容を比べて選べる
- 選考を受けるうちに、自分の希望がはっきりしてくる
- 1社の結果に気持ちが左右されにくくなる

会社の側も、候補者がほかの会社を受けていることは想定しています。だからこそ面接で他社の状況を聞き、内定を出す時期や回答期限を考える材料にしています。並行して受けることに後ろめたさを感じる必要はありません。

一方で、受ける社数が多すぎると、日程の調整や準備が追いつかなくなります。何社くらいが無理のない数かは、今の仕事の忙しさや、選考にかけられる時間で変わります。数の考え方は[何社に応募するのがよいか](/guide/oubo-sushi/)にまとめています。

## 応募先を一つの表で管理する

並行して進めるときに一番の事故は、日程の重複や連絡の漏れです。応募した時点で、応募先を一つの表にまとめておきます。

| 項目 | 書いておくこと |
|---|---|
| 会社名・求人名 | どの求人に応募したか（同じ会社の別求人と区別する） |
| 選考段階 | 書類選考中、一次面接待ち、最終面接済み など |
| 次の予定 | 面接の日時、適性検査の受検期限、課題の提出期限 |
| 結果の目安 | いつごろ連絡が来る予定か |
| 確かめたいこと | 面接で聞きたい質問、聞いた答え |
| 志望度 | 今の時点での優先順位 |

表は、選考が進むたびに書き換えます。特に「次の予定」と「結果の目安」は、日付で書いておくと、連絡が来ないときに問い合わせる目安にもなります。管理のしかたは[応募した求人の管理のしかた](/guide/oubo-kanri/)でも扱っています。

応募書類も、どの会社にどの版を出したかを控えておきます。求人ごとに職務経歴書の書き方を調整している場合、面接で書類の内容を聞かれたときに、出した版と話が食い違わないようにするためです。

## 選考の進み具合をそろえる

並行して受けるときに難しいのは、会社によって選考のスピードが違うことです。ある会社では最終面接まで進んでいるのに、別の会社ではまだ書類選考の結果が出ていない、ということはよく起こります。

進み具合がずれたまま進むと、先に内定が出た会社の回答期限までに、ほかの会社の結果が出そろわないことがあります。なるべくそろえるために、次のような調整をします。

1. 選考が遅い会社には、応募のタイミングを早める
2. 先に進んでいる会社の面接は、無理のない範囲で日程に余裕を持たせる
3. 結果の目安が分からない会社には、次の連絡がいつごろになるか聞いておく
4. 内定が出そうな段階では、回答期限の目安を先に聞いておく

ただし、日程を遅らせすぎると、会社の採用が先に決まってしまうこともあります。そろえることにこだわりすぎず、「どの会社の結果がいつ出そうか」を見通せる状態にしておくことが大切です。詳しくは[複数の選考の進み具合をそろえる方法](/guide/fukusu-senkou/)にまとめています。

:::view
選考のスピードは、会社によって、また同じ会社でも時期によって違います。求人票には選考のステップは書かれていても、次の面接までの間隔や結果が出るまでの目安までは書かれていないことが多くあります。当社経由で選考を受けている求人について、選考がどのくらいの期間で進みそうかは、ご質問いただければ企業に確認できます。
:::

## 準備の負担を減らす

並行して受けると、面接の準備が会社の数だけ必要になります。毎回ゼロから準備していると、時間が足りなくなります。共通の部分と、会社ごとに変える部分を分けておくと、準備が楽になります。

| 共通で使える部分 | 会社ごとに準備する部分 |
|---|---|
| 職務経歴の説明、これまでの成果 | その会社を選んだ理由 |
| 転職を考えた理由 | 求人票の仕事内容と自分の経験の重なり |
| 希望する働き方、入社できる時期 | その会社で確かめたい質問 |

共通の部分は、一度話す内容を整理しておけば、どの会社の面接でも使えます。会社ごとの部分は、面接の前日までに求人票を読み直して準備します。複数の求人を並べて読むと、同じ職種でも会社ごとに求めていることの違いが見えてきます。その違いが、志望理由を組み立てる材料になります。

## 連絡を取りこぼさない

並行して受けていると、各社からの連絡が重なります。面接の日程の候補、適性検査の案内、結果の連絡など、返事が必要なものも多くあります。

- 連絡を受け取ったら、その日のうちに管理表に書き写す
- 日程の候補をもらったら、ほかの会社の予定と重ならないか確かめてから返す
- 返事に時間がかかりそうなときは、いつまでに返すかだけ先に伝える
- 受検期限や提出期限があるものは、期限の前日を目安に済ませる

在職中で日中に連絡を返しにくい場合は、返せる時間帯を決めておくと、返事の遅れを防げます。日程調整の進め方は[面接の日程調整の進め方](/guide/mensetsu-nittei/)にまとめています。

## 他社の選考状況を聞かれたら

面接では、他社の選考状況を聞かれることがよくあります。会社は、内定を出したときに承諾してもらえそうか、いつごろまでに返事をもらえそうかを知りたいと考えています。

答えるときは、正直に、かつ具体的すぎない範囲で伝えます。

- 並行して受けている社数と、おおまかな段階（「ほかに2社、どちらも一次面接を終えたところです」など）
- 同じような職種や業界を受けているか
- 結果が出る時期の見通し

会社名まで言う必要はありません。聞かれた場合も、差し支えのない範囲で答えればかまいません。他社の状況を伏せたり、実際より進んでいるように見せたりすると、あとで日程の相談をするときに話が合わなくなります。答え方は[面接で他社の選考状況を聞かれたときの答え方](/guide/mensetsu-heigan/)でも扱っています。

## 志望度の順番を途中で見直す

並行して受けていると、選考が進むにつれて志望度が入れ替わることがあります。最初は第一希望だった会社の面接で、仕事内容が想像と違うと分かることもあれば、あまり期待していなかった会社の話に引かれることもあります。

志望度は、面接を終えるたびに見直します。見直すときは、印象だけで決めず、面接で聞いた答えを同じ項目で並べて比べます。

- 入社後に任される仕事と役割
- 年収の決まり方と、提示されそうな額の見通し
- 働き方（勤務地、リモート、残業）
- 一緒に働くチームの様子

志望度の低い会社の選考を続けるかどうかも、この時点で判断します。

## 途中で応募先を足すか、絞るか

並行して受けている途中で、応募先を足すか絞るかを考える場面があります。

書類選考で見送りが続いたときや、選考が進むうちに志望度の高い会社が減ってきたときは、応募先を足すことを考えます。新しく応募した会社は、ほかの会社より選考の段階が後ろになるので、内定の時期がずれることも見込んでおきます。足すなら、ずれが大きくなりすぎないよう早めに動きます。

反対に、面接の予定が詰まりすぎて準備が追いつかないときは、志望度の低い会社から絞ります。準備が不十分なまま面接を重ねるより、受ける会社を減らして一社ずつ丁寧に臨むほうが、結果として志望度の高い会社に集中できます。

足すか絞るかの判断は、管理表の「志望度」と「次の予定」を見ながら、1〜2週間ごとに見直すと決めておくと迷いにくくなります。

## 辞退は決めた時点で早めに伝える

並行して受けていると、途中で辞退する会社も出てきます。辞退すると決めたら、早めに伝えるのが相手への配慮です。会社は面接官の時間を確保し、ほかの候補者とも調整しながら選考を進めています。

辞退の連絡は、お礼と辞退の意思を簡潔に伝えれば十分です。理由を詳しく書く必要はありません。伝え方は[選考を辞退するときの伝え方](/guide/senkou-jitai/)にまとめています。

同じ会社に、複数の経路から同じ求人へ応募することは避けます。会社の側で応募の扱いが混乱し、選考に進めなくなることもあります。どの求人にどの経路で応募したかも、管理表に書いておきます。

## 内定が重なったときの考え方

並行して受けていれば、内定の時期が重なることがあります。先に出た内定には回答期限があるため、期限の中でほかの会社の結果を待つのか、先に決めるのかを判断することになります。

- 期限までにほかの会社の結果が出そうなら、その時期を伝えて待ってもらえるか相談する
- 結果が出そうにないなら、ほかの会社に選考を早められないか相談する
- どちらも難しい場合は、手元の情報で判断する

回答期限の延ばし方は[内定の返事はいつまでにするか](/guide/naitei-henji/)、内定どうしの比べ方は[複数の内定で迷ったときの比べ方](/guide/naitei-hikaku/)にまとめています。

:::view
並行して受けるときは、早い段階から「どの会社の結果がいつ出るか」を見通しておくことをおすすめします。内定が出てから日程を整えようとしても、選択肢が限られることが多いためです。当社でお預かりしている求人のうち、サイトに掲載していない求人もありますので、並行して受ける応募先を増やしたいときは、希望を伺ったうえで個別にお探しできます。
:::

## よくある質問

### 並行して受けていることを伝えると、不利になりませんか

並行して受けること自体は、中途採用ではふつうのことで、会社もそれを前提にしています。伝えたことで不利になるというより、正直に伝えておくほうが、日程や回答期限の相談がしやすくなります。

### 同じ業界の会社ばかり受けてもよいですか

問題ありません。同じ業界を受けると、比べる軸がそろうので判断しやすくなります。ただ、面接で志望理由を聞かれたときに、その会社を選ぶ理由を説明できるようにしておきます。

### 志望度が低い会社の選考は、途中でやめたほうがよいですか

続けるかどうかは、面接で知りたいことが残っているかで判断します。話を聞いて志望度が上がることもあります。続ける理由がないと分かった時点で、早めに辞退を伝えてください。
