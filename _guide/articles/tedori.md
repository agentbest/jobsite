手取りは、額面の給与（求人票の年収や月給）から、社会保険料と税金を引いた額です。会社員の場合、引かれる主なものは**健康保険料（40〜64歳は介護保険料も）・子ども・子育て支援金・厚生年金保険料・雇用保険料の社会保険料と、所得税・住民税の税金**です。社会保険料は給与にほぼ比例してかかり、税金は控除を引いた後の所得にかかるため、手取りの割合は年収や家族の状況、住んでいる地域で変わります。

この記事では、2026年11月時点の制度をもとに、引かれるものの仕組みと、簡易な目安の計算を説明します。

## 給与から引かれるものの全体像

| 区分 | 項目 | 何をもとに計算するか |
|---|---|---|
| 社会保険料 | 健康保険料 | 標準報酬月額・標準賞与額×保険料率 |
| 社会保険料 | 介護保険料（40〜64歳） | 同上 |
| 社会保険料 | 子ども・子育て支援金 | 同上（2026年4月分から） |
| 社会保険料 | 厚生年金保険料 | 標準報酬月額・標準賞与額×保険料率 |
| 社会保険料 | 雇用保険料 | 支払われた賃金×保険料率 |
| 税金 | 所得税（復興特別所得税を含む） | 給与所得控除や各種控除を引いた後の所得 |
| 税金 | 住民税 | 前年の所得 |

このほか、会社によっては財形貯蓄や社宅費、労働組合費などが引かれることがあります。

## 社会保険料の仕組み（2026年11月時点）

### 健康保険料・介護保険料・子ども・子育て支援金

協会けんぽの場合、健康保険料率は都道府県支部ごとに違います。令和8年度（2026年3月分から）の料率は、たとえば東京都で9.85%です。40〜64歳の人は介護保険料率1.62%（全国一律）が加わります。

2026年4月分（5月納付分）からは、子ども・子育て支援金が加わりました。協会けんぽの支援金率は0.23%（全国一律）です。

協会けんぽの説明では、保険料は事業主と被保険者が折半で負担します。健康保険組合に加入している会社では、料率や負担の割合が協会けんぽと違うことがあります。

### 厚生年金保険料

日本年金機構の説明では、厚生年金保険料率は18.3%で固定されていて、事業主と被保険者が半分ずつ負担します。本人の負担は標準報酬月額の9.15%です。

### 標準報酬月額の決まり方

健康保険と厚生年金の保険料は、実際の給与そのものではなく、給与を区切りのよい幅に当てはめた「標準報酬月額」にかかります。日本年金機構の説明では、対象になるのは基本給だけでなく、残業手当や通勤手当なども含めた税引き前の給与で、原則として毎年4〜6月の給与の平均で決まり、9月から翌年8月まで使われます。転職した場合は、入社時の給与をもとに決まります。

### 雇用保険料

厚生労働省の案内では、令和8年度（2026年4月〜2027年3月）の雇用保険料率は、一般の事業で労働者負担5/1,000、事業主負担8.5/1,000です。

:::view
求人をご紹介する中でよく見る傾向として、年収が同じくらいの求人でも、賞与の割合、固定残業代の有無、手当の内訳によって、毎月の手取りの感覚は変わります。転職先を比べるときは、年収の合計だけでなく、毎月の給与と賞与の内訳を見ておくと、入社後の家計の見通しが立てやすくなります。内訳が求人票に書かれていない場合は、ご質問いただければ企業に確認できます。
:::

## 税金の仕組み（2026年11月時点）

### 所得税

所得税は、給与の収入から給与所得控除を引いて「給与所得」を出し、そこから社会保険料控除・基礎控除・扶養控除などを引いた「課税される所得金額」にかかります。国税庁の説明では、税率は5%から45%の7段階で、所得が高い部分ほど高い税率がかかります。2026年分は、所得税額の2.1%の復興特別所得税もあわせて納めます。

給与所得控除と基礎控除は、令和7年分、令和8年分と続けて改正されています。国税庁の説明では、令和8年分・令和9年分の給与所得控除の最低額は74万円で、令和8年分の改正は2026年12月1日に施行されます。基礎控除の額は合計所得金額によって変わります。年分ごとの金額は国税庁のページで確かめてください。

毎月の給与から引かれる所得税は、概算で源泉徴収されたものです。国税庁の説明では、1年間の源泉徴収額の合計と、1年間に納めるべき税額との差は年末調整で精算されます（→[転職した年の源泉徴収票と年末調整](/guide/gensen-choshu/)）。

### 住民税

総務省の説明では、個人住民税の所得割の標準税率は10%（道府県民税4%・市町村民税6%）で、前年1月1日から12月31日までの所得をもとに計算します。これに均等割（標準で年4,000円）と、2024年度からの森林環境税（国税・年1,000円）が加わります。税率や均等割の額は自治体の判断で変わることがあります。

会社員は原則として、会社が給与から天引きして市町村に納める「特別徴収」です。前年の所得で決まるため、年収が上がった年の翌年に住民税が増える、というずれが生まれます。転職の時期によって支払い方が変わることは[転職と住民税](/guide/juminzei-tenshoku/)で説明しています。

### 通勤手当の扱い

国税庁の説明では、電車・バスで通勤する場合、最も経済的かつ合理的な経路での通勤手当は1か月15万円までが所得税の非課税です。一方で、標準報酬月額には通勤手当も含まれるため、社会保険料の計算には入ります。

## 簡易な目安の計算

社会保険料がどのくらいかを、2026年11月時点で確かめた料率を使って計算してみます。**これは仕組みを理解するための簡易な見積もりで、実際の額とは一致しません。**

前提：協会けんぽ東京都支部、40歳未満（介護保険料なし）、標準報酬月額が30万円、その月に支払われた賃金が30万円。

| 項目 | 計算 | 本人負担（月額） |
|---|---|---|
| 健康保険料 | 30万円×9.85%÷2 | 14,775円 |
| 子ども・子育て支援金 | 30万円×0.23%÷2 | 345円 |
| 厚生年金保険料 | 30万円×18.3%÷2 | 27,450円 |
| 雇用保険料 | 30万円×5/1,000 | 1,500円 |
| 社会保険料の合計 | | 44,070円 |

この前提では、社会保険料だけで額面の約15%になります。実際には、ここから所得税と住民税も引かれます。所得税と住民税は、扶養家族の有無、ほかの控除、前年の所得などで大きく変わるため、ここでは計算していません。実際の端数処理や、加入している健康保険組合の料率によっても額は変わります。

:::caution
40〜64歳の人は介護保険料（料率1.62%の折半）が加わります。また、住民税は前年の所得で決まるため、転職して年収が変わった年は、手取りの変化が翌年にずれて表れます。
:::

## 求人票の年収から手取りを考える順番

求人票の年収から手取りを考えるときは、次の順で分けると見通しが立てやすくなります。

1. **年収を月給と賞与に分ける**：社会保険料は、月給には標準報酬月額、賞与には標準賞与額をもとにかかります。賞与の割合が大きいと、毎月の手取りは年収から想像するより少なくなります
2. **月給から社会保険料を見積もる**：上の簡易な計算のように、加入する健康保険の料率、厚生年金、雇用保険の料率をかけます
3. **所得税は年末調整・源泉徴収票で確かめる**：毎月の源泉徴収は概算なので、年間の税額は年末調整で決まります
4. **住民税は前年の所得で考える**：転職した年の住民税は、前の年の所得をもとにしています

求人票の年収に、固定残業代やインセンティブ、見込みの賞与が含まれている場合は、その部分が実際に払われるかどうかでも手取りが変わります。年収の内訳の読み方は[「理論年収」「想定年収」の読み方](/guide/riron-nenshu/)、[基本給と手当の違い](/guide/kihonkyu-teate/)で説明しています。

## 転職で手取りが変わりやすい場面

- **賞与の割合が違う**：年収が同じでも、賞与の割合が大きい会社では毎月の手取りは少なくなります（→[賞与の書かれ方の読み方](/guide/shoyo-kyujin/)）
- **健康保険の加入先が変わる**：協会けんぽと健康保険組合では料率が違うことがあります（→[社会保険完備とは](/guide/shakai-hoken/)）
- **加入する協会けんぽの支部が変わる**：協会けんぽの料率は都道府県支部ごとに違うため、勤務先の事業所がどの都道府県にあるかで料率が変わることがあります
- **退職から入社まで間が空く**：国民健康保険・国民年金への切り替えが必要になることがあります（→[転職時の年金・健康保険の切り替え](/guide/nenkin-hoken/)）

:::view
当社の求人への応募は、当社への申し込み（無料）で、当社から企業へ推薦する形で選考が進みます。毎月の給与と賞与の内訳、加入する健康保険など、手取りを考えるうえで必要なことは、ご質問いただければ企業に確認できます。面談はオンラインまたは電話で受けています。
:::

## よくある質問

### 年収の何割くらいが手取りになりますか

一律には言えません。社会保険料は給与にほぼ比例しますが、税金は控除の額や前年の所得で変わり、累進税率のため年収が高いほど手取りの割合は下がる傾向があります。上の簡易な計算のように、まず社会保険料を出し、税金は年末調整や源泉徴収票で実額を確かめるのがおすすめです。

### 転職すると手取りが一時的に変わるのはなぜですか

標準報酬月額は入社時の給与で決まり直し、住民税は前年の所得で決まるためです。年収が上がった場合、社会保険料は入社直後から変わりますが、住民税が増えるのは翌年度からになります。

### 手取りの計算で迷ったときはどこに相談できますか

社会保険料は加入している健康保険（協会けんぽ・健康保険組合）や日本年金機構、所得税は税務署、住民税はお住まいの市区町村で確かめられます。個別の判断が必要な場合は、税理士や社会保険労務士などにご相談ください。年収が下がる転職を考えている場合は[年収が下がる転職を考えるときの判断材料](/guide/genshu-tenshoku/)も参考にしてください。
