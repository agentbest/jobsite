客先常駐の求人は、契約を2本に分けて読むと整理できます。1本は自分と所属会社の雇用契約、もう1本は所属会社と客先（顧客）の契約です。客先との契約が請負や準委任なら、仕事の指示や勤務時間の管理は所属会社が行うのが前提で、客先から直接指示を受けて働く形なら労働者派遣として扱われます。求人票では、この2本目の契約がどの形かと、現場で誰の指示で働くかを確かめるのが読み方の中心です。

この記事の制度の説明は、2026年11月時点の法令と厚生労働省の告示で確かめた内容です。SEの求人に絞った読み方は[客先常駐のSEの求人の読み方](/guide/web-se-kyakusaki/)で扱っているので、ここでは職種を問わず使える読み方をまとめます。

## 客先常駐の求人には契約が2本ある

客先常駐で働くときの関係は、次のようになります。

| 契約 | 当事者 | 決まること |
|---|---|---|
| 雇用契約 | 自分と所属会社 | 給与、勤務時間、休日、評価、雇用形態 |
| 業務の契約 | 所属会社と客先 | 何の業務を、どの形で引き受けるか（請負・準委任・労働者派遣など） |

求人票に書かれているのは、主に1本目の雇用契約です。2本目の契約は求人票に書かれないことが多く、案件ごとに違うこともあります。ところが、現場で誰から指示を受けるか、勤務時間を誰が管理するかは、2本目の契約の形で変わります。客先常駐の求人で「入ってみたら思っていた働き方と違った」となりやすいのは、この2本目が見えにくいためです。

## 客先との契約の形

所属会社と客先の契約は、主に次の3つの形をとります。

| 形 | 法律上の考え方 | 現場での指示 |
|---|---|---|
| 請負 | 仕事の完成を約束し、その結果に報酬が支払われる（民法632条） | 所属会社が行う |
| 準委任 | 法律行為ではない事務を委託する（民法656条が委任の規定を準用） | 所属会社が行う |
| 労働者派遣 | 自分が雇う労働者を、雇用関係はそのままに、他人の指揮命令を受けて働かせる（労働者派遣法2条1号） | 派遣先（客先）が行う |

請負と準委任は、どちらも所属会社が業務を引き受ける形です。現場が客先のオフィスでも、仕事の進め方の指示や勤務時間の管理は所属会社が行う前提になります。一方、労働者派遣法2条1号は、自分が雇う労働者を他人の指揮命令を受けて働かせることを労働者派遣としています。客先が直接指示を出して働かせる形は、この定義に当たります。

労働者派遣法32条は、派遣元の会社が労働者を派遣労働者として雇い入れようとするときは、あらかじめその旨を本人に明示しなければならないとしています。求人票や労働条件通知書に「派遣労働者として雇用」といった記載があれば、客先の指示で働く前提の雇用です。紹介予定派遣の場合はその旨も明示されます。紹介予定派遣の流れは[紹介予定派遣の求人とは](/guide/haken-shoukai/)で扱っています。

## 求人票での書かれ方

客先常駐の求人は、勤務地の欄や仕事内容の欄に手がかりがあります。

| 書き方 | 読み取れること |
|---|---|
| 勤務地：顧客先 / プロジェクト先 / 取引先構内 | 働く場所が客先になる |
| 勤務地：本社または顧客先 | 案件によって自社勤務と客先勤務がある |
| 常駐型 / 持ち帰り型 | 客先で働くか、自社に持ち帰って作業するか |
| チームで参画 / 少人数での参画 | 同じ現場に所属会社の社員がいるか |
| 派遣労働者として雇用 | 客先の指揮命令を受けて働く雇用 |

あわせて、「就業の場所の変更の範囲」も見ておきます。厚生労働省によると、令和6年4月1日から、募集のときに示す事項として、従事すべき業務の変更の範囲と就業の場所の変更の範囲が加わりました。ただ、変更の範囲が「会社の定める場所」のように広く書かれていると、どのくらいの頻度で現場が変わるかまでは分かりません。読み方は[勤務地の「変更の範囲」](/guide/kinmuchi-henko/)と[勤務先が変わる可能性がある求人の確認点](/guide/kyakusaki-henkou/)にまとめています。

## 37号告示が示す線引き

請負の形で契約していても、実態が派遣と変わらない働き方は、いわゆる偽装請負として問題になります。その線引きを示しているのが、厚生労働省の「労働者派遣事業と請負により行われる事業との区分に関する基準」（昭和61年労働省告示第37号、通称37号告示）です。

37号告示の2条は、請負の形の契約で働かせる会社であっても、次のどちらにも当てはまる場合を除き、労働者派遣事業を行う会社として扱うとしています。

1. **自分の雇う労働者を、自分で直接管理していること**
   - 業務の進め方の指示や、仕事ぶりの評価を自分で行う
   - 始業・終業の時刻、休憩、休日、休暇の指示や管理、残業や休日出勤の指示や管理を自分で行う（単に時間を把握するだけでは足りない）
   - 服務規律の指示や管理、配置の決定や変更を自分で行う
2. **請け負った業務を、相手から独立して処理していること**
   - 業務に必要な資金を自分の責任で調達し、支払う
   - 事業主としての法律上の責任をすべて負う
   - 自分で用意した機械・設備・材料で処理するか、自分の企画や専門的な技術・経験で処理する。単に労働力を提供するだけではない

さらに3条は、これらに当てはまる形をとっていても、法律の規定を免れるために故意に偽装したもので、本当の目的が労働者派遣にあるときは、労働者派遣事業を行う会社であることを免れないとしています。

求職者の立場で大事なのは1つ目です。現場で日々の指示を出すのは誰か、勤怠や残業の指示は誰から来るのか、評価は誰がつけるのか。この3点が所属会社の側にあるかどうかで、契約の形と実際の働き方が合っているかを考えられます。

## 雇用契約の側で確かめること

2本目の契約に目が向きがちですが、1本目の雇用契約にも、客先常駐ならではの確かめどころがあります。求人票と労働条件通知書で、次の点を見ておきます。

| 項目 | 確かめたいこと |
|---|---|
| 勤務時間 | 所属会社の所定労働時間で働くのか、現場ごとに始業・終業の時刻が変わるのか |
| 休日 | 所属会社のカレンダーか、客先の休日に合わせるのか |
| 残業 | 残業の指示と申請の流れ。固定残業代がある場合は、超えた分の扱い |
| 通勤 | 現場が変わったときの交通費の扱い、遠い現場になったときの相談先 |
| 給与 | 案件の単価や稼働の状況で給与が変わる仕組みがあるか |

現場ごとに勤務時間や休日が変わる求人では、求人票の書き方が「現場による」となっていることがあります。その場合は、直近の現場での例を聞いておくと、生活の見通しが立てやすくなります。

## 間に何社も入る形に気をつける

客先常駐では、客先と所属会社の間に別の会社が入ることがあります。職業安定法44条は、法律で認められた場合を除き、労働者供給事業を行うことと、その事業を行う者から供給された労働者を自分の指揮命令の下で働かせることを禁じています。

間に入る会社が多いほど、自分が誰の指示で働き、誰に勤怠を報告するのかが分かりにくくなります。面接では、客先と所属会社の間に他の会社が入るか、入る場合に現場の指示は誰から来るのかを聞いておくと安心です。個別の契約が適正かどうかの判断は専門的なので、不安があるときは労働局や社会保険労務士などにご相談ください。

:::view
求人をご紹介する中でよく見るのは、同じ「客先常駐あり」の求人でも、チームで現場に入り所属会社のリーダーが指示を出す会社もあれば、1人で現場に入る会社もある、ということです。求人票の一行だけでは、どちらの形なのかは分かりません。当社経由で応募する求人なら、現場の体制や指示の出し方など求人票に書かれていない点は、ご質問いただければ企業に確認できます。
:::

## 面接で確かめたいこと

客先常駐の求人では、次の点を面接やオファー面談で聞いておくと、入社後の働き方が具体的になります。

- 客先との契約は、請負・準委任・派遣のどれが多いか
- 現場で日々の指示を出すのは誰か。所属会社の社員が同じ現場にいるか
- 勤怠や残業の申請はどこに出し、誰が承認するか
- 評価は誰がつけるか。現場での働きぶりを所属会社がどう把握するか
- 1つの現場にいる期間はどのくらいか。現場を変えたいときに相談できるか
- 案件と案件の間の期間はどう過ごすか。その間の給与の扱いはどうなるか
- 自社に戻って働く道や、社内の仕事に移る道があるか

答えが「案件による」のときは、直近の案件や、同じ職種の社員の例を聞くと、ふだんの働き方が見えてきます。

聞き方に迷うときは、「入社後の働き方を具体的に知りたい」という目的を添えると、責めるような印象になりにくくなります。たとえば「現場では、どなたから作業の指示を受けることが多いですか」「勤怠の承認はどなたがされますか」のように、事実を尋ねる形で聞くと、会社側も答えやすくなります。

答えを聞いたら、雇用契約の内容と照らし合わせておきます。たとえば派遣の契約が多いと聞いたのに、労働条件通知書に派遣労働者として雇う旨の記載がない、といった食い違いがあれば、内定の承諾前に確かめておくと安心です。

## 客先常駐の求人を比べるときの軸

客先常駐の求人は、契約の形だけで良し悪しが決まるわけではありません。比べるときは、次の軸で並べると整理しやすくなります。

| 軸 | 見るところ |
|---|---|
| 指揮命令 | 現場の指示を誰が出すか |
| 体制 | チームで入るか、1人で入るか |
| 期間 | 1つの現場にいる期間と、現場が変わる頻度 |
| 場所 | 通勤できる範囲か、リモートの可否は現場次第か |
| 評価 | 所属会社が仕事ぶりをどう把握し、給与に反映するか |

:::view
客先常駐の働き方が合うかどうかは、現場の体制や期間で大きく変わります。客先常駐を避けたい、または体制が整った会社で働きたいといった希望があれば、その条件を伺ったうえで、サイトに載せていない非公開の求人も含めて個別にお探しできます。
:::

## よくある質問

### 客先常駐で、客先の担当者から作業の指示を受けるのは問題ですか

契約の形によります。労働者派遣の契約なら、客先が指示を出すのは前提どおりです。請負や準委任の契約なのに、客先が日々の作業の進め方や勤務時間を直接管理している場合は、37号告示の考え方に照らして問題になることがあります。判断に迷うときは、労働局や社会保険労務士などにご相談ください。

### 求人票に「客先常駐」と書かれていなくても、客先で働くことはありますか

あります。勤務地の欄が「本社」でも、仕事内容に「顧客先での作業あり」などと書かれていることがあります。勤務地の欄と仕事内容の欄、変更の範囲の欄をあわせて読み、気になるときは選考の中で確かめてください。入社後の配属先によって客先で働くかどうかが変わる求人もあるため、配属の決まり方もあわせて聞いておくと安心です。

### 客先常駐から自社勤務に移ることはできますか

会社によって違います。社内の開発部門や管理部門に移る道がある会社もあれば、客先での業務が中心の会社もあります。面接で、実際に移った社員がいるか、どんな条件で移れるかを聞いてみてください。
