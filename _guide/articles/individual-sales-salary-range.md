個人営業の求人の年収は、基本給と手当でできた固定給、賞与、成約や売上に応じたインセンティブの3つに分けて読むと比べやすくなります。固定給の中に固定残業代や営業手当がどう入っているか、インセンティブが何に連動して、いつ支払われるかで、同じ年収の幅でも中身は大きく変わります。経験者と未経験で給与を分けた書き方や、年数ごとの年収例は、その前提を確かめてから読みます。

求人票の給与欄の基本と、歩合給の保障給の決まりは[個人営業の求人票の読み方](/guide/individual-sales-posting/)で扱っています。年収の幅そのものの考え方は[求人の年収の幅はどう決まるのか](/guide/nenshu-haba/)にまとめています。ここでは個人営業の給与欄に絞って、書き方ごとの読み方を見ていきます。

## 個人営業の給与欄によく出る書き方

個人営業の求人の給与欄は、商材や会社によって書き方がかなり違います。掲載中の求人でよく見る形を並べると、次のとおりです。

| 書き方 | 読むときのポイント |
|---|---|
| 月給の幅＋固定残業代の内訳 | 何時間分か、超えた分が支払われるか |
| 営業手当・職務手当を含む月給 | 手当が固定残業代を兼ねるのか、別の手当なのか |
| 未経験と経験者で分けた給与 | 自分がどちらに当たるかで見込める幅が変わる |
| 入社年数ごとの年収例 | 例の人の前提（役職・成果）を確かめる |
| 賞与の回数が多い・決算賞与あり | 回数より、何で額が決まるかを見る |
| 報奨金・インセンティブ・歩合 | 成約ごとか、期ごとか、基準を超えた分だけか |
| 入社後しばらくの保障の手当 | いつまで付くか、その後の固定給はいくらか |
| 資格手当・車両手当 | 資格を取ると増えるか、車の使い方の前提 |
| 想定年収の幅だけ | 何が含まれた額なのかが分からない。内訳を確かめる |

同じ「想定年収◯◯〜◯◯万円」でも、ある求人は固定給と標準的な賞与の幅、別の求人はインセンティブを含めた幅ということがあります。額の大小を比べる前に、何が入った額なのかをそろえることが大事です。

## 固定給の中身：手当の名前と固定残業代

個人営業の求人では、月給の中に「営業手当」「職務手当」のような手当が入っていることがよくあります。この手当には、主に次の2つの性格があります。

- **一定時間分の残業代として払う手当**（固定残業代）：「◯時間分の時間外手当として支給」と書かれる
- **営業という仕事に対して払う手当**：残業代とは別に支払われる

求人票に「営業手当（◯時間分の時間外労働を含む）」とあれば前者と読めます。「残業代は別途全額支給」と書かれ、手当が残業代と分かれていれば後者です。前者の場合、実際の残業が固定の時間を超えたときに差額が支払われるかを確かめます。「時間外手当が営業手当を超えた場合は差額を支給」のように、手当と残業代の関係を説明している求人もあります。

厚生労働省のQ&Aでは、固定残業代を支払う場合、募集の段階で、固定残業代の計算方法（何時間分でいくらか）、固定残業代を除いた基本給の額、その時間を超えた時間外・休日・深夜の労働に割増賃金を追加で払うことを示す必要があるとしています。あわせて、固定残業代が法律の計算で出る割増賃金より少ない場合は、差額を支払う必要があると説明しています（2026年11月時点で確認）。月給の幅に応じて固定残業代の額や時間が変わる書き方もあるので、自分の提示額では何時間分になるのかを見ておきます。

## 成果で変わる部分：何に連動し、いつ計上されるか

個人営業のインセンティブや報奨金は、次の3点で読み分けます。

1. **何に連動するか**：契約の件数、売上、粗利、手数料の収入など。粗利に連動する場合は、値引きや経費を引いたあとの額で計算されることがある
2. **いつ計上されるか**：契約したときか、引き渡しや入金が済んだときか。住宅や不動産のように契約から引き渡しまで時間がかかる商材では、受け取る時期が後ろにずれることがある
3. **どの周期で支払われるか**：成約ごと、毎月、四半期ごと、半期ごと。「半期の粗利が一定額を超えた場合に、その一定割合を支給」のように、基準を超えたときだけ付く書き方もある

個人の成果だけで決まるのか、店舗やチームの達成度も入るのかも見ておきます。反響営業のように会社がお客様の入り口を用意する求人と、自分で接点を作る求人では、成果の出方も変わります。インセンティブの一般的な読み方は[インセンティブ・歩合の求人の読み方](/guide/incentive-kyujin/)にまとめています。

:::view
求人をご紹介する中でよく見る傾向として、個人営業の求人は、同じ商材でも「固定給を厚くして賞与で報いる会社」と「固定給を抑えて成約ごとのインセンティブを大きくする会社」に分かれます。年収の幅だけでは区別がつかないことも多いため、固定給と成果で変わる部分の割合や、インセンティブの計上の時点は、ご質問いただければ企業に確認できます。
:::

## 入社後しばらくの保障の読み方

個人営業の求人には、「入社後3か月は業務給を保障する手当を月給に含む」のように、立ち上がりの期間だけ固定給を上乗せする書き方があります。成約が出るまでの期間を支える仕組みですが、読み落とすと、保障が終わったあとに月給が下がって見えることになります。

確かめたいのは次の点です。

- 保障の手当がいつまで付くか
- 保障が終わったあとの固定給はいくらか
- 保障の期間中に成約したとき、インセンティブはどう扱われるか

歩合で決まる賃金について、労働基準法27条は、出来高払制その他の請負制で使用する労働者には、使用者が労働時間に応じた一定額の賃金を保障しなければならないと定めています（2026年11月時点。e-Gov法令検索で確認）。保障の額や自分の契約がどれにあたるかなど、個別の判断が必要なときは、労働基準監督署や社会保険労務士などにご相談ください。

## 資格手当・車両手当・賞与の書き方

個人営業の求人では、固定給とインセンティブのほかに、次のような書き方もよく見られます。

- **資格手当**：業務に関わる資格を持っていると月々の手当が付く。入社後に資格を取った場合も対象になるか、取得の時期で額が変わるかを確かめる
- **車両手当・ガソリン代**：自分の車を仕事に使う場合に付く手当として書かれることがある。社用車があるのか、自分の車を使うのか、手当が実際の費用に見合うかを見ておく
- **賞与の回数が多い書き方・決算賞与**：回数の多さより、会社の業績と個人の成果のどちらで額が決まるかが大事。年収の幅や年収例に賞与が含まれているかも確かめる

手当は、条件が変わると外れるものもあります。たとえば、自分の車を使わなくなったときの車両手当の扱いなどです。年収の見込みに手当を含めて考えるときは、どの条件で付く手当なのかをあわせて確かめておきます。

## 年収例・モデル年収の読み方

個人営業の求人では、「入社1年目」「3年目・主任」のように、年数や役職ごとの年収例が書かれていることがよくあります。読むときは次の点を確かめます。

- 例の額のうち、固定給の年額と、賞与・インセンティブの合計がそれぞれいくらか
- 例の人は、どの役職で、どんな成果を出した人か
- 例の額に、残業代や手当がどこまで含まれているか

年収例の内訳を「月給の年額＋賞与とインセンティブ」と分けて書いている求人もあります。この場合、成果で変わる部分が大きい例ほど、同じ水準に届くかは成果次第です。年収例に書かれた年数や年齢は、その人の例を示すもので、応募の条件や見込みの約束ではありません。自分の場合にどの例が近いかは、面接で確かめるのが確かです。

## 幅のどこに決まるか：個人営業で見られる材料

求人票には「経験・能力を考慮して決定」「前職の給与を考慮」と書かれることがよくあります。個人営業の場合、選考で見られやすい材料は次のようなものです。

- **同じ商材・近い商材の経験**：住宅、不動産、保険、車など、扱ってきた商材が近いか
- **お客様の入り口の違い**：反響営業の経験か、自分で接点を作る営業の経験か
- **成約の実績の続き方**：一度の大きな成約より、目標を続けて達成してきたか
- **業務に関わる資格**：資格手当の対象になる資格を持っているか
- **後輩の指導や店舗の取りまとめ**：主任や店長などの役割を担ってきたか

給与欄が「未経験」と「経験者」で分かれている場合は、どこからが経験者として扱われるのかも確かめます。要件の読み方は[個人営業の求人の必須要件・歓迎要件](/guide/individual-sales-requirements/)を参考にしてください。

## 内定前に確かめたい項目

給与の内訳は、内定の段階で書面で確かめるのが確かです。労働基準法施行規則5条では、賃金の決定・計算・支払の方法などを書面で示すことが決まっています（2026年11月時点。e-Gov法令検索で確認）。次の項目を書き出しておくと、確認の漏れが減ります。

1. 基本給と手当の内訳（固定残業代を兼ねる手当があるか）
2. 固定残業代の時間数と、超えた分の支払い
3. インセンティブの計算の基準、計上の時点、支払いの周期
4. 入社後の保障の期間と、その後の固定給
5. 賞与の回数と、何で額が決まるか

内定時の確かめ方は[個人営業の内定で確認したい条件](/guide/individual-sales-offer-check/)、評価のされ方は[個人営業の評価のされ方](/guide/individual-sales-evaluation/)にまとめています。営業の求人や年収の傾向は[営業の求人・年収動向](/jobs/sales/market/)とページ下の掲載データも参考にしてください。

:::view
求人をご紹介する中でよく見る傾向として、個人営業の求人では、手当の名前が同じでも中身が会社ごとに違います。「営業手当」が固定残業代を兼ねる会社もあれば、残業代とは別に払う会社もあります。求人票の書き方では分かりにくい手当の性格は、応募の前に確かめておくことをおすすめします。
:::

## よくある質問

### インセンティブが大きい求人と、固定給が高い求人はどう比べればよいですか

まず固定給どうし（固定残業代を除いた基本給どうし）で比べ、そのうえで、インセンティブがどんな条件で、いつ支払われるかを見ます。インセンティブは成果次第で上下するため、成果が出なかった月や、立ち上がりの期間にどのくらい受け取れるかを考えておくと、生活の見通しが立てやすくなります。

### 「未経験」の給与で提示されたら、経験者の給与にはいつ上がりますか

会社によって違います。一定の期間や成果で経験者の給与に切り替える会社もあれば、昇給や昇格の中で上がっていく会社もあります。切り替えの基準と時期を、内定の段階で確かめておくと安心です。

### 年収例に書かれた額は、入社1年目から目指せますか

年収例は、その会社で成果を出した人の例として書かれていることが多く、入社時の提示額とは別のものです。例の額のうち、成果で変わる部分がどのくらいかを確かめ、固定給の部分で生活の見通しを立てたうえで判断するのが現実的です。
