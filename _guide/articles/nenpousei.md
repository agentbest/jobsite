年俸制の求人では、「年俸に賞与や残業代が含まれているか」「年俸を何回に分けて、毎月いくら払われるか」「翌年の年俸がどう決まるか」の3点を確認します。年俸制でも賃金は毎月1回以上払われる必要があり、管理監督者などを除けば、法定労働時間を超えて働いた分の割増賃金（残業代）も支払われます。「年俸制だから残業代は出ない」とは限らないので、求人票と労働条件通知書で内訳を読むことが大切です。

この記事の制度の説明は、2026年11月時点の労働基準法と厚生労働省・労働局の資料にもとづいています。

## 年俸制は「1年単位で賃金の額を決める」決め方

年俸制は、賃金の額を1年単位で決める仕組みです。月給制が「1か月いくら」で決めるのに対し、年俸制は「1年でいくら」を先に決め、それを分けて支払います。

ただし、1年分をまとめて払うわけではありません。労働基準法第24条第2項で、賃金は毎月1回以上、一定の期日を定めて支払わなければならないとされています。賞与など臨時に支払われる賃金は例外ですが、年俸の大部分は毎月の給与として振り分けられます。

求人票では、次のような書き方がよく見られます。

| 求人票の書き方 | 読み取ること |
|---|---|
| 年俸◯◯円（12分割して毎月支給） | 年俸をそのまま12等分し、賞与は別にないか、別に業績で支給される |
| 年俸◯◯円（一部を賞与時期に支給） | 年俸の一部が賞与として決まった月に払われる。毎月の額は12分割より少ない |
| 年俸◯◯円＋業績賞与 | 年俸とは別に、成績や業績で変わる賞与がある |
| 年俸◯◯円（固定残業代◯時間分を含む） | 年俸の中に一定時間分の残業代が入っている |

毎月の手取りや生活の計画に関わるのは、年俸の総額よりも「毎月いくら払われるか」です。何回に分けて払うのかが書かれていなければ、確認しておきたい点です。

## 年俸制でも残業代は出る

厚生労働省のQ&Aでは、年俸制を採っていても、実際の労働時間が法定労働時間を超えれば、原則として割増賃金を支払う必要があると説明されています。労働基準法第37条の割増賃金の決まりは、労使で「払わない」と取り決めても無効になる強行規定とされています。

割増賃金が要らないとされるのは、主に次のような場合です。

- 労働基準法第41条で労働時間の規定が適用されない、管理監督者や機密の事務を取り扱う人など
- 裁量労働制などのみなし労働時間制が適用され、年俸がそのみなし時間に応じて決められている場合

管理職の求人で年俸制が採られている場合も、管理監督者にあたるかどうかで扱いが変わります。詳しくは[「管理職」の求人と残業代](/guide/kanrishoku-kyujin/)をご覧ください。

### 年俸に残業代を含める場合の条件

年俸の中に一定時間分の残業代を含めて払うこともできます。その場合、厚生労働省のQ&Aでは、割増賃金にあたる部分と通常の賃金にあたる部分を区別でき、割増賃金にあたる部分が法定の額以上であれば違反にはならないとされています。そのうえで、含まれている時間を超えて働いた分の割増賃金は、別に支払う必要があります。

考え方はみなし残業（固定残業代）と同じです。年間の残業代相当額を毎月均等に分けて払う場合でも、その月の実際の残業時間で計算した額に届かなければ、差額を払う必要があるとされています。何時間分の残業代がいくら含まれているかの読み方は、[みなし残業（固定残業代）の求人の読み方](/guide/minashi-zangyo/)で整理しています。

### 裁量労働制と組み合わさった求人

年俸制の求人の中には、裁量労働制などのみなし労働時間制とあわせて採られているものもあります。労働局の資料では、みなし労働時間制が適用され、年俸がみなし労働時間に応じて決められている場合は、割増賃金を別に払う必要がないケースとして挙げられています。

厚生労働省の求職者向けリーフレットでは、裁量労働制を採る求人には「企画業務型裁量労働制により、◯時間働いたものとみなされます」のような記載が必要だとされています。年俸制の求人で残業代の記載が見当たらないときは、裁量労働制の記載がないかも確かめます。どの制度が適用されるかで残業代の考え方が変わるので、分からなければ面接で聞いておきます。

## 賞与部分の扱いは「年俸が確定しているか」で変わる

年俸制で見落としやすいのが、賞与として払われる部分の扱いです。

残業代を計算するときの「1時間あたりの賃金」には、労働基準法施行規則第21条で除外される賃金があります。家族手当・通勤手当・住宅手当などのほか、「臨時に支払われた賃金」と「1か月を超える期間ごとに支払われる賃金」も除外されます。一般の賞与は、成績などで額が変わり、1か月を超える期間ごとに払われるため、計算から除かれます。

ところが、労働局の資料では、毎月払う部分と賞与として払う部分を合わせて年俸額が先に確定している場合は、賞与として払う部分も除外できず、確定した年俸額をもとに割増賃金を計算する必要があるとされています（平成12年3月8日基収78号）。

求人票の書き方に当てはめると、次のように読めます。

- **「年俸◯◯円（一部を賞与時期に支給）」**：賞与時期の分も含めて額が決まっているなら、残業代の計算のもとは年俸全体になる
- **「年俸◯◯円＋業績賞与」**：業績で変わる賞与の部分は、一般の賞与と同じく計算から除かれる

実際の計算方法は会社の賃金規程によります。内定時には、残業代の計算のもとになる額がどう決まっているかを聞いておくと、毎月の給与明細を読むときに迷いません。

:::view
求人をご紹介する中では、同じ「年俸制」でも、年俸の中に賞与や固定残業代を含める会社と、年俸とは別に業績賞与を払う会社があり、求人票の年俸の額だけでは比べられないことがよくあります。年俸の内訳や何回に分けて払うかが求人票に書かれていない場合は、ご質問いただければ企業に確認できます。
:::

## 翌年の年俸の決め方を確認する

年俸制では、評価などをもとに翌年度の年俸を決め直す仕組みになっていることがあります。上がることもあれば、評価によっては下がることもある、という点は月給制と違うところです。

確認しておきたいのは次の点です。

1. 年俸を決め直す時期（年に1回か、いつ決まるか）
2. 何をもとに決めるか（評価制度・目標の立て方）
3. 下がることがあるか、下がる場合の幅に決まりがあるか
4. 年度の途中で入社した場合、初年度の年俸がどう決まるか

常時10人以上の労働者がいる会社では、賃金の決め方・計算や支払いの方法・昇給に関する事項を就業規則に定めることが、労働基準法第89条で決められています。年俸の決め直しのルールは就業規則や賃金規程で確かめられることがあるので、内定時に内容を説明してもらえるか聞いてみるとよいでしょう。

労働契約法では、労働条件は労使の合意で変更できると定められています（第8条）。年度の途中で年俸を下げると言われたなど、個別の事情で判断が要る場合は、労働基準監督署や社会保険労務士などにご相談ください。

## 内定・オファー面談で確かめたいこと

年俸制の求人で内定が出たら、労働条件通知書で次の点を確かめます。

- 年俸の総額と、何回に分けて払うか（毎月の支給額）
- 年俸に含まれるもの（賞与・固定残業代・各種手当）
- 固定残業代を含む場合、その時間数と金額、超えた分の扱い
- 年俸とは別の賞与・インセンティブの有無と決まり方
- 翌年の年俸の決め直しの時期と方法

月給制の求人と比べるときは、次のように項目をそろえて並べると、違いが見えやすくなります。

| 比べる項目 | 年俸制の求人 | 月給制の求人 |
|---|---|---|
| 毎月の支給額 | 年俸÷分割回数（賞与時期の分を除く） | 月給 |
| 賞与 | 年俸に含むか、別に業績賞与があるか | 別に支給されるか、算定方法 |
| 固定残業代 | 年俸に含まれる時間数と金額 | 月給に含まれる時間数と金額 |
| 残業代の計算のもと | 確定した年俸額か、毎月の部分だけか | 月給（除外される手当を除く） |
| 翌年の決まり方 | 年俸の改定時期と評価の仕組み | 昇給の時期と評価の仕組み |

オファー面談の進め方は[オファー面談で確認すること](/guide/offer-mendan/)、書面の読み方は[内定通知書と労働条件通知書の違い](/guide/naitei-tsuuchi/)で整理しています。複数の内定で月給制と年俸制を比べる場合は、[複数の内定で迷ったときの比べ方](/guide/naitei-hikaku/)も参考にしてください。

:::view
当社への応募は無料で、当社から企業へ推薦する形で選考が進みます。年俸制の求人は、提示額の内訳や翌年の決め方が分かりにくいと感じる方が多い求人です。面談はオンラインまたは電話で受けていて、年俸の内訳や評価の仕組みなど求人票に書かれていない点は、ご質問いただければ企業に確認できます。
:::

## よくある質問

### 年俸制だと、残業しても残業代はまったく出ないのですか？

いいえ。厚生労働省のQ&Aでは、年俸制でも法定労働時間を超えて働けば、原則として割増賃金を支払う必要があるとされています。例外は、管理監督者など労働基準法第41条にあたる人や、みなし労働時間制が適用されて年俸がそれに応じて決められている場合などです。年俸に残業代が含まれている場合も、含まれた時間を超えた分は別に払われる必要があります。

### 年俸制の求人に書かれた額は、月給制の年収と同じように比べてよいですか？

そのままでは比べにくいことがあります。年俸に賞与や固定残業代が含まれているか、年俸とは別に業績賞与があるかで、同じ額でも中身が変わるためです。年俸の内訳と毎月の支給額、残業代の扱いをそろえてから比べてください。

### 年度の途中で入社すると、初年度の年俸はどうなりますか？

初年度の年俸の決め方（入社月からの月割りにするか、次の改定時期までの扱いをどうするかなど）は、会社の賃金規程によって違います。法律で一律に決まっているものではないので、内定時に初年度の支給額と次の改定時期を確認しておくと安心です。
