経理の求人に書かれた年収は、「決算期の残業がどう扱われるか」「賞与が年収にどれだけ含まれているか」「管理職として採用されるか」の3点で、同じ額でも中身が大きく変わります。経理は月末・月初や四半期・年度の決算に仕事が集まりやすい職種なので、残業代の扱いは年収の比べ方に直結します。提示額が幅のどこに決まるかは、決算をどの段階まで自分で回せるかが主な材料になります。

年収の幅そのものの考え方は[求人の年収の幅はどう決まるのか](/guide/nenshu-haba/)、理論年収の前提は[「理論年収」「想定年収」の読み方](/guide/riron-nenshu/)にまとめています。ここでは経理の求人に絞って見ていきます。

## 経理の給与欄によく出る書き方

経理の求人の給与欄を並べて読むと、次のような書き方が見られます。

| 書き方 | 読むときのポイント |
|---|---|
| 月給と固定残業代の内訳 | 何時間分か。決算期にその時間を超えたら追加で支払われるか |
| 残業代は全額支給、固定残業代なし | 年収の幅に残業代が含まれているか。決算期の残業の目安 |
| 賞与の月数の実績つき | 年収の幅が、その月数を前提に計算されているか |
| 決算賞与あり | 会社の業績で決まる追加の賞与。毎年出るとは限らない |
| 年収を分割して月給と賞与に配分 | 賞与の一部があらかじめ額の決まったものか |
| 管理監督者として採用する場合の注記 | その場合は固定残業代が付かない、などの書き方 |
| 役職ごとのモデル年収 | 主任・課長代理・部長代理などの例。入社時の額とは別のもの |

同じ経理の求人でも、固定残業代を月給に含めて書く会社と、残業代を別に全額払う会社があります。年収の幅の数字だけを比べる前に、どちらの形かをそろえることが大事です。

## 決算期の残業代の扱いを確かめる

経理の仕事は、月次決算の締めの時期や、四半期・年度の決算の時期に忙しさが集まります。そのため、給与欄の残業代の書き方は、決算期の働き方とあわせて読みます。

**固定残業代がある求人**では、月給に一定時間分の残業代が含まれています。厚生労働省は、固定残業代を支払う場合、募集の段階で「計算方法」「固定残業代を除いた基本給の額」「その時間を超えた時間外労働・休日労働・深夜労働の割増賃金を追加で支払うこと」を明示する必要があるとしています。固定残業代が法律の計算で出る割増賃金より少ない場合は差額を支払う必要がある、ともしています（いずれも2026年11月時点で確認）。決算期に固定の時間を超えた月は、超えた分が追加で支払われるのが前提です。

**残業代を全額支給する求人**では、決算期に残業が増えた月は、そのぶん受け取る額も増えます。この場合、求人票の年収の幅に残業代が含まれているか、含まれているなら月何時間を想定しているかを確かめておくと、実際の受取額との差を見込めます。

どちらの形でも、確かめたいのは「平均の残業時間」だけでなく、「決算期の残業時間」です。平均が少なくても、年度の決算の月に残業が集中する職場はあります。四半期ごとに決算を締めて開示する会社と、年1回の決算が中心の会社でも、忙しさの波の形は変わります。比べるときは、固定残業代を除いた基本給どうしで並べ、決算期の働き方を面接で聞いておくと安心です。詳しくは[みなし残業（固定残業代）の求人の読み方](/guide/minashi-zangyo/)にまとめています。

:::view
求人をご紹介する中でよく見るのは、経理の求人の「平均残業時間」の書き方が、会社によって年間の平均だったり、通常月の目安だったりすることです。年度の決算の月や監査の時期にどのくらい残業があるか、その月の残業代がどう支払われるかは、求人票からは読み取りにくい点です。ご質問いただければ企業に確認できます。
:::

## 賞与と決算賞与：年収に含まれているかを分ける

経理の求人では、「賞与年2回（前年実績◯か月分）」のように、賞与の月数の実績が書かれていることがよくあります。年収の幅がこの月数を前提に計算されている場合、会社の業績や評価で月数が変われば、年収も上下します。

「決算賞与あり」と書かれている場合は、通常の賞与とは別に、会社の業績によって出る追加の賞与です。決算賞与を年収の幅に含めて書いている求人と、含めずに書いている求人があるので、どちらかを確かめましょう。入社した年の賞与が在籍期間に応じて減ることもあります。決算賞与の読み方は[決算賞与の書かれ方の読み方](/guide/kessan-shoyo/)、賞与全般は[賞与の書かれ方の読み方](/guide/shoyo-kyujin/)で扱っています。

年俸をあらかじめ決めて、月給と賞与に分けて払う形の求人もあります。厚生労働省の「確かめよう労働条件」では、年俸制で年俸の一部をあらかじめ額の決まった賞与として払う場合、その部分は割増賃金の計算の基礎から除外できないと説明しています（2026年11月時点）。残業代の計算に関わる点なので、賞与の部分が業績で変わるものか、額が決まっているものかを確かめておきましょう。

## マネージャー候補の求人と管理監督者

経理のマネージャー候補や責任者候補の求人では、「管理監督者での採用可能性もあり。その場合、固定残業代は支給対象外」のような注記を見かけます。厚生労働省の「確かめよう労働条件」では、管理職の役職に就いたからといってすぐに労働基準法上の管理監督者に当たるわけではなく、職務の内容や権限、勤務の仕方、待遇などの実態で判断すると説明しています。また、管理監督者に適用されないのは労働時間・休憩・休日に関する規定で、深夜の割増賃金や年次有給休暇の規定は適用されるとしています（2026年11月時点）。

決算期に残業が集まりやすい経理では、管理監督者として採用されるかどうかで、繁忙期の受取額の考え方が変わります。管理監督者の場合とそうでない場合の額を分けて書き出し、自分がどちらで採用されるかを内定の段階で確かめてください。考え方は[「管理職」の求人と残業代](/guide/kanrishoku-kyujin/)にまとめています。個別の事情で判断が要るときは、労働基準監督署や社会保険労務士などにご相談ください。

## 会社の段階で変わる給与の組み立て

経理の求人の給与欄は、会社の段階によっても書き方が変わります。

- **上場企業の求人**：等級ごとの給与の範囲や、役職ごとのモデル年収が書かれていることがあり、入社時にどの等級に入るかで額が決まる
- **上場準備中の会社の求人**：年収の幅に加えて、ストックオプションの付与が書かれていることがある。株式報酬は年収の外として分けて考える
- **成長途中の会社の求人**：「グレード制度を加味して決定」「現在の年収を考慮」のように、前職の条件と社内の基準をすり合わせて決める書き方が見られる

モデル年収は、その会社で昇格した場合の例で、入社時の額とは別のものです。例の額に残業代や賞与がどこまで含まれているか、例の役職に上がるまでに何が求められるかを確かめましょう。ストックオプションの確かめ方は[ストックオプションがある求人で確認したいこと](/guide/stock-option/)にまとめています。

## 幅のどこに決まるか：経理で見られる材料

求人票には「経験・能力を考慮して決定」「前職の給与を考慮」と書かれることが多く見られます。経理の場合、選考で見られやすい材料は次のようなものです。

- **決算の段階**：月次決算の補助か、月次・年次の決算を主担当として締めてきたか
- **専門領域**：連結決算、開示書類の作成、税務申告、監査法人とのやり取りなど
- **会社の種類**：上場企業や上場準備中の会社で、監査や開示の水準に慣れているか
- **仕組みづくり**：経理の業務の見直しや、会計システムの入れ替えに関わったか
- **人を率いた経験**：メンバーの仕訳のレビューや、チームの取りまとめ

決算の段階の考え方は[経理の求人の必須要件・歓迎要件](/guide/accounting-requirements/)で詳しく扱っています。資格は、給与欄に「経験・資格に応じる」と書かれていたり、資格手当の対象になっていたりする求人もあります。手当がある場合は、どの資格が対象で、いくら支給されるかを確かめましょう。書かれ方は[資格手当の書かれ方と確認点](/guide/shikaku-teate/)を参考にしてください。

## 内定の段階で確かめたい項目

1. 基本給と手当の内訳（固定残業代がある場合は時間数と超過分の支払い）
2. 決算期の残業時間の目安と、その月の残業代の支払われ方
3. 賞与の回数・月数の前提と、決算賞与が年収に含まれているか
4. 管理監督者として採用されるかどうか、深夜の割増の扱い
5. 入社時の等級と、次の昇給・昇格の時期

評価の仕組みは[経理の評価のされ方](/guide/accounting-evaluation/)、内定時の確かめ方は[経理の内定で確認したい条件](/guide/accounting-offer-check/)にまとめています。経理の求人や年収の傾向は、ページ下の掲載データや[管理部門の求人・年収動向](/jobs/corporate/market/)もご覧ください。

:::view
当社の求人への応募は、当社へのお申し込み（無料）のあと、当社から企業へ推薦する形で選考が進みます。経理の求人は、決算の段階や会社の種類で条件の組み立てが変わるため、これまで担ってきた決算の範囲と、年収や働き方の希望を面談（オンラインまたは電話）でお伺いし、サイトに掲載していない非公開の求人も含めて個別にお探しできます。
:::

## よくある質問

### 固定残業代のある求人と、残業代を全額支給する求人はどちらがよいですか

どちらがよいかは、実際の残業時間で変わります。固定の時間より残業が少ない月が多ければ固定残業代のある求人のほうが受取額は安定し、決算期に大きく増えるなら全額支給の求人では増えたぶんが反映されます。基本給どうしで比べたうえで、決算期の残業の目安を確かめて判断してください。

### 賞与の実績が書かれていない経理の求人は、どう考えればよいですか

賞与の回数だけが書かれていて実績が無い場合は、年収の幅に賞与がどれだけ含まれているかが分かりません。面接や内定の段階で、年収の幅が賞与を何か月分として計算しているかを聞いておくと、比べやすくなります。

### 簿記の資格を持っていると、提示額は上がりますか

資格の有無だけで提示額が決まるとは限らず、決算をどの段階まで回してきたかも大きな材料になります。一方で、資格手当を設けている会社や、等級を決める材料の1つにしている会社もあります。給与欄に資格の扱いが書かれていない場合は、手当や評価の対象になるかを確かめてください。
