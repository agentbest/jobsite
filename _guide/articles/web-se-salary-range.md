SE（Web・オープン系）の求人に書かれた年収の幅は、会社の立場によって作り方が違います。SIerや受託開発の会社では、PG・SE・PL・PMといった役割の段階に等級が結びつき、年収例や賞与の実績月数とあわせて書かれることがよくあります。自社サービスや事業会社では、年俸制や「月給×12」の形で書かれることがよくあり、賞与の扱いもSIerとは違います。同じ幅の数字でも、どの役割で迎えるのか、賞与がどこまで含まれているのかで読み方が変わります。

年収の幅の一般的な読み方は[求人の年収の幅はどう決まるのか](/guide/nenshu-haba/)で扱っています。この記事では、SEの求人に特有の書かれ方に絞って説明します。

## SIerの求人：役割の段階と等級が対応している

SIerや受託開発の会社のSEの求人では、プロジェクトの中の役割が、そのまま社内の等級と対応していることがよくあります。年収の幅は、何段階かの等級をまとめた範囲として書かれていると読むと分かりやすくなります。

| 役割の段階 | 主な仕事 | 求人票に出る手がかり |
|---|---|---|
| PG（プログラマー） | 詳細設計に沿った実装とテスト | 「製造・テスト」「プログラミング」 |
| SE | 基本設計・詳細設計、顧客との仕様の調整 | 「設計から」「要件の取りまとめ」 |
| PL（プロジェクトリーダー） | チームの進捗と品質の管理、メンバーの指導 | 「リーダー」「チームの取りまとめ」 |
| PM（プロジェクトマネージャー） | プロジェクト全体の計画、予算、顧客との合意 | 「PM」「プロジェクト全体の責任者」 |

給与欄に「職級手当」「職務手当」「役職手当」とあれば、等級や役割によって加わる手当です。等級ごとに固定残業代の時間数が違うと書く求人もあり、同じ会社の中でも等級が上がると月給の内訳が変わることがあります。資格の取得に応じた手当や報奨金を給与欄に書く会社もあり、毎月の手当か一時金かで年収への入り方が違います。どの段階で迎える想定かは、必須要件と仕事内容から見当をつけます。役割ごとの違いは[SE（Web・オープン系）の求人のポジション別の違い](/guide/web-se-grade/)、リーダー層の求人は[リーダー候補のSEの求人で求められること](/guide/web-se-lead/)で扱っています。

## 年収例の読み方

SIerのSEの求人では、給与欄に「年収例」「年収提示例」として、経験年数や役割ごとの例が並んでいることがよくあります。年収例は、その会社で実際にその役割に就いた人の例や、会社が示すモデルで、同じ額が提示されることを約束するものではありません。

年収例を読むときは、次の点を確かめます。

- **役割**：例に書かれた役割（PG・SE・PL・PM）が、自分のこれまでの経験に近いか
- **含まれるもの**：残業代、賞与、手当が含まれた額か
- **時点**：入社時の提示額の例か、入社から何年か経ったあとの例か

年収例に年齢が添えられていても、比べる軸は年齢ではなく役割と経験です。自分が担ってきた工程や、チームの中での役割に近い例を選んで読みましょう。

## 賞与の書かれ方：実績月数・12分割・決算賞与

SEの求人の賞与の書き方は、会社によってかなり違います。

- **実績の月数**：「昨年度実績◯か月分」と前年の実績を書く。今年も同じとは限らず、会社の業績と個人の評価で変わる
- **月給に含める**：「給与には賞与を12分割した金額が含まれます」と書き、賞与にあたる分を毎月払う
- **決算賞与**：通常の賞与とは別に、決算の結果に応じて出す。出るかどうかは年によって変わる
- **インセンティブ賞与**：通常の賞与はなく、成果に応じた賞与を年に何回か出す

想定年収に賞与を含めて書いている場合は、どの月数や評価を前提にしているかで、実際の受け取りが変わります。賞与を12分割して月給に含める会社の月給は、賞与を別に払う会社の月給と同じ基準では比べられません。年収に何が含まれているかの読み方は[「理論年収」「想定年収」の読み方](/guide/riron-nenshu/)で扱っています。

:::view
求人をご紹介する中でよく見る傾向として、SEの求人は、SIerと自社サービスの会社とで給与の作り方が違い、月給だけ、想定年収だけを並べても比べにくいことがよくあります。賞与が月給に含まれているのか、別に出るのかで、同じ数字の意味が変わるためです。求人票に書かれていない等級の基準や賞与の決まり方は、ご質問いただければ企業に確認できます。
:::

## 「初年度想定年収」と2年目以降の違い

SEの求人の給与欄には、「初年度想定年収」と書かれているものがあります。入社した年は、賞与の算定期間に在籍していた期間が短く、賞与が満額にならなかったり対象外になったりすることがあるので、1年目の年収を分けて示していると考えられます。「賞与は入社2年目以降」と書く求人もあります。

この場合、初年度の年収と、2年目以降の年収は別のものとして読みます。初年度想定年収にどの手当が含まれているのか、賞与はいつから満額の対象になるのか、評価の最初の時期はいつかを確かめておくと、前職と比べたときの見通しが立ちます。

前職の年収の扱いにも、会社ごとの違いがあります。「前職給与を十分に考慮」「現年収を考慮」と書く求人のほか、条件付きで現年収を下回らないようにすると書く求人もあります。どの条件で、どの額を基準にするのかは会社によって違うので、気になる場合は確かめておきましょう。年収の交渉の進め方は[年収交渉はできるのか](/guide/nenshu-kosho/)で扱っています。

## 自社サービス・事業会社の求人の書かれ方

自社サービスを持つ会社や事業会社のSEの求人では、給与欄の書き方がSIerと違うことがよくあります。

| 項目 | SIer・受託開発に多い書き方 | 自社サービス・事業会社に多い書き方 |
|---|---|---|
| 給与の形 | 月給＋賞与（実績の月数） | 年俸制、または「月給×12」 |
| 等級の手がかり | PG・SE・PL・PMの段階、職級手当 | グレード、エンジニア共通の等級 |
| 年収の例 | 経験年数・役割ごとの年収例 | 幅だけを書き、例は少ない |
| 改定の頻度 | 年1回が中心 | 半期ごと、または年1回 |

これは傾向で、すべての求人に当てはまるわけではありません。事業会社のSEの求人では、会社全体の給与規程に沿って、営業や管理部門と同じ等級の仕組みで決まることもあります。その場合は、ITの職種としての専門性がどう評価されるのかを確かめておくと、入社後の年収の動きが見通せます。会社の立場ごとの違いは[SIerと自社サービス企業のSEの求人の違い](/guide/web-se-sier-vs-own/)、事業会社の求人は[事業会社のSEの求人の読み方](/guide/web-se-in-house/)で扱っています。

## 残業代の扱い：全額支給か、固定残業代か

SEの求人では、残業代の書き方も会社によって分かれます。「残業代は1分単位で全額支給」と書く求人もあれば、月給に固定残業代を含める求人もあります。

厚生労働省の「確かめよう労働条件」では、時間外労働には1時間当たりの賃金の2割5分以上、1か月60時間を超える時間外労働には5割以上の割増賃金が必要とされています（2026年11月時点で確認）。固定残業代を払う場合は、募集の段階で、算定の基礎になる時間数と金額、固定残業代を除いた基本給、超えた分を追加で払うことを明らかにすることが求められています（スタートアップ労働条件・厚生労働省、2026年11月時点で確認）。

また、「該当する役職の方は裁量労働制・管理監督者を適用」のように、等級によって労働時間の扱いが変わると書く求人もあります。その場合、同じ求人の中でも、固定残業代のかわりに専門職や管理職の手当が払われる形に切り替わることがあります。提示された等級でどちらの扱いになるのかを確かめておきましょう。

客先常駐の働き方がある求人では、「就業先によって勤務時間が変わる」と書かれていることもあります。その場合、残業の多さは現場ごとに変わるので、固定残業代の時間数と、これまでの現場での実際の残業時間を並べて聞いておくと見当がつきます。固定残業代の読み方は[みなし残業（固定残業代）の求人の読み方](/guide/minashi-zangyo/)、客先常駐の求人は[客先常駐のSEの求人の読み方](/guide/web-se-kyakusaki/)で扱っています。

## 内定のときに確かめたい内訳

| 項目 | 確かめたいこと |
|---|---|
| 等級と役割 | PG・SE・PL・PMのどの段階で迎えるか、その等級の定義 |
| 基本給と手当 | 職級手当・職務手当の額と、等級が上がったときの変わり方 |
| 残業代 | 全額支給か固定残業代か、固定なら時間数と超えた分の払い方 |
| 賞与 | 想定年収に含まれるか、前提の月数、12分割の有無 |
| 昇給 | 改定の頻度と、評価との結びつき |
| 働く場所 | 客先常駐の有無と、現場によって変わる条件 |

## よくある質問

### PGとして経験を積んできましたが、SEの等級で提示されることはありますか
あります。設計の一部を担当してきた経験や、顧客との仕様の調整に関わった経験があれば、SEの段階として評価されることがあります。職務経歴書では、実装した機能だけでなく、設計のどこに関わったかを書いておくと、等級の判断の材料が伝わりやすくなります。

### 年収例と同じ額が提示されると考えてよいですか
年収例はあくまで例です。提示額は、選考での評価、前職の条件、会社の等級の決まりで決まります。年収例は、自分がどの役割で迎えられたらどのあたりになりそうかの目安として使い、実際の提示額は内定のときに内訳とあわせて確かめましょう。

### 客先常駐の求人では、現場によって給与が変わりますか
基本給や等級は会社の規程で決まり、現場によって変わらないのが一般的な書き方です。ただし、残業代や現場への手当、勤務時間は現場によって変わることがあります。案件の条件が見直されたときに昇給の機会を設けると書く会社もあるので、給与と現場の条件の関係を確かめておきましょう。
