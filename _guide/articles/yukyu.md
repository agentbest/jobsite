年次有給休暇は、労働基準法39条により、入社から6か月続けて働き、その期間の8割以上出勤すると10日が付与され、その後は勤続に応じて増えていきます。付与される日数の最低ラインは法律で決まっているので、求人で確かめたいのは「いつ付与されるか」と「実際に取れているか」の2点です。付与の時期は求人票や労働条件通知書で、取りやすさは面接やオファー面談での質問で確かめます。

この記事の制度の説明は、2026年11月時点の法令と厚生労働省の資料で確かめた内容です。

## 法律で決まっている付与日数

労働基準法39条1項は、雇入れの日から6か月継続して勤務し、全労働日の8割以上出勤した労働者に、10労働日の有給休暇を与えなければならないと定めています。2項で、その後は1年ごとに日数が加わります。通常の働き方の場合、法律上の最低の日数は次のとおりです。

| 入社からの継続勤務 | 付与される日数 |
|---|---|
| 6か月 | 10日 |
| 1年6か月 | 11日 |
| 2年6か月 | 12日 |
| 3年6か月 | 14日 |
| 4年6か月 | 16日 |
| 5年6か月 | 18日 |
| 6年6か月以上 | 20日 |

厚生労働省のFAQも、6年6か月以上で20労働日になると説明しています。週の所定労働日数が少ない働き方では、日数を比例させて付与する仕組みがあります。厚生労働省のFAQによると、対象は週の所定労働時間が30時間未満で、週の所定労働日数が4日以下（または年間の所定労働日数が48日から216日）の人です。たとえば週4日勤務の場合、6か月で7日、6年6か月以上で15日と示されています。週4日勤務や短時間勤務の求人を検討している人は、自分の働き方がこの表の対象になるかどうかも確かめてください。週の所定労働時間が30時間以上なら、週4日でも通常の表で付与されます。

使わなかった日数は翌年に繰り越せます。厚生労働省の「確かめよう労働条件」のQ&Aは、年次有給休暇の権利の消滅時効は2年で、前年度の分が繰り越されると説明しています。

## 入社直後は有給がないことがある

法律どおりの運用だと、入社してから6か月は有給休暇がありません。転職して間もない時期に通院や家庭の用事がある人は、この点を先に知っておく必要があります。

一方で、法律は最低限の決まりです。会社によっては、入社日に一部を付与する、6か月を待たずに付与するなど、法律より早く与えている場合があります。労働基準法39条7項のただし書きも、基準日より前から有給休暇を与える場合を想定した書き方になっています。

付与の時期の書き方には、次のようなものがあります。

| 求人票の書き方の例 | 読み取れること |
|---|---|
| 入社6か月後に10日付与 | 法律どおりの時期と日数 |
| 入社時に◯日、6か月後に◯日 | 入社直後から一部を使える |
| 入社月に応じて付与 | 全社員の付与日を年1回にそろえている可能性がある |
| 有給休暇あり（法定どおり） | 時期と日数は法律の最低ライン |

全社員の付与日を毎年同じ日にそろえている会社では、入社した月によって初回の付与日や日数が変わることがあります。書き方が分かりにくいときは、自分が入社した場合はいつ何日付与されるかを聞くのがいちばん早い確かめ方です。

入社日から逆算した有給の使い方は[入社日の決め方](/guide/nyusha-bi/)にまとめています。

## 年5日の取得義務がある

有給休暇が年10日以上付与される人について、会社は付与日から1年以内に5日を取らせなければなりません。労働基準法39条7項の定めで、本人が自分で5日取っていれば、会社が時季を指定する必要はありません。

「確かめよう労働条件」の解説によると、会社は労働者ごとに年次有給休暇管理簿を作り、3年間保存する義務があります。時季を指定する義務に違反した場合の罰則（30万円以下の罰金）も設けられています。

:::point
- 年10日以上付与される人は、法律上、年5日は取ることになる
- 5日を超える分の取りやすさは、会社ごとに差が出る
- 計画的付与（会社が労使協定で日を決める仕組み）は、5日を超える分にしか使えない
:::

つまり「年5日は取れる」は、どの会社でも前提になっています。求人を比べるときに差が出るのは、それを超えた日数がどれだけ使われているかです。

## 時季は働く人が決めるのが原則

労働基準法39条5項は、有給休暇は労働者が請求する時季に与えなければならないと定めています。会社は、請求された時季に与えると事業の正常な運営を妨げる場合に限り、別の時季に変えられます。厚生労働省のFAQは、会社が有給休暇を与えないとすることはできないと説明しています。

また「確かめよう労働条件」の解説は、労働基準法附則136条が、有給休暇を取った人への不利益な取扱いを禁じていることにも触れています。

取得の単位は1日が原則です。半日単位は就業規則で定めている会社で使えます。時間単位は労使協定を結んだ会社で、年5日の範囲で使えます。通院や子どもの行事など、短い時間だけ抜けたい場面が多い人は、半日・時間単位があるかも確かめておくと便利です。

## 求人票と書面で見るところ

有給休暇の情報は、求人票では「休日・休暇」の欄に書かれていることが多くあります。年間休日には有給休暇が含まれない点に注意します。年間休日の読み方は[年間休日の読み方](/guide/kyujitsu-kyujin/)にまとめています。

内定後に受け取る労働条件通知書では、休暇も明示する項目になっています（労働基準法施行規則5条）。次の点を確かめます。

1. 初回の付与の時期と日数
2. 2回目以降の付与日（入社日基準か、全社一律の日か）
3. 半日単位・時間単位の取得ができるか
4. 計画的付与があるか、あれば何日分か
5. 夏季休暇や年末年始休暇が、有給休暇とは別の特別休暇か

5つ目は見落としやすい点です。夏季休暇を有給休暇の計画的付与で充てている会社もあります。特別休暇の書かれ方は[特別休暇の書かれ方の読み方](/guide/kyuka-seido/)で扱っています。

:::view
求人をご紹介する中でよく見るのは、休暇欄に「有給休暇」とだけ書かれ、初回の付与時期や取得の単位までは書かれていない求人です。同じ「有給あり」でも、入社直後から使えるかどうかは会社によって違います。当社経由で応募する求人なら、付与の時期や半日単位の有無など、求人票に書かれていない点はご質問いただければ企業に確認できます。
:::

## 取りやすさは数字と運用で確かめる

付与日数が同じでも、実際に使えるかどうかは職場によって違います。取りやすさを確かめるには、次のような聞き方があります。

- 配属予定の部署で、有給休暇の取得日数はどのくらいか
- 連続した休み（土日とつなげた数日など）を取る人はいるか
- 休むときの申請の手順と、何日前までに出すことが多いか
- 休んでいる間の仕事の引き継ぎはどうしているか
- 繁忙期で取りにくい時期はあるか

会社全体の取得率を出している会社もありますが、部署によって差があることもあります。配属先の数字や運用を聞けると、入社後の働き方を思い描きやすくなります。

聞き方に迷う場合は、「入社後の働き方をイメージするために」と目的を添えると角が立ちません。面接で聞きにくければ、内定後のオファー面談で聞くこともできます。

## 休みの条件を求人どうしで比べる手順

複数の求人で迷っているときは、休みにかかわる項目を同じ表に並べると違いが見えます。有給休暇だけを比べても、年間休日や特別休暇の数え方が違えば、1年に休める日の合計は変わるためです。

| 比べる項目 | 確かめる場所 |
|---|---|
| 年間休日の日数と内訳 | 求人票の休日欄 |
| 有給休暇の初回の付与時期と日数 | 求人票の休暇欄、労働条件通知書 |
| 夏季・年末年始などの特別休暇 | 求人票の休暇欄、就業規則 |
| 計画的付与の有無と日数 | 面接・オファー面談での質問 |
| 半日・時間単位の取得 | 面接・オファー面談での質問 |
| 配属先での取得の様子 | 面接・オファー面談での質問 |

並べるときの手順は次のとおりです。

1. 求人票に書かれている項目を先に埋める
2. 空いた欄を、面接で聞く質問のリストに移す
3. 内定が出たら、労働条件通知書の記載で表を書き直す
4. 口頭で聞いた内容と書面が違う点は、承諾の前に確かめる

労働基準法89条は、休暇に関する事項を就業規則に書くことを会社に求めています（常時10人以上の労働者を使う会社の場合）。入社前に就業規則の該当部分を見せてもらえるかを聞くのも一つの方法です。見せてもらえない場合でも、労働条件通知書の休暇の欄で最低限の内容は確かめられます。

## 入社前と退職前に気をつけること

転職の前後は、有給休暇の扱いが切り替わる時期です。今の会社で残っている日数は、退職すると使えなくなります。退職前の消化の考え方は[退職前の有給休暇の消化の考え方](/guide/yukyu-shouka/)で扱います。

転職先では、勤続年数がゼロから数え直しになるため、付与日数は10日から始まるのが法律の最低ラインです。今の会社で勤続が長い人ほど、日数が減ることになります。休みの日数を条件として重視する場合は、年間休日と有給休暇の付与を合わせて比べてください。

:::view
休みの取りやすさは、求人票の文字だけでは判断しにくい項目です。気になる求人があっても、休暇の欄だけで応募をやめる必要はありません。応募は当社への申し込み（無料）で、当社から企業へ推薦する形で選考が進みます。休み方について確かめたいことは、選考の中で質問として整理しておくことをおすすめします。
:::

個別の事情で有給休暇の扱いに疑問があるときは、労働基準監督署や社会保険労務士にご相談ください。

## よくある質問

### 入社してすぐに休みが必要な予定があります。どうすればよいですか

法律どおりの運用の会社では、入社から6か月は有給休暇がありません。内定の段階で、予定の時期と事情を伝えて相談してください。入社日を調整する、欠勤扱いになるかを確かめるなど、選べる方法は会社によって違います。

### 有給休暇の日数を求人どうしで比べるとき、何を見ればよいですか

付与日数は法律の最低ラインに沿っている会社が多いため、比べるときは初回の付与の時期、半日・時間単位の有無、夏季休暇が別にあるかを並べます。そのうえで、配属先での取得の様子を聞いて比べると判断しやすくなります。

### 年5日の取得義務があるなら、それ以上は取れないのですか

年5日は会社が取らせなければならない最低の日数で、上限ではありません。付与された日数の範囲で、時季は働く人が決めるのが原則です（2026年11月時点）。5日を超えて取れているかどうかは職場の運用で変わるため、配属先での取得の様子を面接やオファー面談で聞いておくと、入社後の休み方を思い描きやすくなります。
