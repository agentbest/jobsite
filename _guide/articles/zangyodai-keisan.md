残業代は「1時間あたりの賃金×（1＋割増率）×時間数」で計算します。割増率は、法定時間外の労働と深夜の労働が2割5分以上、法定休日の労働が3割5分以上、1か月60時間を超える時間外労働は5割以上です。1時間あたりの賃金は、月給制なら月給を1年間の1か月平均所定労働時間で割って出し、家族手当・通勤手当・住宅手当などは計算から除かれます。

この記事の制度の説明は、2026年11月時点の労働基準法・同法施行規則と厚生労働省の資料にもとづいています。

## 計算の全体像

労働基準法第37条は、時間外・休日・深夜の労働に、通常の労働時間または労働日の賃金の計算額に一定の率を掛けた割増賃金を払うよう定めています。式にすると次のとおりです。

**残業代＝1時間あたりの賃金×（1＋割増率）×該当する時間数**

「1＋割増率」としているのは、時間外の1時間には、通常の1時間分の賃金に割増分を上乗せした額が払われるためです。所定労働時間内の深夜労働のように、その時間の通常の賃金がすでに払われている場合は、割増分（2割5分以上）だけが上乗せされます。ここで大事になるのは、「1時間あたりの賃金」の出し方、どの時間にどの割増率がかかるか、計算のもとから除く賃金は何か、の3つです。

## 計算の手順

給与明細と照らし合わせるときは、次の順で計算していくと分かりやすくなります。

1. **計算のもとになる月給を出す**：月給の合計から、家族手当・通勤手当・住宅手当などの除外される賃金と、固定残業代（割増賃金にあたる部分）を差し引く。厚生労働省のQ&Aでは、固定残業代を払う場合は通常の労働時間の賃金にあたる部分と割増賃金にあたる部分を区別できるようにすることが求められている
2. **1か月平均所定労働時間を出す**：1年間の所定労働日数×1日の所定労働時間÷12
3. **1時間あたりの賃金を出す**：1の額÷2の時間
4. **時間の種類ごとに分ける**：法定時間外（60時間以内・60時間超）、法定休日、深夜に分けて時間数を数える
5. **割増率を掛けて合計する**：種類ごとに「1時間あたりの賃金×（1＋割増率）×時間数」を出して足す

1か月平均所定労働時間は、年間休日の数で変わります。同じ月給でも、休日が多く所定労働時間が短い会社ほど、1時間あたりの賃金は高くなり、残業1時間あたりの額も高くなります。求人票の年間休日の数と1日の所定労働時間が分かれば、おおよその目安をつけられます。年間休日の読み方は[年間休日の読み方](/guide/kyujitsu-kyujin/)で整理しています。

## 割増率の一覧

厚生労働省の資料と労働基準法第37条をもとに整理すると、割増率は次のとおりです。

| 労働の種類 | 割増率 |
|---|---|
| 時間外労働（1日8時間・1週40時間を超える部分） | 2割5分以上 |
| 時間外労働のうち1か月60時間を超える部分 | 5割以上 |
| 深夜労働（原則として午後10時〜午前5時） | 2割5分以上 |
| 法定休日の労働 | 3割5分以上 |
| 月60時間を超える時間外労働が深夜に及んだ場合 | 7割5分以上（50%＋25%） |

1か月60時間を超える時間外労働の5割以上の割増率は、大企業では2010年4月から、中小企業でも2023年4月1日から適用されています。いまは企業の規模にかかわらず同じです。

深夜の労働には、時間内か時間外かを問わず、深夜の割増が別にかかります。一方、厚生労働省のQ&Aでは、法定休日に働いた時間については、時間外の割増を別に払う必要はないとされています。法定休日の3割5分と深夜の2割5分は、重なれば両方がかかります。

## 1時間あたりの賃金の出し方

労働基準法施行規則第19条は、賃金の決め方ごとに1時間あたりの賃金の出し方を定めています。

| 賃金の決め方 | 1時間あたりの賃金 |
|---|---|
| 時給 | その金額 |
| 日給 | 日給÷1日の所定労働時間（日によって違う場合は1週間の1日平均） |
| 週給 | 週給÷週の所定労働時間（週によって違う場合は4週間の1週平均） |
| 月給 | 月給÷月の所定労働時間（月によって違う場合は1年間の1か月平均） |
| 出来高払い | 賃金算定期間の出来高給の総額÷その期間の総労働時間 |

月給制の会社では、月によって所定労働時間が違うのがふつうなので、「1年間の所定労働時間の合計÷12」を1か月平均所定労働時間として使います。月給と出来高払いのように、決め方の違う賃金が組み合わさっている場合は、それぞれで出した金額を合計します。

厚生労働省のQ&Aでは、月給制の1時間あたりの賃金を「月給（各種手当を含んだ合計）÷1年間における1か月平均所定労働時間数」と示しています。ここでいう月給には、次に見る「計算から除く賃金」は入りません。

## 計算から除く賃金

労働基準法第37条第5項と同法施行規則第21条により、次の賃金は割増賃金を計算するもとの賃金に入れません。

1. 家族手当
2. 通勤手当
3. 別居手当
4. 子女教育手当
5. 住宅手当
6. 臨時に支払われた賃金
7. 1か月を超える期間ごとに支払われる賃金

厚生労働省のQ&Aでは、これらに当たるかどうかは「名称ではなく実質によって判断します」とされています。手当の名前が「住宅手当」でも、実質がこれらに当たらなければ計算に入ることがあり、反対に別の名前でも実質がこれらに当たれば除かれます。具体的にどう判断されるかは個別の事情によるので、気になる場合は労働基準監督署や社会保険労務士にご相談ください。

この7つ以外の手当、たとえば役職手当や資格手当などは、原則として計算のもとに入ります。

なお、労働基準法第41条の管理監督者には、労働時間・休憩・休日の規定が適用されないため、法定時間外や法定休日の割増賃金は発生しません。ただし深夜の割増賃金は管理監督者にも必要です。管理職の手当と残業代の関係は[「管理職」の求人と残業代](/guide/kanrishoku-kyujin/)で整理しています。

## 1か月60時間の数え方

月60時間超の割増率がかかるかどうかは、1か月の起算日から時間外労働を積み上げて判断します。厚生労働省のリーフレットでは、累計で60時間を超えた時点から5割以上の率で計算した割増賃金を払わなければならないとされています。

数え方で注意したいのは休日の扱いです。リーフレットによると、月60時間の時間外労働の計算には、法定休日に働いた時間は含まれませんが、それ以外の休日（いわゆる所定休日）に働いた時間は含まれます。週休2日の会社で、法定休日でないほうの休日に出勤した分は、時間外労働として60時間の計算に入ることがあります。

また、労使協定を結んだ事業場では、月60時間を超えた分の引き上げ分の割増賃金の代わりに、有給の休暇（代替休暇）を与えることができます（労働基準法第37条第3項）。労働条件通知書のモデル様式にも「代替休暇（有・無）」の欄があります。

## 所定労働時間と法定労働時間の違い

割増賃金の対象になる時間外労働は、法定労働時間（1日8時間・1週40時間、労働基準法第32条）を超えた部分です。会社が決めた所定労働時間が法定より短い場合、所定労働時間を超えても法定労働時間に収まる部分は、法律で定めた割増率の対象ではありません。

厚生労働省のモデル労働条件通知書には、割増賃金率の欄として「法定超 月60時間以内」「月60時間超」「所定超」「法定休日」「法定外休日」「深夜」が分けて設けられています。所定超の部分をどう扱うかは会社の定めによるので、労働条件通知書や就業規則で確かめます。

:::view
求人をご紹介する中では、求人票の残業代の欄が「残業代全額支給」「固定残業代◯時間分を含む」など会社ごとに違う書き方をされている様子をよく見ます。どの手当が1時間あたりの賃金の計算に入るのか、所定労働時間が何時間かといった計算のもとになる情報は、求人票だけでは分からないことが多いので、ご質問いただければ企業に確認できます。
:::

## 求人票と給与明細で確かめたいこと

入社前の比較でも入社後の確認でも、残業代が正しく払われているかを確かめるには、次の情報をそろえます。

1. **所定労働時間**：1日の所定労働時間と、年間の休日数（1か月平均所定労働時間のもとになる）
2. **給与の内訳**：基本給と各手当の名前と額
3. **固定残業代の有無**：ある場合は何時間分でいくらか
4. **割増率**：60時間超・休日・深夜の率が会社の規程でどうなっているか
5. **労働時間の記録**：勤怠の記録と、給与明細の時間外時間が合っているか

固定残業代がある求人の読み方は[みなし残業（固定残業代）の求人の読み方](/guide/minashi-zangyo/)、手当の書かれ方は[時間外手当の書かれ方の読み方](/guide/jikangai-teate/)や[深夜手当・休日手当の書かれ方](/guide/shinya-kyujitsu/)、残業の上限との関係は[36協定と求人票の残業の書かれ方](/guide/zangyo-36/)で整理しています。

自分で計算した額と給与明細の額が合わないときは、まず会社の担当部署に計算の方法を確かめます。それでも納得できない場合は、勤怠の記録や給与明細を手元に残したうえで、労働基準監督署や社会保険労務士などにご相談ください。

:::view
残業の多さや残業代の払われ方は、転職先を選ぶときに気にされる方が多い条件です。サイトに載せていない求人もあるので、残業時間や給与の形についての希望を伺ったうえで、掲載外の求人も含めて個別にお探しできます。面談はオンラインまたは電話で受けています。
:::

## よくある質問

### 賞与は残業代の計算に入りますか？

1か月を超える期間ごとに支払われる賃金は、割増賃金の計算のもとから除かれます（労働基準法施行規則第21条）。年2回などの賞与は、ふつうこれに当たります。毎月支払われる手当は、家族手当や住宅手当など除外の対象に当たらない限り、計算に入ります。

### 所定労働時間が7時間の会社で8時間働いた場合、割増はつきますか？

法律で定めた割増率がかかるのは、1日8時間・1週40時間の法定労働時間を超えた部分です。所定の7時間を超えて8時間までの1時間は法定労働時間の範囲内なので、法律上の割増率の対象ではありません。その1時間をどう払うかは会社の定めによるので、就業規則や労働条件通知書で確かめてください。

### 固定残業代がある場合、残業代はどう計算しますか？

固定残業代は、決められた時間分の時間外手当を定額で払う仕組みです。厚生労働省のQ&Aでは、通常の賃金にあたる部分と固定残業代とを区別できるようにしたうえで、固定残業代の額が労働基準法の方法で計算した割増賃金の額を下回るときは、その差額を払う必要があるとされています。読み方は[みなし残業（固定残業代）の求人の読み方](/guide/minashi-zangyo/)で整理しています。
