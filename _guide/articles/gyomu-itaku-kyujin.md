業務委託の求人は、会社に雇われる「雇用」の募集ではなく、事業者として仕事を受ける契約の募集です。そのため、労働時間・割増賃金・年次有給休暇といった労働基準法のルールや、会社の健康保険・厚生年金への加入は前提になりません。ただし、契約の名前が業務委託でも、働き方の実態が労働者であれば労働基準法などが適用されます。2024年11月1日からは、いわゆるフリーランス・事業者間取引適正化等法により、発注する事業者に取引条件の明示や報酬の支払期日の設定などが義務づけられています。

この記事の説明は、2026年11月時点の法令と、厚生労働省・公正取引委員会・日本年金機構・国税庁の資料にもとづいています。

## 雇用と業務委託で何が変わるか

同じ職種名の募集でも、雇用か業務委託かで、守られるルールやお金の流れが変わります。主な違いを並べると次のとおりです。

| 項目 | 雇用（正社員・契約社員など） | 業務委託 |
|---|---|---|
| 契約の性質 | 会社の指揮命令を受けて働き、賃金を受け取る | 事業者として仕事を受け、報酬を受け取る |
| 労働基準法 | 労働時間・割増賃金・年次有給休暇などが適用される | 前提にならない（実態が労働者なら適用される） |
| 求人で示される条件 | 業務内容・労働時間・賃金・加入保険などの労働条件 | 業務の内容・報酬・支払期日などの取引条件 |
| 年金・健康保険 | 求人票に健康保険・厚生年金などの加入保険が示される | 自分で国民年金・国民健康保険に加入するのが基本 |
| 税金 | 給与所得 | 事業所得などとして、収入から必要経費を差し引いて計算 |

雇用の求人では、職業安定法施行規則にもとづき、健康保険・厚生年金・労災保険・雇用保険の適用を求人票に示すことになっています。求人票の保険の書かれ方は[社会保険完備とは｜求人票の保険の書かれ方](/guide/shakai-hoken/)で整理しています。

なお、職業紹介は、職業安定法第4条で「求人者と求職者との間における雇用関係の成立をあつせんすること」と定められています。人材紹介会社を通じて紹介される求人は、雇用の求人が前提です。

## 求人票で業務委託かどうかを見分けるところ

業務委託の募集かどうかは、求人のタイトルだけでは分からないことがあります。次の欄を見ると判断しやすくなります。

- **雇用形態・契約形態の欄**：「業務委託」「準委任」「請負」などと書かれていれば、雇用ではない契約の募集です
- **お金の呼び方**：雇用の求人は「給与」「賃金」「月給」、業務委託は「報酬」「単価」と書かれることが多くあります
- **保険の欄**：雇用の求人には加入保険が示されます。業務委託の募集では、この欄がないか「なし」になっていることがあります
- **時間の書き方**：雇用の求人は「就業時間」「休日」、業務委託は「稼働時間」「稼働日数」のように書かれることがあります

ひとつの求人に「業務委託（正社員登用あり）」のように2つの形が書かれている場合は、入社時点の契約がどちらで、いつ切り替わるのかを分けて確かめます。

## 年金・健康保険はどう変わるか

日本年金機構は、日本国内に住む20歳以上60歳未満で厚生年金保険に加入していない人は、国民年金の第1号被保険者または第3号被保険者になると説明しています。会社を辞めて業務委託だけで働く場合は、住んでいる市区町村の窓口で国民年金の手続きをするのが基本で、退職日の翌日から14日以内とされています。

健康保険について、厚生労働省は、国民健康保険を「他の医療保険制度に加入されていない全ての住民の方を対象とした医療保険制度」と説明しています。会社の健康保険の被保険者でなくなる場合は、国民健康保険などへの切り替えを考えることになります。手続きや保険料は市区町村ごとに案内されているので、住んでいる自治体に確認してください。

業務委託の報酬額を雇用の年収と比べるときは、年金や健康保険を自分で手続きして納めることになる点も含めて考えます。手取りの考え方は[年収と手取りの違い](/guide/tedori/)もご覧ください。

## 税金はどう変わるか

雇用で受け取る給料は給与所得です。業務委託の報酬は、事業として行っていれば事業所得になります。国税庁は、事業所得の金額を「総収入金額−必要経費」で計算すると説明しています。収入から差し引く必要経費として、仕事に使う機材や通信費などをどう扱うかを含めて、自分で所得を計算することになります。

また、国税庁によると、原稿料や講演料、弁護士・公認会計士など特定の資格を持つ人への報酬などは、支払う側が源泉徴収をする対象になります。自分の報酬が源泉徴収の対象かどうか、申告をどう行うかは、税務署や税理士にご確認ください。

## 契約名より実態で判断される「労働者性」

業務委託契約で働いていても、実態が労働者であれば、労働基準法などの保護を受けます。公正取引委員会・中小企業庁・厚生労働省のリーフレットにも、契約の名前が業務委託であっても、働き方の実態として労働者である場合はフリーランス法ではなく労働基準法などが適用されると書かれています。

労働者にあたるかどうかの考え方として、昭和60年の労働基準法研究会報告がよく参照されます。報告では、雇用契約か請負契約かといった形式にかかわらず、実質的な「使用従属性」で総合的に判断するとされ、主に次の点が挙げられています。

- **仕事の依頼を断る自由があるか**：具体的な依頼や指示を拒めないことは、指揮監督関係をうかがわせる重要な要素
- **業務の進め方への指揮命令**：業務の内容や進め方について具体的な指揮命令を受けているか
- **時間・場所の拘束**：勤務場所と勤務時間が指定され、管理されているか
- **代わりの人を立てられるか**：本人の代わりに他の人が仕事をすることが認められているか
- **報酬の性格**：時間給を基礎に計算される、欠勤すると差し引かれる、残業すると別の手当が出るなど、働いた時間への対価になっているか

さらに、高価な機械や器具を自分で負担しているか、報酬が同じ業務の正社員と比べて著しく高いか、他社の仕事を事実上できないほど専属しているか、といった点も補強の要素として考えられています。求人票で業務委託なのに勤務時間や勤務場所が細かく決められている場合は、契約の中身を確かめておきたいところです。

## フリーランス・事業者間取引適正化等法のポイント

正式名称は「特定受託事業者に係る取引の適正化等に関する法律」で、2024年11月1日に施行されました。対象のフリーランスは、業務委託を受ける事業者で、従業員を使用しない個人や、代表者以外に役員も従業員もいない法人です。リーフレットでは、「従業員」は週20時間以上かつ31日以上の雇用が見込まれる人を指すとされています。会社員が副業で業務委託を受ける場合も、この法律のフリーランスにあたります。

従業員を使用する発注事業者には、主に次の義務があります。期間の条件がある項目は、契約の更新で継続する場合も含みます。

| 義務 | 内容（リーフレットの要旨） |
|---|---|
| 取引条件の明示 | 業務の内容、報酬の額、支払期日などを書面等で直ちに示す |
| 支払期日の設定 | 物品などを受け取った日から60日以内のできる限り早い日を支払期日とし、期日内に支払う |
| 禁止行為（1か月以上の委託） | 受領拒否、報酬の減額、返品、買いたたき、購入・利用強制など7つの行為の禁止 |
| 募集情報の的確表示 | 広告などの募集情報で虚偽や誤解を与える表示をせず、正確かつ最新に保つ |
| 育児介護等への配慮（6か月以上） | 申出に応じて、育児や介護と業務を両立できるよう配慮する |
| ハラスメント対策 | 方針の明確化、相談体制の整備などの措置を講じる |
| 中途解除等の予告（6か月以上） | 原則として30日前までに予告し、求めがあれば理由を開示する |

リーフレットでは、取引条件の明示・支払期日・禁止行為については公正取引委員会と中小企業庁、募集情報やハラスメント対策などの就業環境については厚生労働省（都道府県労働局）が問い合わせ先とされています。

:::view
求人をご紹介する中では、雇用形態の欄の書き方が会社ごとに違い、「契約形態は面談時にご案内」のように詳しく書かれていない求人も見かけます。雇用なのか業務委託なのか、どの期間がどちらの契約になるのかは、ご質問いただければ企業に確認できます。
:::

## 応募する前に確かめたいこと

業務委託の求人に応募する前に、次の点を確かめておくと、契約後の食い違いを防ぎやすくなります。

1. **契約の形**：雇用か業務委託か。業務委託から雇用に切り替わる予定があるか
2. **業務の範囲**：何を成果物とし、どこまでを受けるのか
3. **報酬の決まり方**：月額・時間単価・成果物ごとなど、計算の方法と支払期日
4. **時間と場所**：稼働時間や作業場所の指定がどの程度あるか
5. **費用の負担**：機材や交通費などを誰が負担するか
6. **契約期間と終了**：更新の有無、途中で終える場合の予告

副業として業務委託を受ける場合は、勤め先の副業の決まりも確かめておきます。読み方は[副業可の求人の読み方](/guide/fukugyo-kyujin/)で整理しています。働き方の実態が労働者にあたるかどうか迷う場合は、労働基準監督署や社会保険労務士、税金については税理士などにご相談ください。

:::view
雇用されて働く形での転職を考えている方には、面談はオンラインまたは電話で受けています。業務委託との違いを踏まえて、正社員や契約社員の求人の中から希望の働き方に近いものを探したい場合は、サイトに載せていない求人も含めて個別にお探しできます。
:::

## よくある質問

### 業務委託の求人で、勤務時間や出社日が細かく決められているのは問題ですか？

勤務場所と勤務時間が指定され管理されていることは、労働者性を判断するときの要素のひとつです。ただし、業務の性質から時間や場所が決まる場合もあり、それだけで決まるものではありません。仕事の依頼を断れるか、進め方に具体的な指示を受けるかなども含めて総合的に判断されます。気になる場合は労働基準監督署などにご相談ください。

### 業務委託だけで働くと、年金と健康保険はどうなりますか？

厚生年金に加入していない20歳以上60歳未満の人は、国民年金の第1号被保険者または第3号被保険者になります。健康保険は、ほかの医療保険に加入していなければ国民健康保険の対象です。手続きは住んでいる市区町村の窓口で行います。

### 会社員が副業で業務委託を受ける場合も、フリーランス法の対象になりますか？

なります。リーフレットでは、会社に従業員として雇われている個人が、副業として事業者から業務委託を受けている場合も、この法律のフリーランスにあたると説明されています。ただし、従業員を使用していないことなどの条件があります。
