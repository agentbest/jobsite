新規事業・事業開発の求人の年収の幅は、メンバーからマネージャー候補・事業責任者候補までの役割をまたいで書かれることが多く、ほかの職種より広く見えがちです。さらに、固定残業代を多めの時間で含める書き方や、業績連動の賞与、ストックオプションなど、毎年同じ額にならない部分が組み合わさります。幅を見るときは、どの役割の範囲か、毎月の固定給はいくらか、変動する部分は何に連動するかの3点を分けて読みます。

幅そのものの一般的な読み方は[求人の年収の幅はどう決まるのか](/guide/nenshu-haba/)で扱っているので、ここでは事業開発の求人に特有の書かれ方に絞ります。

## 事業開発の求人の給与欄に出てくる項目

| 項目 | 書かれ方の例 | 読むときのポイント |
|---|---|---|
| 年収の幅 | 想定年収、年俸、職位によって異なる | 何の役割までを含んだ幅か |
| 役割別のモデル | メンバーとマネージャー候補で範囲を分ける | 自分がどちらに当たりそうか |
| 固定残業代・固定深夜手当 | 何時間分でいくらか | 基本給の割合 |
| 賞与 | 年2回、決算賞与、業績と人事考課で変動 | 会社の業績か、担当事業の成果か |
| インセンティブ | 実績に応じた報奨、社内表彰 | 営業の比重がどのくらいか |
| ストックオプション | 制度あり、全社員対象、個別に協議 | 対象・時期・条件 |
| 決め方の一文 | 前職の年収や実績を考慮して決定 | 幅のどこに決まるかの手がかり |

すべてが書かれている求人は多くありません。「応相談」「当社規定により決定」とだけ書く求人もあり、その場合は選考の途中で確かめることになります。

## 幅が広くなる3つの理由

事業開発の求人の年収の幅が広くなるのは、主に次の理由です。

1. **役割の幅が広い**：同じ求人の中で、メンバーとして事業の一部を担う人から、事業全体を任せる責任者候補までを募集しています。役割ごとに範囲を分けて示す求人もあります
2. **オープンポジションで募集している**：配属する事業や役割を選考の中で決めるため、幅をあらかじめ広く取っています
3. **職位で賃金の形が変わる**：職位によって年俸制になる、管理職として迎える場合は残業代の扱いが変わる、といった書き方では、上限側の額に別の前提が入っています

役割による仕事の違いは[新規事業・事業開発の求人のポジション別の違い](/guide/bizdev-grade/)で扱っています。

## 「オープンポジション」の年収の読み方

事業開発の求人には、配属先を決めずに募集するオープンポジションが見られます。年収の幅は、会社の複数の事業や役割の範囲をまとめたものと読めます。

この場合、提示額は、選考を通じてどの事業のどの役割で迎えるかが決まった後に固まります。早めに確かめておきたいのは次の点です。

- 想定している事業や役割の候補はどれか
- 候補ごとに、給与の範囲や賃金の形（月給制か年俸制か）は変わるか
- 配属が決まるのは、内定の前か後か

候補の事業によって、営業の比重やインセンティブの有無が違うこともあります。年収の額だけでなく、その額に変動する部分がどれだけ含まれているかを候補ごとに確かめておくと、配属が決まったときの条件の差に驚かずに済みます。オープンポジションの仕事の中身は[新規事業・事業開発の求人票の読み方](/guide/bizdev-posting/)も参考にしてください。

## 固定残業代・固定深夜手当の含め方

事業開発の求人では、固定残業代を年収に含める書き方がよく見られます。時間外の手当に加えて、深夜の時間帯の手当を一定時間分含める書き方もあります。年収の幅が同じでも、こうした手当の割合が大きい求人は、基本給が小さくなります。

一方、上限側では管理監督者として迎えるため固定残業代を含まない、と書く求人もあります。同じ求人の中で、下限側と上限側の給与の構成が違うことがあるので、提示を受けたら内訳で確かめます。固定残業代の読み方は[みなし残業（固定残業代）の求人の読み方](/guide/minashi-zangyo/)、管理職の扱いは[「管理職」の求人と残業代](/guide/kanrishoku-kyujin/)をご覧ください。個別の判断が要る場合は、労働基準監督署や社会保険労務士などにご相談ください。

:::view
事業開発の求人をご紹介していると、同じ職種名でも、年収の幅がメンバーの範囲なのか、責任者候補までを含んだ範囲なのかは会社ごとに違います。求人票の文面だけでは、上限側がどんな役割を想定しているかを読み取りにくいことが多いです。どの役割で迎える想定か、上限側ではどこまでを任せるのかは、ご質問いただければ企業に確認できます。
:::

## 賞与と業績連動の部分を読む

事業開発の求人の賞与は、会社全体の業績、個人の評価、担当する事業の成果のどれに連動するかで、毎年の額の動き方が変わります。決算の結果に応じて別に支給する決算賞与を設ける会社もあります。

新規事業は、立ち上げてすぐに数字が出るとは限りません。賞与が担当事業の成果に強く連動する場合、立ち上げの時期には賞与が見込みより少なくなることもあります。年収の幅に賞与をどれだけ見込んでいるか、評価で何を見るのか（売上などの数字か、検証の進み具合か）を確かめておくと、見通しが立てやすくなります。評価の読み方は[新規事業・事業開発の評価のされ方](/guide/bizdev-evaluation/)、決算賞与の書かれ方は[決算賞与の書かれ方の読み方](/guide/kessan-shoyo/)をご覧ください。

## 年俸制で書かれる求人

事業開発の求人には、年俸制で、年俸を12で割った額を毎月払うと書くものがあります。職位によって昇給の回数が違う、上司との面談と自己目標の評価で年俸を改定する、といった書き方も見られます。

年俸制では、賞与にあたる部分が年俸に含まれているのか、別に業績賞与があるのかで、年収の見通しが変わります。改定の時期と、評価がどう年俸に反映されるかを確かめておくと、入社後の年収の動き方が読みやすくなります。年俸制の一般的な読み方は[年俸制の求人で確認したいこと](/guide/nenpousei/)をご覧ください。

## インセンティブが付く求人

提携先の開拓や法人への提案を担う事業開発の求人では、実績に応じたインセンティブや社内表彰による報奨を設けることがあります。上限側の年収がこうした変動部分を含んだ額かどうかで、読み方が変わります。固定給との割合の見方は[インセンティブ・歩合の求人の読み方](/guide/incentive-kyujin/)で扱っています。

## ストックオプションの書かれ方

事業開発の求人では、給与や福利厚生の欄にストックオプションが書かれていることがあります。書かれ方には、次のような違いがあります。

| 書かれ方 | 読み方 |
|---|---|
| 全社員が対象 | 入社すれば付与の対象になる。時期と数は別に確かめる |
| 成果や役職に応じて付与 | 入社時ではなく、評価や昇格のタイミングで付与されることがある |
| 人事評価により付与 | 評価の結果しだいで、付与されないこともある |
| 選考の中で個別に協議 | 提示の段階で条件が示される。書面で確かめる |

「ストックオプション制度あり」とだけ書かれた求人では、自分が対象になるかどうかも分かりません。付与の時期・数・行使の条件、退職したときの扱い、税の扱いは、[ストックオプションがある求人で確認したいこと](/guide/stock-option/)を参考に、内定の前後で確かめます。株式を直接受け取る形の報酬は[RSU・株式報酬がある求人の読み方](/guide/rsu/)で扱っています。

## 子会社や出向で働く求人

事業開発の求人には、新しい事業を担う子会社への出向や、子会社での採用を前提にしたものがあります。この場合、給与の規定がどちらの会社のものか、賞与の業績連動が親会社と子会社のどちらの数字で決まるかによって、年収の見通しが変わります。出向の期間や、出向が終わった後の扱いもあわせて確かめておきます。

## 提示額が幅のどこになるかを左右するもの

| 要素 | 事業開発の求人での見られ方 |
|---|---|
| 担ってきた範囲 | 構想・検証・立ち上げ・拡大のどこまでを持ったか |
| 成果の示し方 | 立ち上げた事業や提携の結果を具体的に説明できるか |
| 任せたい役割 | メンバーか、事業の責任者候補か |
| 前職の年収と実績 | 決め方の一文で考慮すると書く求人がある |

担ってきた範囲は、職務経歴書で事業ごとに、自分が持っていた工程と結果を書いておくと伝わりやすくなります。うまくいかずに閉じた事業でも、何を検証し、どの判断で撤退を決めたかを書けば、事業開発の経験として評価の材料になります。前職の年収をどう考慮するかは会社ごとに違うので、交渉を考える場合は[年収交渉はできるのか](/guide/nenshu-kosho/)も参考にしてください。

## 年収の欄を読むときのチェックリスト

- 年収の幅は、どの役割までを含んでいるか
- 固定残業代や固定深夜手当を除いた基本給はいくらか
- 上限側で残業代の扱いが変わらないか
- 賞与は、会社の業績・個人の評価・担当事業の成果のどれに連動するか
- ストックオプションは、自分が対象になるか、いつ何が決まるか
- 出向や子会社の場合、どちらの給与規定が使われるか

:::view
当社からの応募は当社への申し込み（無料）で、当社から企業へ推薦する形で選考が進みます。どの役割で迎える想定か、ストックオプションの対象になるかなど、本人からは聞きにくいことも、ご質問いただければ企業に確認できます。サイトに載せていない非公開の求人もあるので、希望の役割と年収を伺ったうえで、掲載外の求人も含めて個別にお探しできます。
:::

事業開発の求人は[事業企画・経営企画の求人一覧](/jobs/business-planning/)で探せます。年収の分布は[事業企画・経営企画の求人・年収動向](/jobs/business-planning/market/)やページ下の掲載データをご覧ください。

## よくある質問

### 年収の幅がとても広い求人は、上限で提示されることがありますか？
ありえますが、上限は、事業の責任者として迎える人や、変動部分が大きく出た場合を想定した額と読むのが基本です。自分がどの役割で迎えられる想定かを確かめたうえで判断するのがおすすめです。

### ストックオプションがあれば、年収が低めでも選んでよいですか？
ストックオプションは、会社の成長や上場などの条件がそろって初めて価値が出るもので、受け取りが約束された報酬ではありません。固定給と賞与だけで生活の見通しが立つかを先に確かめ、ストックオプションは上乗せとして考えるのが安全です。

### 新規事業がうまくいかなかったら、年収は下がりますか？
賞与が担当事業の成果に連動する場合は、賞与が見込みより少なくなることがあります。基本給がどう決まり、どんなときに改定されるかは会社の評価制度によるので、評価の指標とあわせて内定の前に確かめておくと安心です。
