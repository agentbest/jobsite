退職のときは、会社に返すものと、会社から受け取る書類を分けて準備します。返すのは、有効期限内の健康保険の資格確認書と、パソコンや社員証などの貸与品です。受け取るのは、源泉徴収票と、必要に応じて離職票や退職証明書で、年金手帳を会社に預けている場合は返してもらいます。

この記事の制度の説明は、2026年11月時点の法令と公的機関の資料で確かめた内容です。退職の伝え方は[退職の伝え方と時期](/guide/taishoku-kosho/)で扱っているので、ここでは伝えたあとの手続きに絞ります。

## 退職前後の手続きの流れ

退職の手続きは、時期ごとにすることが変わります。

| 時期 | すること |
|---|---|
| 退職を伝えたあと | 引き継ぎの計画、有給休暇の使い方の相談、受け取る書類の確認 |
| 最終出社日まで | 貸与品とデータの整理、返却物の準備、私物の持ち帰り |
| 退職日 | 有効期限内の資格確認書と貸与品の返却 |
| 退職後 | 源泉徴収票・離職票などの受け取り、健康保険・年金の切り替え（次の会社にすぐ入らない場合） |

最終出社日と退職日が違う場合は、返却の方法を事前に決めておきます。有給休暇を使って最終出社日のあとに退職日がくる場合、返却物を最終出社日に返すのか、郵送するのかを会社と相談しておくと、慌てずに済みます。

## 会社に返すもの

会社から受け取っていたものは、退職までに返します。主なものは次のとおりです。

| 返すもの | 気をつけること |
|---|---|
| 健康保険の資格確認書（有効期限内） | 扶養家族の分も含めて返す |
| 社員証・入館証・鍵 | 最終出社日に返すか、郵送するかを決めておく |
| パソコン・スマートフォンなどの機器 | 個人のデータが残っていないか、返す前に確かめる |
| 名刺（自分のもの・受け取ったもの） | 会社の扱いに従う |
| 書類・データ・記録媒体 | 会社の資料を持ち出さない |
| 制服・備品・定期券など | 会社の規程に従う |

健康保険については、協会けんぽの案内（石川支部、令和7年12月掲載）が次のように説明しています。従来の健康保険証は令和7年12月1日をもって使えなくなっており、退職するときに健康保険証・資格情報のお知らせ・有効期限が切れた資格確認書は返却が不要で、自分で破棄します。一方、有効期限内の資格確認書は退職日までしか使えないため、扶養家族の分も含めて勤め先に返します。退職日の翌日以降に誤って使うと、協会けんぽが負担した医療費を返すことになります。健康保険組合に加入している場合は、組合の案内に従ってください。

日本年金機構の案内でも、退職した人は交付されていた資格確認書などを事業主に返し、事業主は資格喪失届に回収したものを添えて提出するとしています。

会社の資料やデータは、退職後に使うつもりがなくても持ち出さないようにします。退職時に秘密保持などの誓約書を求められることもあるので、内容は[退職時の誓約書・競業避止の読み方](/guide/kyougi-kinshi/)で確かめてください。

## 会社から受け取る書類

会社から受け取る主な書類は次のとおりです。

| 書類 | どんなときに要るか | 受け取りの考え方 |
|---|---|---|
| 源泉徴収票 | 次の会社での年末調整、または確定申告 | 退職の日以後1か月以内に交付される（所得税法226条） |
| 離職票 | 雇用保険の基本手当を受けるとき | 会社が出す離職証明書をもとに、ハローワークが交付する。希望しない場合は交付されない |
| 退職証明書 | 次の会社や手続きで在籍を示すとき | 請求すれば、会社は遅滞なく交付する（労働基準法22条） |
| 年金手帳 | 会社に預けていた場合 | 返してもらう |

### 源泉徴収票

所得税法226条は、年の途中で退職した人には、退職の日以後1か月以内に源泉徴収票を交付するよう定めています。同じ年のうちに次の会社に入る場合は、前の会社の源泉徴収票を次の会社に出し、年末調整で前の会社の分とあわせて計算してもらいます。年内に次の会社に入らない場合は、自分で確定申告をするときに使います。扱いは[転職した年の源泉徴収票と年末調整](/guide/gensen-choshu/)で詳しく扱っています。

### 離職票

ハローワークの案内では、離職票は、離職したときに事業主が出す離職証明書にもとづいて、公共職業安定所が交付するものです。離職票の交付を希望しない場合は交付されませんが、あとで必要になれば交付を受けられます。

雇用保険法施行規則7条は、事業主が、被保険者でなくなった日の翌日から10日以内に資格喪失届をハローワークに出すこと、離職が原因のときは離職証明書を添えることを定めています。本人が離職票を希望しないときは離職証明書を添えないことができますが、離職の日に59歳以上の人はこの限りではありません。

このように、離職票は会社の手続きとハローワークの処理を経て交付されるため、退職日にその場で受け取れるものではありません。どのくらいで届きそうか、郵送か手渡しかは、退職前に会社の担当者に聞いておくと安心です。

次の会社が決まっていても、入社までの間に基本手当を受ける可能性があるなら、離職票を希望しておくと手続きが進めやすくなります。離職票と雇用保険の関係は[離職票と雇用保険](/guide/rishoku-hyo/)にまとめています。

### 退職証明書

労働基準法22条は、退職する人が、使用期間、業務の種類、その事業での地位、賃金、退職の事由について証明書を請求した場合、会社は遅滞なく交付しなければならないと定めています。証明書には、本人が請求しない事項を書いてはいけないとされています。次の会社から在籍の証明を求められた場合などに使えます。

### 年金手帳と基礎年金番号

日本年金機構の案内では、令和4年4月以降に初めて年金制度に加入する人には、年金手帳に代わって基礎年金番号通知書が発行されます。すでに年金手帳を持っている人には通知書は発行されず、年金手帳を引き続き保管するよう案内されています。会社に年金手帳を預けている場合は、退職のときに返してもらいます。入社時の扱いは[基礎年金番号と入社時の手続き](/guide/nenkin-techou/)で扱っています。

:::view
当社が求人をご紹介する中でよく見るのは、入社時に出す書類の案内の時期や中身が、会社によって違うことです。前の会社から受け取る源泉徴収票などを、いつまでに出せばよいかが分からないこともあります。当社経由で応募した求人なら、入社時の提出書類など求人票に書かれていない点は、ご質問いただければ企業に確認できます。
:::

## 書類が届かないとき

退職後しばらくたっても書類が届かないときは、まず退職した会社の担当者に確かめます。それでも届かないときの相談先は、書類によって違います。

- **源泉徴収票**：国税庁の案内では、支払者から交付されない場合、交付期限（中途退職は退職後1か月）を過ぎたあとに「源泉徴収票不交付の届出書」を、自分の納税地を所轄する税務署に提出できます。勤め先に交付を求めたことが分かる書類などを添えます。すでに交付された源泉徴収票の再発行は、この手続の対象外です
- **離職票**：ハローワークの案内では、前の会社に離職証明書の交付を請求し、それをハローワークに出すことで離職票の交付を受けられます。請求しても前の会社から離職証明書を受け取れない場合は、近くのハローワークに相談します
- **退職証明書**：請求しても交付されない場合は、労働基準監督署に相談できます

催促するときは、メールなど記録が残る方法でお願いしておくと、あとで相談するときに経緯を示しやすくなります。源泉徴収票の不交付の届出でも、勤め先に交付を求めたことが分かる書類を添えることになっているため、やりとりは残しておきます。

## 最終出社日までのチェックリスト

退職の手続きは項目が多く、最終出社日が近づくと引き継ぎで手一杯になりがちです。早めに次の一覧を作り、終わったものから消していきます。

1. 返却物の一覧を作り、返す日と方法（手渡しか郵送か）を会社と決める
2. 貸与されたパソコンやスマートフォンから、個人のデータやアカウントを整理する。会社のデータは消さずに残す
3. 社内に置いている私物を持ち帰る
4. 受け取る書類（源泉徴収票、必要なら離職票・退職証明書、預けている年金手帳）と、送ってもらう先の住所を伝える
5. 最後の給与の支払日と、交通費の精算や立て替えた経費の精算の方法を確かめる
6. 次の会社に入るまでに間が空く場合は、健康保険と年金の切り替えの段取りを確かめる
7. 退職後の連絡先を、担当者に伝えておく

4つ目の送り先は、退職後に引っ越す予定がある人ほど大事です。書類が前の住所に届いて受け取れないと、次の会社への提出や手続きが遅れます。引き継ぎの進め方は[引き継ぎの進め方](/guide/hikitsugi/)、有給休暇の使い方は[退職前の有給休暇の消化の考え方](/guide/yukyu-shouka/)にまとめています。

## 会社から返してもらうお金・物

労働基準法23条は、退職の場合に権利者から請求があれば、会社は7日以内に賃金を支払い、積立金・保証金・貯蓄金など名前を問わず労働者の権利に属する金品を返さなければならないと定めています。争いがある場合も、異議のない部分は期間内に支払う、または返すことになっています。

会社に預けていた物や、社内で積み立てていたものがあれば、退職前に一覧にしておき、返してもらう時期を確かめておくと安心です。

:::view
退職の手続きの中で、次の会社の入社日の調整が必要になることもあります。入社日の決め方は[入社日の決め方](/guide/nyusha-bi/)にまとめています。まだ転職先を探している段階なら、希望を伺ったうえで、サイトに載せていない非公開の求人も含めて個別にお探しできます。
:::

退職の手続きで個別の判断が必要なときは、労働基準監督署・ハローワーク・税務署・社会保険労務士などにご相談ください。

## よくある質問

### 退職後の健康保険はどうすればよいですか

退職日の翌日から次の会社に入る場合は、次の会社で健康保険に加入します。間が空く場合は、任意継続、国民健康保険、家族の健康保険の被扶養者のいずれかを選びます。選び方は[退職後の健康保険の選び方](/guide/kenpo-ninnin/)で扱っています。

### 次の会社が決まっていても、離職票は受け取った方がよいですか

入社までの間に基本手当を受ける予定がなければ、必要ないこともあります。ハローワークの案内では、希望しない場合は交付されず、あとで必要になったときに交付を受けることもできます。迷う場合は、退職前に会社に希望を伝えておくと手続きが進めやすくなります。

### 年金手帳が見当たりません

令和4年4月以降に初めて加入した人には、年金手帳ではなく基礎年金番号通知書が発行されています。それより前から加入している人で、手元にも会社にもない場合は、基礎年金番号の確かめ方を年金事務所に相談してください（2026年11月時点）。
