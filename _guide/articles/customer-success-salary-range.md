カスタマーサクセスの求人の年収は、固定給と、会社や個人の業績で変わる賞与を中心に組み立てられていることが多く、そこに更新や追加契約の成果に付くインセンティブが乗る求人と乗らない求人があります。比べるときは、固定の部分と変動の部分を分け、変動の部分が「どの指標で、個人とチームのどちらの成果で」決まるかを読みます。入社時の額は、等級（グレード）ごとの給与レンジに当てはめて決める書き方がよく見られます。

年収の幅そのものの読み方は[求人の年収の幅はどう決まるのか](/guide/nenshu-haba/)、理論年収の前提は[「理論年収」「想定年収」の読み方](/guide/riron-nenshu/)にまとめています。ここではカスタマーサクセスの求人に絞って見ていきます。

## カスタマーサクセスの給与欄によく出る書き方

カスタマーサクセスの求人の給与欄には、次のような書き方がよく出てきます。

| 書き方 | 読むときのポイント |
|---|---|
| 想定年収のレンジだけ | 賞与・固定残業代・インセンティブが含まれるかが分からない。内訳を確かめる |
| 月給と、その内訳（基本給・固定残業代） | 固定残業代の時間数と、超えた分が別に支払われるかを見る |
| 年俸制（12分割など） | 賞与が別にあるか、年俸に何が含まれるかを見る |
| 等級ごとの給与レンジに応じて決定 | 入社時にどの等級に入るかで額が決まる |
| 賞与は会社・個人の業績に応じて | 会社の業績と個人の評価の比重を見る |
| 受注やアップセルに応じたインセンティブ | 何の成果に、個人とチームのどちらで付くかを見る |
| 給与改定は年2回など | 評価の結果で固定給が見直される時期を示す |
| ストックオプションの付与の可能性 | 年収とは別のもの。条件は内定時に確かめる |
| 現年収を考慮して決定 | 前職の条件が入社時の額の材料になる |

「年収◯◯〜◯◯万円（賞与・インセンティブ込みの目安）」のように、幅の中に何が入っているかを書いている求人もあれば、レンジだけの求人もあります。同じ幅に見えても中身が違うことがあるので、何が含まれた数字かをそろえてから比べます。

## 固定給中心か、成果連動があるか

カスタマーサクセスの求人の給与の組み立ては、担当する範囲と結びついています。担当範囲が導入の支援や活用の定着にとどまる求人では、固定給と賞与だけで成り立っていることがよくあります。更新の交渉や追加契約の提案まで担う求人では、営業に近い形で、個人やチームの成果にインセンティブが付くことがあります。

給与欄だけで判断せず、仕事内容に「アップセル」「クロスセル」「契約更新」「売上目標」のような言葉があるかもあわせて見ると、成果連動の部分がどれくらい大きいかの見当がつきます。

反対に、成果連動の部分が大きい求人では、担当する顧客の入れ替わりや、製品の価格改定の影響を受けやすくなります。どの顧客を何社担当するのか、担当の割り振りは誰がどう決めるのかもあわせて聞いておくと、変動する部分の見通しが立てやすくなります。担当範囲の違いは[カスタマーサクセスの仕事の範囲](/guide/customer-success-job-scope/)、追加契約を担う求人は[アップセル・クロスセルを担うカスタマーサクセスの求人](/guide/customer-success-upsell/)で扱っています。

## 成果連動の部分は「どの指標で」決まるかを読む

カスタマーサクセスで見られる成果には、売上に直結するものと、すぐには売上にならないものがあります。給与に結びつく指標が何かで、受け取り方が変わります。

- **追加契約・アップセルの受注**：1件ごと、または金額に応じて個人に付く書き方がある
- **更新・継続の状況**：解約の少なさや継続の割合は、個人よりチームや部門の目標として扱われることがある
- **部門や事業の目標の達成**：四半期や半期の目標を達成したときに、チーム全員に支給される書き方がある
- **行動の目標**：顧客との接点の数や、施策の実行など。賞与の評価に入ることがある

個人の数字にしにくい指標は、チームの目標と結びつけて賞与に反映する書き方がよく見られます。この場合、自分が担当する顧客の状況だけでは額が決まりません。どの指標が個人で、どれがチームかを分けて確かめておくと、入社後の受け取り方のイメージが持てます。指標の読み方は[カスタマーサクセスの求人に書かれる指標の読み方](/guide/customer-success-kpi/)にまとめています。

:::view
求人をご紹介する中でよく見るのは、同じカスタマーサクセスの求人でも、インセンティブがある会社と、固定給と賞与だけで評価する会社に分かれることです。どの指標が給与に結びつくのか、個人とチームの比重はどうかは、求人票から読み取りにくい点です。ご質問いただければ企業に確認できます。
:::

## 等級と給与レンジの読み方

カスタマーサクセスの求人では、「当社規定のグレードごとの給与レンジに応じて決定」のように、等級制度に当てはめて額を決める書き方がよく見られます。同じ会社の中で、メンバー・リーダー候補・マネージャー候補と求人が分かれ、それぞれに別の幅が書かれていることもあります。

この書き方の求人では、提示額は「どの等級に入るか」と「その等級のレンジのどこか」の2段階で決まります。読むときは次の点を確かめます。

- 求人票の幅が、1つの等級のレンジなのか、複数の等級にまたがっているのか
- 入社時の等級を、選考のどの段階で、何を材料に判断するのか
- 次の等級に上がる基準と、給与改定の時期（年1回か年2回か）

給与改定が年2回の会社では、評価の期間も半年ごとのことがあり、入社した時期によって最初の見直しまでの期間が変わります。役割ごとの違いは[カスタマーサクセスの求人のポジション別の違い](/guide/customer-success-grade/)、評価のしくみは[カスタマーサクセスの評価のされ方](/guide/customer-success-evaluation/)で扱っています。

## 固定給の部分：固定残業代と手当

カスタマーサクセスの求人でも、月給の中に固定残業代を含める書き方がよく見られます。一方で、残業代を実際の時間に応じて別に支払う求人もあります。比べるときは、固定残業代を除いた基本給どうしで見ると、条件の差が分かりやすくなります。

手当では、在宅勤務の手当や、資産形成のための手当が基本給と並んで書かれていることがあります。手当が残業代の計算に入るかどうかで、時間外に働いたときの額が変わります。手当の読み方は[基本給と手当の違い](/guide/kihonkyu-teate/)、固定残業代は[みなし残業（固定残業代）の求人の読み方](/guide/minashi-zangyo/)にまとめています。

## ストックオプションが書かれている場合

成長中の会社のカスタマーサクセスの求人では、「入社時や入社後の成果に応じてストックオプション付与の可能性あり」と書かれていることがあります。ストックオプションは年収とは別のもので、行使できる時期や条件、会社の今後によって価値が大きく変わります。年収の比較には入れず、別に条件を確かめるのが基本です。付与の対象が全員なのか、成果を出した人に限るのかも、求人によって違います。確かめ方は[ストックオプションがある求人で確認したいこと](/guide/stock-option/)を参考にしてください。

## 幅のどこに決まるか：選考で見られやすい材料

カスタマーサクセスの求人で、入社時の位置を決める材料になりやすいのは次のようなものです。

- **担当してきた顧客の規模と数**：少数の大手企業を深く担当してきたか、多くの中小企業を効率よく支援してきたか
- **扱ってきた製品**：SaaSなど継続して使ってもらう製品の経験があるか、応募先と近い業務領域か
- **売上への関わり**：更新や追加契約の数字を持っていたか
- **仕組みづくりの経験**：支援の手順や資料を整え、チームで使えるようにした経験
- **チームを率いた経験**：メンバーの育成や、顧客の担当の割り振りを担ってきたか

「現職給与を加味しオファー」と書かれた求人では、前職の年収も材料になります。現在の年収を伝えるときは、固定給と賞与、成果による部分を分けて伝えると、提示額との比較がしやすくなります。

## 内定時に確かめたい項目

カスタマーサクセスの求人で、内定の前後に確かめたい項目をまとめます。

1. 基本給、固定残業代、手当の内訳
2. 賞与の決まり方（会社の業績と個人の評価の比重）
3. インセンティブの有無と、対象になる指標
4. 入社時の等級と、次の給与改定の時期
5. ストックオプションの有無と条件

内定時の条件の確かめ方は[カスタマーサクセスの内定で確認したい条件](/guide/customer-success-offer-check/)にまとめています。営業職全体の求人の傾向は[営業の求人・年収動向](/jobs/sales/market/)とページ下の掲載データも参考にしてください。

:::view
カスタマーサクセスの求人は、給与の組み立てが担当範囲と結びついているため、年収の幅だけで比べると判断を誤りやすい分野です。サイトに掲載していない非公開の求人もあるため、面談（オンラインまたは電話）で担当したい範囲や給与の希望を伺い、掲載外の求人も含めて個別にお探しできます。
:::

## よくある質問

### インセンティブがないカスタマーサクセスの求人は、年収が上がりにくいですか

一概には言えません。インセンティブがない会社では、評価の結果が固定給の見直しや等級の昇格に反映される形がよく見られます。年ごとの変動は小さくなる一方、上がり方は評価と昇格のしくみで決まるので、給与改定の時期と昇格の基準を確かめてください。

### 想定年収のレンジに賞与が含まれているかは、どう見分けますか

給与欄に「賞与を含む」「年収総額」と書かれていれば含まれています。月給の内訳と、賞与が「年2回・業績に応じて」とだけ書かれている場合は、幅に含まれていないこともあります。分からないときは、月給の12か月分と年収の幅を比べたうえで、内訳を聞いてください。

### 営業からカスタマーサクセスに移ると、年収の組み立てはどう変わりますか

求人によって違います。営業の成果に大きなインセンティブが付いていた人は、カスタマーサクセスでは固定給と賞与の比重が高くなることがあります。追加契約の成果に連動する求人もあるので、固定と変動の内訳を並べて比べるのが現実的です。営業からの移り方は[営業からカスタマーサクセスの求人に応募するときの考え方](/guide/customer-success-from-sales/)で扱っています。
